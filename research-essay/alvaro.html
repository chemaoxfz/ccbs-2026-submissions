Learned Static and Nonlinear Controllers Preserve the Local Bode Integral on a Glycolytic Plant

Álvaro Bátrez · EST 5053, Control and Computation in Biological Systems · Westlake University · research essay · 2026-11-10

One sentence: on the glycolytic plant from lecture 13, every learned controller whose linearization at the equilibrium is stabilizing — static or nonlinear — inherits a weighted Bode sensitivity integral of 0.6786 (numerical error < 3.3×10⁻¹¹), because the interpolation constraints are set by the plant's right-half-plane zero and unstable pole; the nonlinear terms shape the inhibition profile away from equilibrium without changing that local value, yielding an average 14.9% reduction in paired IAE and survival under a w = 1.1 test where the static equivalents leave the domain, but with a larger offset under w = 0.9.

1. The question

I come from AI and spent a semester watching control theory explain biological systems. Lecture 13 derives a number: 0.6786, a weighted Bode sensitivity integral that every stabilizing linear controller on the glycolytic plant must pay. The question is whether a controller learned rather than designed is subject to the same constraint, and whether a nonlinear learned policy changes the picture.

This matters because reinforcement learning is being applied to metabolic control (Espinel-Ríos et al., 2025). Empirical evidence from adaptive optics suggests learned controllers exhibit waterbed-like behavior (Nousiainen et al., 2024), but the weighted integral was not computed there.

2. The plant and its constraint

Lecture 13 compresses glycolysis into two pools with Hill-type rate laws (Chandra, Buzi & Doyle). The controlled parameter is the upstream inhibition exponent h:

v₁ = 2q̄ATP / (1 + q̄ATP2h),   v₂ = 2κq̄I / (1 + q̄ATP2g)

At (1/κ, 1) with w = 1, the equilibrium is h-independent. The linearized plant has an unstable pole p ≈ 0.3595 and a right-half-plane zero z = κ = 1.1. For every stable gain (1 < h < 2.7):

(2/π) ∫₀∞ [z/(z²+ω²)] ln|Sh(iω)| dω = ln[(z+p)/(z−p)] ≈ 0.6786

3. Phase 1: Baseline validation

The numerical pipeline (pole p from the polynomial; substitution r = (2/π)arctan(ω/z) for the infinite tail) reproduces the integral for all linear controllers tested (P at h = 1.2, 1.5, 1.9, 2.3, 2.6; PI at h = 1.9, kI = 0.2). All integrals equal 0.678588… to within 10⁻⁶ of the theoretical value.

4. Phase 2a: Static-gain RL

CEM (Cross-Entropy Method), a derivative-free policy-search algorithm, trains a constant h on the full nonlinear plant with h reevaluated at every RK4 stage. Three seeds, same configuration, common initial conditions per iteration.

5. Phase 2b: Nonlinear learned policies

The policy parameterizes the inhibition exponent:

hθ(y) = clip(θ₀ + θ₁y + θ₂tanh(2y) + θ₃y tanh(y),  0,  4),   y = q̄ATP − q*

The local linearization depends on hloc = hθ(0) = θ₀ because ∂v₁/∂h at q̄ATP = 1 is zero (ln 1 = 0). The Jacobian at the equilibrium is exactly Acl(hloc) from the course.

Each nonlinear policy is compared against a constant-gain controller with the same hloc, under 21 domain-valid initial conditions per seed (y₀ = ±{0.05, 0.2, 0.5} and +1.0; q̄I offset = {−0.1, 0, +0.1}) at w = 1, T = 100, with domain checks at every RK4 stage and no state truncation. 8. Interpretation

The Bode integral constrains the linearization of the closed loop at the operating point. The interpolation constraints S(z) = 1 and S(p) = 0 are set by the plant's right-half-plane zero and unstable pole. For all learned policies whose linearization is stabilizing, the local LTI equivalent inherits the same weighted integral.

For all learned policies whose linearization at the nominal equilibrium is stabilizing, the local LTI equivalent inherits the same weighted Bode integral (0.6786), determined by the plant's pole and zero. The nonlinear terms modify hθ(y) outside the equilibrium without changing that local value. A global advantage in average paired IAE (14.9%) and a larger tested convergence set arise from the profile shape, not from evading the local constraint.

9. Limitations

  • Local result. The integral constrains the linearization at one operating point. Global observations are from simulation of tested conditions, not proof of stability.
  • CEM is policy search (stochastic optimization of parameters on a fixed plant), not online adaptation.
  • Simple policy class (4 parameters, tanh basis, saturation). Richer policies could behave differently.
  • One plant, three seeds, 21+3 conditions each.
  • Non-uniform advantage. The static controller has lower IAE in 13/60 paired conditions; the nonlinear policy has a larger offset under w = 0.9.

10. Conclusion

All six learned policies have stable local linearizations and inherit the plant-determined weighted Bode integral. On the tested grid, the nonlinear policies reduce mean paired IAE by 14.9% and converge from three additional valid initial conditions across the seeds, while remaining in the domain under a w = 1.1 test where the static equivalents leave the domain. These global benefits are not uniform: some initial conditions favor the static controller, and the nonlinear policies show larger offsets under w = 0.9. The local constraint depends on hθ(0), whereas the nonlinear terms shape the response away from equilibrium.

import numpy as np
from scipy.integrate import quad
import json

KAPPA, G = 1.1, 0.3
Z = KAPPA
P = max(np.roots([1, 2.7, -1.1]).real)
THEORY = np.log((Z + P) / (Z - P))  # 0.678588...
X_EQ = np.array([1/KAPPA, 1.0])
H_MAX, DT, T_EVAL = 4.0, 0.02, 100.0
DOMAIN = {"qI": (0.001, 20.0), "qA": (0.001, 20.0)}

def rhs(x, h, w=1.0):
    qI, qA = x
    v1 = 2*qA / (1 + qA**(2*h))
    v2 = 2*KAPPA*qI / (1 + qA**(2*G))
    return np.array([v1-v2, -v1+2*v2-w])

def in_domain(x):
    return (DOMAIN["qI"][0] <= x[0] <= DOMAIN["qI"][1] and
            DOMAIN["qA"][0] <= x[1] <= DOMAIN["qA"][1] and
            np.all(np.isfinite(x)))

def h_policy(theta, y):
    t = np.zeros(4); t[:len(theta)] = theta
    return np.clip(t[0]+t[1]*y+t[2]*np.tanh(2*y)+t[3]*y*np.tanh(y), 0, H_MAX)

def step_nl(x, theta, w, dt):
    def f(xx):
        if not in_domain(xx): return None
        return rhs(xx, h_policy(theta, xx[1]-1.0), w)
    k1 = f(x)
    if k1 is None: return None
    k2 = f(x+dt/2*k1)
    if k2 is None: return None
    k3 = f(x+dt/2*k2)
    if k3 is None: return None
    k4 = f(x+dt*k3)
    if k4 is None: return None
    xn = x + dt/6*(k1+2*k2+2*k3+k4)
    return xn if in_domain(xn) else None

def step_st(x, h_val, w, dt):
    def f(xx):
        if not in_domain(xx): return None
        return rhs(xx, h_val, w)
    k1 = f(x)
    if k1 is None: return None
    k2 = f(x+dt/2*k1)
    if k2 is None: return None
    k3 = f(x+dt/2*k2)
    if k3 is None: return None
    k4 = f(x+dt*k3)
    if k4 is None: return None
    xn = x + dt/6*(k1+2*k2+2*k3+k4)
    return xn if in_domain(xn) else None

def bode(h_gain):
    D_o = lambda s: s**2 + 2.7*s - 1.1
    D_c = lambda s: s**2 + (2.7-h)*s + KAPPA*(h-1)
    if max(np.roots([1, 2.7-h, KAPPA*(h-1)]).real) >= 0:
        return None
    def integrand(r):
        w_ = Z*np.tan(np.pi*r/2)
        S = D_o(1j*w_)/D_c(1j*w_)
        dw = Z*(np.pi/2)/np.cos(np.pi*r/2)**2
        return (Z/(Z**2+w_**2))*np.log(np.abs(S))*dw
    val, _ = quad(integrand, 1e-10, 1-1e-10,
                  points=[.01,.1,.5,.9,.99], limit=200)
    return (2/np.pi)*val

# ===== CEM training =====
def cem_train(seed, dim, n_iters=40, pop=60, elite_frac=0.2,
              mu_init=None, sig_init=None):
    rng = np.random.default_rng(seed)
    mu = np.array(mu_init, dtype=float)
    sig = np.array(sig_init, dtype=float)
    n_elite = max(4, int(pop*elite_frac))
    history = []
    for it in range(n_iters):
        conds = []
        for _ in range(5):
            y0 = rng.uniform(0.1, 0.5) * rng.choice([-1, 1])
            qI_off = rng.uniform(-0.1, 0.1)
            conds.append((X_EQ + np.array([qI_off, y0]), 1.0))
        thetas = rng.normal(mu, sig, (pop, dim))
        thetas[:, 0] = np.clip(thetas[:, 0], 0.1, 3.5)
        costs = np.zeros(pop)
        for pi, th in enumerate(thetas):
            tot = 0.0
            for x0, w in conds:
                x = x0.copy(); traj = [x[1]]
                for _ in range(int(10.0/DT)):
                    x = step_nl(x, th, w, DT)
                    if x is None: tot += 100; break
                    traj.append(x[1])
                if x is not None:
                    tot += np.sum(np.abs(np.array(traj)-1.0))*DT
            costs[pi] = tot/len(conds)
        elite_idx = np.argsort(costs)[:n_elite]
        mu = np.mean(thetas[elite_idx], axis=0)
        sig = np.maximum(np.std(thetas[elite_idx], axis=0), 0.01)
        history.append({"iter":it, "mu":mu.tolist(),
                       "best_cost":float(costs[elite_idx[0]])})
    return mu, sig, history

VALID = []
for y0m in [0.05, 0.2, 0.5]:
    for s in [1, -1]:
        for dq in [-0.1, 0.0, 0.1]:
            VALID.append((X_EQ+np.array([dq, s*y0m]), 1.0))
for dq in [-0.1, 0.0, 0.1]:
    VALID.append((X_EQ+np.array([dq, 1.0]), 1.0))

def simulate_nl(theta, x0, w, T=T_EVAL):
    x = x0.copy(); traj = [x.copy()]
    for i in range(int(T/DT)):
        x = step_nl(x, theta, w, DT)
        if x is None: return {"status":"LEFT_DOMAIN"}
        traj.append(x.copy())
    traj = np.array(traj)
    return {"status":"OK", "traj":traj,
            "iae":float(np.sum(np.abs(traj[:,1]-1.0))*DT),
            "max_dev":float(np.max(np.abs(traj[:,1]-1.0)))}

def simulate_st(h_val, x0, w, T=T_EVAL):
    x = x0.copy(); traj = [x.copy()]
    for i in range(int(T/DT)):
        x = step_st(x, h_val, w, DT)
        if x is None: return {"status":"LEFT_DOMAIN"}
        traj.append(x.copy())
    traj = np.array(traj)
    return {"status":"OK", "traj":traj,
            "iae":float(np.sum(np.abs(traj[:,1]-1.0))*DT),
            "max_dev":float(np.max(np.abs(traj[:,1]-1.0)))}
