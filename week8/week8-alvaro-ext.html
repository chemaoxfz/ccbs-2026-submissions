Week 8 — Extension: Kd does not specify a sensor — the kinetic floor a feedback loop adds

Author: Álvaro Bátrez · Week 8 (lectures 15–16) · 2026-11-07 · CCBS 2026

One sentence: lecture 15 §11 shows two rate pairs with identical Kd = 1 µM but relaxation times 0.5 s vs 5 s — for an isolated receptor with the ligand clamped — and I walk through the door it explicitly closes ("excluding ligand depletion, cooperativity, and cellular reaction networks"): put that receptor inside a depletion loop (occupancy → output → saturable uptake) and the equilibrium stays exactly Kd-degenerate while the dynamics do not — the loop imposes a kinetic floor k+* ≈ 0.24 µM−1s−1 (a Hopf: below it the loop oscillates forever), the floor rises with loop gain, and the slow off-rate that buys affinity is memory (τoff = 1/k− = 10 s): designing a binder by affinity alone can break the loop it is meant to serve.

The point I am adding

Lecture 15 §11 pins the fact: "Different association and dissociation rates can produce the same Kd but different response times ... Equilibrium occupancy leaves response speed undetermined" — with the worked pair (k+, k−) = (1, 1) vs (0.1, 0.1), S = 1 µM, τ = 0.5 s vs 5 s, and only the fast pair meeting the 90%-in-2-s criterion. But the example holds the ligand clamped and the receptor alone, and says so: it excludes depletion and networks. In a cell, a receptor is a sensor in a loop. So I built the smallest loop that violates the exclusion:

θ̇ = k+S(1−θ) − k−θ,   Ɋ̇ = βθ − δX,   Ṃ̇ = u − (VmaxX/(KmX+X))·S/(KmS+S)

— occupancy drives an uptake output; uptake depletes the ligand; the ligand returns to the receptor: negative feedback. The equilibrium equations contain (k+, k−) only through Kd, so every pair on the degeneracy line gives the same operating point (S*, θ*, X*) = (1.000, 0.500, 2.500) — verified in simulation for every stable pair. Then the linearization says what the equilibrium cannot: a Hopf at k+* = 0.238 µM−1s−1 (at Kd = 1, loop gain ×1). The lecture's slow pair (0.1) sits below the floor: a ligand bolus does not get cleared — the loop falls into a sustained oscillation (S swinging 0.18–2.14 µM). The fast pair (1.0) sits comfortably above: smooth clearance. And doubling the loop gain doubles the floor (0.472): the faster the loop, the faster the sensor must be — exactly the trade an engineer would expect, now with a molecule-level knob. One more degeneracy breaker: after ligand washout the slow-off binder keeps θ ≈ 0.30 at t = 5 s (τoff = 1/k− = 10 s vs 1 s) — the same small k− that makes affinity cheap makes the sensor remember.

The code (core)

import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import brentq

Kd, beta, delta = 1.0, 1.0, 0.2
KmX, KmS, Vmax, u = 10.0, 0.02, 11.5, 2.2549

def equil():                       # contains (kon,koff) only via Kd
    th = lambda S: S/(S+Kd); X = lambda S: beta*th(S)/delta
    S = brentq(lambda S: (Vmax*X(S)/(KmX+X(S)))*S/(KmS+S) - u, 1e-9, 50)
    return S, th(S), X(S)          # (1.000, 0.500, 2.500) for every pair

def rhs(t, x, kon, koff):
    th, X, S = x
    return [kon*S*(1-th) - koff*th,                                # sensor
            beta*th - delta*X,                                     # output
            u - (Vmax*X/(KmX+X))*S/(KmS+S)]                        # uptake loop

# poles: char = s^3 + (a+d+e)s^2 + (ad+ae+de)s + (ade + b*beta*c)
#   a = kon(S*+Kd), b = kon(1-th*), c=dU/dX, e=dU/dS at the equilibrium
# fast pair poles: -2.09, -0.076 +/- 0.419i (stable)
# slow pair poles: +0.021 +/- 0.278i  -> Hopf floor kon* = 0.238
def bolus(kon, koff, T=160):       # +1 uM ligand bolus, full nonlinearity
    S0, th0, X0 = equil()
    s = solve_ivp(lambda t,x: rhs(t,x,kon,koff), [0,T], [th0,X0,S0+1],
                  method="LSODA", rtol=1e-10, atol=1e-12)
    return s
# bolus(1,1):   S returns to 1 smoothly (clearance)
# bolus(.1,.1): sustained oscillation, S in [0.18, 2.14]

What I would argue against / where this breaks

  • The floor is wiring-dependent. My first wiring (uptake ∝ X·S, first-order in ligand) has no floor at any gain: the uptake pole scales with the gain and damps the loop as fast as the gain excites it — I verified this by failing to tune one. The floor here belongs to saturable uptake (zero-order in ligand, KmS = 0.02 µM ∝ S*). The lesson survives the wiring: whether a kinetic floor exists, and where, is a property of the network — invisible to Kd.
  • The loop is a toy. Ligand turnover at equilibrium is 2.25 µM/s — a seconds-scale circuit chosen to match the receptor kinetics of §11, not a measured uptake system; real scavenging loops (cytokines, iron, amino acids) run slower and would sit far above their floors.
  • Still excluded, as in the lecture: cooperativity, rebinding, allostery, multivalent binding — each can add its own slow timescale and move the floor.
  • No noise. Molecular counts would make the slow pair's oscillation stochastic and the memory (τoff = 10 s) noisy; the identifiability angle — equilibrium data cannot even separate the pair on the degeneracy line — is the natural sequel, not done here.
  • The 90%-in-2-s criterion is the lecture's reporter scenario, not a universal spec; a slower task would tolerate the slow pair in the isolated setting — but inside a loop, the tolerance is set by the gain, not by the task.
