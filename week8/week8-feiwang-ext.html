Week 8 — Extension: A virtual cell must predict recovery, not just the resting state

Author: Fei Wang · Week 8 / Lecture 16 · 2026-11-09

One sentence: A common reaction language can make a virtual cell easier to assemble, but reliable predictions of recovery require dynamic constraints that steady-state agreement alone cannot provide.

The point I am adding

Problem. Lecture 16 proposes binding and catalysis as a shared language for mechanistic virtual cells [1]. I support this ambition, but would evaluate its success with a specific question: can the model predict how a molecular pool recovers after depletion? Matching its resting concentration is a weaker test.

Challenge. A concentration measures the amount present, not the speed of replacement. Rapid production balanced by rapid loss can produce the same baseline as slow production balanced by slow loss. Even when the reaction network is known exactly, a baseline measurement may leave its rates unidentified. A more consistent representation does not, by itself, supply the missing information.

Approach. I would retain all parameter sets compatible with baseline data and compare their predictions after a defined perturbation. Karr et al. integrated 28 submodels in a whole-cell model of Mycoplasma genitalium and evaluated predictions against independent data [2]. My proposed extension is to make disagreement among equally compatible models a guide to choosing the next dynamic measurement.

Proof. The calculation below is a counterexample, not a whole-cell simulation: two parameter sets share the same reactions and exactly the same baseline, yet differ tenfold in recovery time. It establishes that steady-state agreement is insufficient for this prediction. It does not establish that every virtual-cell model is unreliable.

Significance. A practical virtual cell should report which perturbation predictions remain uncertain and which observations could resolve them. For a future model of cellular stress adaptation, this would distinguish maintaining an unchanged molecular abundance from restoring that abundance rapidly. The useful output is a testable recovery prediction with an explicit range of possibilities.

Work it

Consider an effective production–loss module, ∅ → X → ∅, with constant production rate α and first-order loss rate δ. It is deliberately simpler than an explicit binding–catalysis model: both parameter sets already use identical reaction rules. X is a concentration in a well-mixed compartment of fixed volume; α has units nM min−1 and δ has units min−1.

dX/dt = α − δX  ;  Xss = α/δ

All parameters are illustrative choices, not fitted measurements. A baseline of 100 nM constrains only α/δ: every pair α = 100δ fits it exactly. The rates remain non-identifiable from this observation, however precisely the baseline is measured.

At t = 0, remove half of X instantaneously, so X(0) = 50 nM; then restore the original conditions without changing α or δ. Solving the differential equation gives:

X(t) = 100 − 50e−δt
t90 = ln(10)/δ

Here, 90% recovery means replacing 45 of the missing 50 nM, reaching 95 nM; it does not mean reaching 90 nM. At 20 minutes, the two predictions differ by 34.17 nM despite their identical baselines.

For these two fixed candidates, the concentration gap is ΔX(t) = 50(e−0.01t − e−0.10t). Setting its derivative to zero yields t* = ln(0.10/0.01)/(0.10 − 0.01) = 25.58 min, where the gap is 34.84 nM. With equal, time-independent absolute measurement error, this is the single sampling time that maximizes their predicted separation. It is not a universal optimal time for parameter estimation.

Reproduce the numbers — JavaScript, no dependencies

This code evaluates the exact solution; it does not approximate the ODE by time steps. The figure samples that same solution every 0.1 min from 0 to 60 min. Use the button or paste the code into a browser console.

const baseline = 100; // nM; illustrative, not measured
const initial = 50;   // nM immediately after depletion
const models = [
  {name: "A", alpha: 10, delta: 0.10},
  {name: "B", alpha: 1,  delta: 0.01}
]; // alpha: nM/min; delta: 1/min
function concentration(m, t) {
  const steady = m.alpha / m.delta;
  return steady + (initial - steady) * Math.exp(-m.delta * t);
}
const rows = models.map(m => ({
  model: m.name,
  baseline_nM: m.alpha / m.delta,
  at20min_nM: concentration(m, 20),
  t90_min: Math.log(10) / m.delta
}));
const tBest = Math.log(models[0].delta / models[1].delta)
            / (models[0].delta - models[1].delta);
const gap = concentration(models[0], tBest)
          - concentration(models[1], tBest);
console.table(rows);
console.log({tBest, gap});

What I would argue against / where this breaks

I would argue against treating a correct baseline plus a common reaction language as sufficient evidence of predictive validity. The lecture itself lists parameter unidentifiability as a challenge [1]; my example gives that challenge an explicit, falsifiable consequence rather than claiming the lecture ignores it.

I would also reject the opposite extreme: requiring every parameter to be precisely measured before trusting any prediction. Gutenkunst et al. showed that some predictions can remain tightly constrained even when individual parameters are uncertain [3]. Their “sloppiness” concerns unequal sensitivities to parameter combinations; my example is the narrower case of exact non-identifiability from a single steady-state observable. Uncertainty should be assessed for the specific prediction.

This toy model assumes constant production, linear loss, fixed volume, and a perturbation that leaves both rates unchanged. Feedback, growth dilution, saturation, or spatial transport could invalidate its recovery curve. A trajectory matching neither candidate would challenge the model assumptions, not merely select a new rate. More dynamic measurements would then be needed. Thus the result motivates targeted validation; it is not evidence that one recovery measurement can validate an entire cell.
