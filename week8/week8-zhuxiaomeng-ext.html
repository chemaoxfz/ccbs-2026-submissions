Week 8 · Can Two Unfavorable Mutations Rescue Binding?

Author · zhuxiaomeng  |  Student ID · 20261104507
Week 8 (2026-11-09) · CCBS 2026 · Lecture 15

One sentence. In GB1, the effect of a substitution depends on the residue at another site, so screening single mutants alone can miss a combination that improves the binding-selection readout.

The point I am adding

Lecture 15 uses sequence covariation to show that the identities at two positions may matter together.1 I want to test that idea with an experiment. If two substitutions each lower the readout in a wild-type background, could combining them raise it above wild type?

Olson et al. surveyed single and double substitutions across the GB1 domain.2 I use four variants from the later GB1 library of Wu et al., which tested binding to the Fc region of human IgG by mRNA display.3 Positions 40 and 41 stay fixed while I compare V39F, V54S and their combination.

Work it

I recalculated the normalized enrichment w from the input and selected read counts in Supplementary file 1. The ratio of selected to input reads is divided by the same ratio for wild type, giving wild type a score of 1.34 I use this calculation for all four variants so they share one assay scale. The supplement's published single-mutant fitness values incorporate a rescaling of Olson et al.'s measurements. The corresponding raw-score column in the authors' analysis files confirms the recomputed values.5

If the substitutions act independently on a proportional scale, their effects multiply. Equivalently, they add on a log scale. For the double mutant, this gives an expected enrichment of 0.159.

ε=ln(wdoublewV39FwV54S)≈2.258

The observed double-mutant score of 1.520 is 9.56 times the prediction. V39F lowers enrichment when introduced into wild type, but raises it when V54S is already present. V54S shows the same reversal across backgrounds. These point estimates illustrate reciprocal sign epistasis in the binding-selection phenotype.3

What I would argue against / where this breaks

A rule that discards every substitution with a score below 1 would discard both starting substitutions in this example. The evidence concerns enrichment in one selection condition. Enrichment can reflect folding as well as binding, and direct affinity and stability measurements would help identify the mechanism. The pair was selected as an illustration after inspecting the data. Its effect size describes this pair under this assay condition.

Reproduce the calculation and figure in Python 3

Run the script to generate the numerical CSV and the SVG. The four count pairs are embedded, and the script uses only the Python standard library.

"""Reproduce the GB1 enrichment analysis and figure using Python 3.

The input/selected read counts are from rows 2, 7, 42 and 308 of
Wu et al. (2016), Supplementary file 1, doi:10.7554/eLife.16965.024.
Use the count columns, following Equation 1 in the article. The supplement
Fitness column uses rescaled Olson et al. scores for single substitutions.
Run this script to write gb1_epistasis.svg and gb1_enrichment.csv.
"""
import csv
import math
from pathlib import Path

# (four-site sequence, substitution, input reads, selected reads)
RECORDS = [
    ("VDGV", "Wild type", 92735, 338346),
    ("FDGV", "V39F", 136, 161),
    ("VDGS", "V54S", 896, 1602),
    ("FDGS", "V39F/V54S", 236, 1309),
]


def calculate():
    wild_type_ratio = RECORDS[0][3] / RECORDS[0][2]
    scores = [selected / initial / wild_type_ratio
              for _, _, initial, selected in RECORDS]
    expected = scores[1] * scores[2]
    return scores, expected, math.log(scores[3] / expected)


def figure():
    scores, expected, _ = calculate()
    baseline, scale = 250, 122
    y = lambda value: baseline - scale * value
    parts = [
        '<svg viewBox="0 0 660 318" xmlns="http://www.w3.org/2000/svg" role="img" aria-labelledby="plot-title plot-desc">',
        '<title id="plot-title">Two low-enrichment single mutants yield a high-enrichment double mutant</title>',
        '<desc id="plot-desc">Wild type 1.000, V39F 0.324, V54S 0.490, predicted double mutant 0.159, and observed double mutant 1.520.</desc>',
        '<rect width="660" height="318" fill="white"/>',
        '<g font-family="Arial, sans-serif" font-size="13" fill="#233042">',
        '<text x="67" y="24" font-size="15" font-weight="700">IgG Fc selection of GB1 variants</text>',
    ]
    for tick in [0, 0.5, 1, 1.5]:
        yy = y(tick)
        stroke = "#93a3b3" if tick == 1 else "#e1e7ee"
        dash = ' stroke-dasharray="5 4"' if tick == 1 else ""
        parts += [
            f'<line x1="66" y1="{yy}" x2="637" y2="{yy}" stroke="{stroke}"{dash}/>',
            f'<text x="56" y="{yy+4}" text-anchor="end">{tick:g}</text>',
        ]
    parts += [
        '<path d="M66 43V250H637" fill="none" stroke="#49596a"/>',
        '<text x="17" y="150" text-anchor="middle" transform="rotate(-90 17 150)">Enrichment relative to wild type</text>',
    ]
    bars = [
        ("Wild type", "VDGV", scores[0], "#51677d"),
        ("V39F", "FDGV", scores[1], "#527bc2"),
        ("V54S", "VDGS", scores[2], "#527bc2"),
        ("Predicted", "double mutant", expected, "#ffffff"),
        ("Observed", "double mutant", scores[3], "#138375"),
    ]
    for index, (label, sublabel, value, color) in enumerate(bars):
        center = 123 + 114 * index
        outline = ' stroke="#536577" stroke-width="2" stroke-dasharray="5 3"' if index == 3 else ""
        parts += [
            f'<rect x="{center-30}" y="{y(value):.2f}" width="60" height="{scale*value:.2f}" fill="{color}"{outline}/>',
            f'<text x="{center}" y="{y(value)-8:.2f}" text-anchor="middle" font-weight="700">{value:.3f}</text>',
            f'<text x="{center}" y="271" text-anchor="middle">{label}</text>',
            f'<text x="{center}" y="289" text-anchor="middle" fill="#536577">{sublabel}</text>',
        ]
    return "\n".join(parts + ['</g></svg>'])


if __name__ == "__main__":
    scores, expected, epsilon = calculate()
    with open("gb1_enrichment.csv", "w", newline="", encoding="utf-8") as out:
        writer = csv.writer(out)
        writer.writerow(["variant", "substitution", "input_reads", "selected_reads", "relative_enrichment"])
        for row, score in zip(RECORDS, scores):
            writer.writerow([*row, score])
    Path("gb1_epistasis.svg").write_text(figure(), encoding="utf-8")
    print(f"Observed = {scores[3]:.6f}, expected = {expected:.6f}")
    print(f"Observed / expected = {scores[3] / expected:.6f}, log epistasis = {epsilon:.6f}")
