CCBS 2026 · WEEK 8 EXTENSION

Which four protein designs should we test?

Siheng Wang · 3 November 2026 · Lecture 15, protein design

One sentence. Among eight Top7 redesigns, selecting four by sequence coverage puts every candidate within 26 substitutions of a selected design, while the four lowest model scores leave a gap of 30.

The point I am adding

Lecture 15 runs ProteinMPNN on a fixed protein backbone called Top7. The eight proposed sequences have 92 aligned residues each. ProteinMPNN assigns each sequence a score for its compatibility with the backbone, with lower values favored in this run. Suppose I can measure soluble expression for only four candidates. I want the first panel to sample the range of sequences on offer. Which four give the best coverage?[1] [2]

Work it

Start with two candidates, A2 and A4. Their amino acids differ at 19 of the 92 positions, so their Hamming distance is 19. For any proposed panel, I count each candidate’s distance to its closest panel member. A selected candidate has distance zero. The largest of the eight distances tells me how far the least represented candidate sits from the panel.

R(panel) = largest distance to the nearest selected sequence

The four lowest scores select A4, A2, A5 and A3. Candidate A6 differs from those sequences at 30, 30, 34 and 33 positions respectively, giving it a nearest distance of 30. I compared all 70 ways to pick four of the eight. A2, A5, A6 and A8 form the only panel with a gap of 26. Its least represented sequence is A3, which differs from A8 at 26 positions.

Reproduce the comparison and plot · Python

The script includes the eight input sequences and scores in the order used in Figure 12 of the lecture. A1–A4 correspond to T0.1-S1 through T0.1-S4, and A5–A8 to T0.3-S1 through T0.3-S4. Run with Python 3 and Matplotlib 3.6 or later.

"""Reproduce the Top7 shortlist comparison and figure. Requires Matplotlib."""
from itertools import combinations
import matplotlib.pyplot as plt

# A1–A8 follow Lecture 15, section 7, Figure 12.
# Within each row: candidate ID, ProteinMPNN score, sequence on chain A3–A94.
designs = [
    ('T0.1-S1', 0.932, 'MIKIKVTIKKGDEVLELEKEVESEEEFEKVLEEIKEIIKKLDPKEVTISVTAETPEKAEEYAKILRKLLEELGYKDIKVELEGNTVTVTGKK'),
    ('T0.1-S2', 0.8626, 'MIEITVTIKDGDKTIELKYEVESDEEFKKVLKEIEEIIKKENPEEVTISVKAETPEEAKKYAEILKKLLKKLGYNDIEVKFEGNTVTVTGKK'),
    ('T0.1-S3', 0.9166, 'MIKIKVKIEKEDEVIELEYEVESKEELKKVLEELREIIREKNPPVVEISVTAETPEEAKEYAEILEELLRELGYEEIEVKFEGNTVTVKGRR'),
    ('T0.1-S4', 0.8415, 'MIKITVIIKKGDKEIKLEYEVESEEELEKVLEEIKKIIKEENPPEVTISIEAETPEEAKKYAEKLKKLLKELGYNDIEVKLEGNTVTVTGKK'),
    ('T0.3-S1', 0.9012, 'KILIKVNIEKGNEKIEIEEEVSSDEELEEVLKKIEEIIKKKNPEKVTISVTAETPEEARKYAEKLKKLLEKLGYKDIKVEFNGNTVTVTGKR'),
    ('T0.3-S2', 0.961, 'MKKIKVVIEKDNKKIELDYTVDSDEEFEKVLEELKQVIKKENPPEVSISVTASTPEEAEKYAKILKEFLEELGYKDIEVKFDGNTVTVTGKK'),
    ('T0.3-S3', 0.9904, 'MIKVTVTIKKGDETIEIKREIESKEEFEKVLEELKEIIKEKNPEEVTISVEAETPEEAKEYAEILRNFLEELGYSDITVEFDGNTVTVTGKK'),
    ('T0.3-S4', 0.9898, 'MIKIKVTIKKGDEVLEIEKEVDDEEEFKEVLEELEEIIKERNPEEVTISVTAETPEEAKKYATILEELLRKLGYEDITVTLDGNTVTVTGRR'),
]
count = len(designs)
sequences = [row[2] for row in designs]
assert count == 8 and all(len(seq) == 92 for seq in sequences)
distances = [
    [sum(x != y for x, y in zip(left, right)) for right in sequences]
    for left in sequences
]
score_order = sorted(range(count), key=lambda i: designs[i][1])

def nearest_distances(panel):
    return [min(row[index] for index in panel) for row in distances]

def gap(panel):
    return max(nearest_distances(panel))

budgets = list(range(1, 7))
score_gaps, best_gaps = [], []
for budget in budgets:
    panels = list(combinations(range(count), budget))
    best_panel = min(panels, key=gap)
    score_panel = score_order[:budget]
    score_gaps.append(gap(score_panel))
    best_gaps.append(gap(best_panel))
    if budget == 4:
        print("Panels checked:", len(panels))
        print("Number attaining smallest gap:",
              sum(gap(panel) == gap(best_panel) for panel in panels))
        for selected in (score_panel, best_panel):
            print("Panel:", [f"A{i + 1}" for i in selected])
            print("Nearest distances:", nearest_distances(selected))

plt.rcParams.update({"svg.fonttype": "path", "font.size": 10})
fig, ax = plt.subplots(figsize=(6.9, 3.55), layout="constrained")
ax.axvspan(3.78, 4.22, color="#e8f1ed", zorder=0)
ax.plot(budgets, score_gaps, "s--", color="#905128", lw=2, ms=6,
        label="Take the lowest scores")
ax.plot(budgets, best_gaps, "o-", color="#08786e", lw=2.3, ms=6,
        label="Minimize the gap")
for value, color, offset in [(score_gaps[3], "#905128", 9),
                             (best_gaps[3], "#08786e", -16)]:
    ax.annotate(str(value), (4, value), xytext=(0, offset),
                textcoords="offset points", color=color, ha="center",
                weight="bold", fontsize=11)
ax.set(xlabel="Number of designs selected", ylabel="Largest gap (substitutions)",
       xticks=budgets, yticks=range(22, 35, 2), ylim=(22, 34.8), xlim=(.75, 6.25))
ax.spines[["top", "right"]].set_visible(False)
ax.spines[["left", "bottom"]].set_color("#aebeb8")
ax.grid(axis="y", color="#dce5df", lw=.8)
ax.set_axisbelow(True)
ax.legend(loc="upper right", frameon=False, fontsize=9)
fig.savefig("shortlist.svg", metadata={"Date": None})

Where this rule breaks

Coverage counts every substitution equally. If one buried residue controls stability, two nearby sequences could give very different assay results. For this example I would use the four candidates to measure soluble expression under identical conditions. A useful follow-up would measure A3 alongside its nearest representative A8. A large difference would challenge the idea that the panel represents biological performance as well as it represents sequence space. All eight expression outcomes remain open.
