One Michaelis–Menten curve, five decades of simulation cost

Shi Yanqing (施延庆) · Week 1, lectures 1–2 · CCBS 2026 · ~1150 words

One sentence: Steady-state kinetics measures kcat and KM; the cost of simulating the same enzyme one reaction event at a time is proportional to k1, which is the one constant those measurements cannot see — so two enzymes with identical Michaelis–Menten curves can differ by five decades in simulation cost.

1The input that is not a measurement

Lecture 2 §11 compresses Briggs–Haldane into one line and calls the result the number the whole course rests on: how many times a complex forms and falls apart per molecule of product,

r ≡ k−1/k2 = k1/(kcat/KM) − 1.   (1)

Equation (1) is exact. What I want to push on is what goes into it. Steady-state kinetics returns kcat and KM; k1 appears only inside the composite kcat/KM and is never recovered on its own. The course exposition says exactly this, about its own arithmetic: "one of the five inputs above is not a measurement … kon = 108 did not: it is the diffusion ceiling, discounted for modesty." And because kcat/KM ≤ k1, a measured kcat/KM is only a lower bound on the encounter rate.1

So r is not measured either. It is bracketed, between that lower bound and the diffusion-limited rate constant of lecture 2 §8. Write that ceiling as kdiff ≡ 4πDa · 103NA, the Smoluchowski volume-per-time already converted into M−1s−1; for a metabolite meeting an enzyme it is 1.4 × 1010 M−1s−1. Then

kcat/KM ≤ k1 ≤ kdiff  ⟹  0 ≤ r ≤ 1.4 × 105.   (2)

A bracket 5.15 decades wide. My claim is that this particular missing constant is not harmless bookkeeping: it is the entire cost of simulating the enzyme stochastically.

2One curve, many enzymes

Hold kcat = 10 s−1 and KM = 10−4 M, the medians of lecture 2's Table 4. Walk k1 across the bracket in (2) and set k−1 = KMk1 − kcat at each step, which holds KM fixed by construction. Every parameter set below therefore has the identical rate law v = kcat[S]/(KM+[S]).

In Gillespie's direct method each product molecule costs, in expectation, (1 + r) bindings, r unbindings and one catalysis. Substituting (1),

E[Nevents] per turnover = 2(r + 1) = 2k1/(kcat/KM).   (3)

Both equalities are exact — the second is just (1) with the −1 cancelled, so no large-r approximation is needed. The bill is linear in the unmeasured constant: one decade of k1 buys exactly one decade of events.

the sweep, in full 
KCAT, KM = 10.0, 1e-4              # lecture 2, Table 4 medians
KCATKM   = KCAT / KM               # 1e5 M^-1 s^-1, the measured composite

def r_of(k1):                      # lecture 2, eq (21). Exact.
    return k1 / KCATKM - 1.0

def events_per_turnover(r):        # (1+r) bindings + r unbindings + 1 catalysis
    return 2.0 * r + 2.0

for k1 in (1e5, 1e6, 1e7, 1e8, 1e9, 1.4e10):
    r = r_of(k1)
    assert abs(events_per_turnover(r) - 2*k1/KCATKM) < 1e-6      # eq (3), exactly
    print(f"k1={k1:8.1e}  k_-1={r*KCAT:10.1f}  r={r:9.1f}  E[events]={events_per_turnover(r):9.1f}")

the simulator 
import random, time, math
def ssa_mm(k1S, km1, k2, E0, n_prod, seed=0):
    """Gillespie DIRECT METHOD, substrate buffered so k1S = k1*[S] is constant.
       Draws the exponential waiting time and advances the clock, then the channel."""
    rng = random.Random(seed)
    E, C, P, ev, t = E0, 0, 0, 0, 0.0
    w0 = time.perf_counter()
    while P < n_prod:
        a1, a2, a3 = k1S * E, km1 * C, k2 * C
        a0 = a1 + a2 + a3
        if a0 <= 0.0: break
        t += -math.log(rng.random()) / a0        # waiting time; clock advanced
        u = rng.random() * a0                    # which channel fired
        if   u < a1:      E -= 1; C += 1         # bind
        elif u < a1 + a2: E += 1; C -= 1         # fall apart
        else:             E += 1; C -= 1; P += 1 # turn over
        ev += 1
    return ev, P, t, time.perf_counter() - w0

for r in (1, 10, 100, 1000):                     # E0 = 1: one enzyme
    ev, P, t, dt = ssa_mm(1e4, r * 10.0, 10.0, 1, 3000, seed=7)
    print(f"r={r:5d}  measured {ev/P:8.1f}   2(r+1) = {2*(r+1):6d}   "
          f"ratio {ev/P/(2*(r+1)):.3f}   {dt:.2f} s wall")

This is the payoff, and it is not a complaint about the lecture: it is the lecture's own instruction being followed. Lecture 1 §10 closes with "every number on this page is checkable, and some of them will not survive being checked." Equation (1) survives. The number people quote from it does not, because the input it needs was never measured.

5Then which measurement would settle it?

If the mean carries no information about r, the fluctuations might. Take a single enzyme with buffered substrate. One turnover is a geometric number of attempts, each an Exp(k1[S]) wait in E followed by an Exp(k−1+k2) wait in C, succeeding with probability p = 1/(1+r). Writing s = 1/k1[S] and t = 1/(k−1+k2), so that s/t = KM/[S],

1/E[T] = kcat[S]/(KM+[S]),     R ≡ VarT/(ET)2 = 1 − 2p·st/(s+t)2.   (4)

The mean returns Michaelis–Menten exactly, as it must. The variance does not: at [S] = KM, equation (4) collapses to

R = 1 − 1/(2(1+r))  ⟺  r = 1/(2(1−R)) − 1.   (5)

R is the randomness parameter, which is what single-molecule turnover statistics measure. So the information the steady-state curve throws away is recoverable in principle, from exactly the kind of experiment lecture 5 is about. Then ask how well it is recoverable, which is where my own check stops being able to help. As r grows T tends to an exponential, and the delta method on R̂ = m2/m12 − 1 with exponential moments gives Var(R̂) → 4/n, so SE(R̂) ≈ 2/√n. At my n = 2 × 105 that is 4.5 × 10−3:

Table 4. My simulation verifies equation (5) for r ≤ 10 and cannot verify it beyond. The last two rows agree with (5) to a decimal place or two, and that agreement is not evidence: the deviation being tested is smaller than the error on the test. Saying so is the point of the table. (An empirical check with 200 replicates at r = 10 gives SD(R̂) = 0.0246 against 2/√n = 0.0283, so the formula is a slight over-estimate at moderate r, where T is not yet exponential.)

Inverting the requirement gives the sharper statement. To see the deviation at one sigma needs n = (2/(1−R))2 = 4(1+r)2 turnovers: 1.6 × 107 to detect r = 103, and 3.1 × 1011 to detect the r = 1.4 × 105 that lecture 2 §11 quotes. The cost of measuring r from noise grows as r2, so the experiment gets hardest exactly where the answer matters most.

the turnover-statistics check 
import random, statistics, math
KCAT, KM = 10.0, 1e-4
def turnovers(r, S_over_KM, n, seed=0):
    """n turnover times of ONE enzyme; K_M held fixed while r varies."""
    rng = random.Random(seed)
    k2 = KCAT; b = r * k2 + k2                   # b = k_-1 + k_2
    a = (b / KM) * (S_over_KM * KM)              # = k1 * [S]
    p = k2 / b                                   # Pr[a formed complex reaches product]
    ts = []
    for _ in range(n):
        T = 0.0
        while True:
            T += rng.expovariate(a) + rng.expovariate(b)
            if rng.random() < p: break
        ts.append(T)
    m = statistics.fmean(ts)
    return 1.0 / m, statistics.pvariance(ts) / m**2          # (rate, R)

N = 200_000; SE = 2 / math.sqrt(N)               # delta method, exponential limit
for r in (0, 1, 10, 100, 1000):
    v, R = turnovers(r, 1.0, N, seed=11)
    signal = 1 / (2 * (1 + r))                   # eq (5)
    print(f"r={r:5d}  1/E[T]={v:7.4f} (MM: 5.0000)  1-R measured={1-R:9.2e}  "
          f"theory={signal:9.2e}  signal/SE={signal/SE:6.2f}")

So the measurement that actually settles r is the pre-steady-state one: stopped flow, temperature-jump relaxation, or NMR relaxation dispersion — anything that resolves the binding transient instead of the steady state, and returns k1 and k−1 separately rather than through their combination.

6Where this breaks

The bracket is not a distribution. The lower end of (2), k1 = kcat/KM, requires k−1 = 0, which is irreversible binding and not a real enzyme. So 5.15 decades is the width of what the measurements permit, not of what enzymes do. Establishing the latter needs the pre-steady-state data this essay says are missing, which is circular in a way I cannot escape from lecture material alone.

Equation (3) is a specific accounting. One enzyme, buffered substrate, direct method, and an expectation rather than a realisation. The next-reaction method changes the constant and not the scaling; substrate depletion, enzyme competition and compartmentation change it too.

The wall-clock column is one implementation. 1.72 × 106 events/s is measured, but it is pure Python on one core, and I have no benchmark for any other implementation, so I make no claim about how much a compiled one would gain. Table 3's argument is the ratio 140, which is a ratio of event counts and carries no implementation in it at all.

Equation (5) assumes the three-state scheme. Real enzymes have conformational substates, and dynamic disorder can push R above 1, which the derivation above cannot produce. Inverting a measured R for r is legitimate only once that scheme has been independently justified — the same kind of assumption this essay is complaining about, one level down.

7Where this goes

Cao, Gillespie and Petzold built the slow-scale SSA on exactly this system, and their reason for choosing it is equation (1) read as a computational statement: the complex "is usually much more likely to decay into its original constituents than to produce a product molecule."2 Lecture 2's Figure 11 draws binding and catalysis as two boxes, separable because they are four decades apart. Equation (3) says that separation has a price list, and that the entry on it was never measured.
