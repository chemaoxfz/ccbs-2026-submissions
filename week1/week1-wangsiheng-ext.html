Why a DNA-binding protein should not search DNA forever

Author: Wangsiheng · Week 1 (due 2026-09-07) · CCBS 2026

One sentence: A transcription factor finds a DNA target fastest by alternating 3D diffusion with short 1D slides, because longer sliding checks more base pairs per landing but wastes time revisiting nearby DNA; a minimal model predicts a finite optimum where the two legs take equal time.

The point I am adding

Lecture 2 derives a diffusion-limited rate for two molecules meeting in solution, then mentions that the lac repressor can beat the naive limit for a one-base-pair target by first binding anywhere on DNA and sliding to its operator [1]. That sounds as if more nonspecific DNA binding—and therefore more sliding—must always make the search faster. It does not. If LacI never lets go, finding one operator becomes a one-dimensional random walk across a 4.6-million-base-pair chromosome, and the diffusion time grows with distance squared. The useful strategy is not “slide”; it is alternate dimensions.

3D relocationland at a new DNA segment
→
1D slidescan ℓ nearby base pairs
→
repeatuntil the operator is hit

Make that trade-off explicit. Let the genome contain G base pairs. In one search round, a protein spends τ3 relocating in the cytoplasm, then scans a fresh stretch of length ℓ by 1D diffusion with coefficient D1. Diffusing a distance ℓ takes roughly τ1 = ℓ²/(2D1), while about G/ℓ rounds are needed to cover the genome. The null-model search time is therefore

T(ℓ) ≈ (G/ℓ)[τ3 + ℓ²/(2D1)] = Gτ3/ℓ + Gℓ/(2D1).

The first term falls when sliding length grows: longer slides amortize each 3D landing. The second rises: 1D diffusion revisits nearby positions, so doubling the distance costs four times as long per slide. Differentiating gives ℓ* = √(2D1τ3). At this optimum, τ1 = τ3: the fastest search spends equal time in the two modes, a scaling result first developed for facilitated diffusion by Berg, Winter and von Hippel [2].

Work it: one universal curve, then LacI

Write x = ℓ/ℓ*. Dividing by the minimum time removes every organism-specific parameter:

T/Tmin = ½(x + 1/x).
Reproducible calculation embedded in this file 
# Python 3; no packages
from math import log10

# Universal curve in Fig. 1
for i in range(101):
    logx = -1 + 2*i/100
    x = 10**logx       # ell / ell_star
    y3 = 1/(2*x)       # 3D-relocation cost
    y1 = x/2           # 1D-scanning cost
    total = y3 + y1
    print(x, y3, y1, total)

# LacI order-of-magnitude check
G = 4.6e6             # bp [1]
ell = 45              # bp [4]
D1_um2_s = 0.046      # um^2/s [3]
bp_um = 0.00034       # um/bp
D1 = D1_um2_s / bp_um**2

rounds = G / ell
cycle_ms = [t/rounds*1000
            for t in (180, 300)]
slide_ms = ell**2/(2*D1)*1000

print(rounds)          # 102222
print(cycle_ms)        # 1.76, 2.93 ms
print(slide_ms)        # 2.54 ms

Now use LacI as an order-of-magnitude check, not a fit. Hammar and colleagues measured a sliding length of 45 ± 10 bp in living E. coli and a 3–5 minute search time for one LacI dimer to find one operator [4]. If each 45-bp slide inspected entirely fresh DNA—the model’s deliberately optimistic assumption—then a 4.6-Mbp genome requires about 4.6×106/45 ≈ 1.0×105 rounds. Dividing 3–5 minutes by that count leaves only 1.8–2.9 ms per round.

An independent single-molecule study reported D1 = 0.046 ± 0.01 μm²/s for LacI [3]. Using 0.34 nm per base pair, a 45-bp RMS slide takes ℓ²/(2D1) ≈ 2.5 ms—the same millisecond scale as the entire round inferred above. The agreement is not a parameter-free prediction, but it passes the lecture’s order-of-magnitude test: alternating roughly 105 very short searches can fit inside minutes.

The extension: facilitated diffusion is useful because it creates a tunable compromise, not because one-dimensional search is intrinsically faster. The optimal control variable is how long the protein stays nonspecifically bound.

What I would argue against / where this breaks

The calculation assumes each 3D excursion lands at an independent, uniformly random genome position and each slide scans ℓ new base pairs. A packed nucleoid violates both assumptions: the protein can rebind nearby, revisit bases, transfer between adjacent DNA segments, hit roadblocks, and miss the operator even after sliding across it. Hammar et al. found that LacI passed its natural operator without binding in more than 90% of encounters [4]. Our numerical check is therefore an optimistic lower-resolution ledger, not a mechanistic fit. Its robust claim is only the U-shaped trade-off: if 3D relocation has a cost and 1D motion is diffusive, both zero sliding and infinite sliding are slow, so an intermediate switching time must be best.
