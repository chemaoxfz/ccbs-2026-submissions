Week 1 — Extension: Fast diffusion does not guarantee a uniform signal

Author: Fei Wang · Week 1 / Lecture 2 · 2026-9-3· CCBS 2026

One sentence: Even in a one-micrometre compartment, sufficiently rapid signal inactivation can sustain a steep concentration gradient, so cell size alone cannot justify a well-mixed model.

The point I am adding

Lecture 2 asks us to compare the diffusion clock with the reaction clock before assuming uniform concentrations [1]. I want to turn that warning into a quantitative decision: how fast can a signal be removed before its concentration differs by more than 10% across a small compartment?

Imagine an active protein supplied at one boundary and inactivated throughout the interior. Diffusion carries activity inward while inactivation removes it. Increasing the activity of the inactivating enzyme can shorten the signal’s reach without changing the diffusion coefficient. The relevant comparison is between diffusion and loss of the active pool, not simply one enzyme’s turnover time. Spatially separated phosphorylation and dephosphorylation provide a biological precedent for this competition [3].

My claim is therefore conditional: a short absolute diffusion time need not be short enough for the process being modeled. A concentration measured near the source could substantially overestimate exposure elsewhere, even when the compartment is only a micrometre long.

Work it

Use a one-dimensional compartment of length L = 1 µm with constant cross-section. Set D = 7.7 µm² s−1, the reported mean apparent diffusion coefficient of GFP in E. coli under one measured condition [2]. This is a reference mobility, not evidence that GFP undergoes the hypothetical inactivation below. Let c denote active-signal concentration and k its spatially uniform, effective first-order inactivation rate.

∂c/∂t = D ∂²c/∂x² − kc
c(0,t) = c₀  ;  ∂c/∂x(L,t) = 0

The source maintains a fixed positive concentration c₀; the opposite boundary is impermeable. The rates k = 1, 10, and 100 s−1 are illustrative assumptions. For an unsaturated enzyme-mediated loss, an effective k can take the form (kcat/KM)qE, provided the kinetic reduction is valid and enzyme abundance is uniform [1]. Thus k is a pool-loss coefficient, not kcat itself.

At steady state, solving Dc″ − kc = 0 with these boundaries gives:

ℓ = √(D/k)  ;  Da = kL²/D
c(x)/c₀ = cosh[(L − x)/ℓ] / cosh(L/ℓ)
c(L)/c₀ = 1 / cosh(√Da)

Here ℓ is the reaction–diffusion length and Da is the Damköhler number, defined as (L²/D)/(1/k). The characteristic diffusion time is 0.130 s in every case, yet the resulting spatial profiles differ greatly.

Table 1. Original calculations for the same L and D.
k (s−1) 1/k (s) Da ℓ (µm) c(L)/c₀
1 1.00 0.130 2.775 93.84%

100 0.01 12.987 0.277 5.44%

Define “nearly uniform” here as c(x) staying within 10% of c₀ everywhere. Because this profile decreases monotonically, it is enough to require c(L)/c₀ ≥ 0.90. This gives Da ≤ [arcosh(1/0.90)]² = 0.218, or k ≤ 1.68 s−1 for the chosen L and D. Only the first example passes. This bound quantifies spatial variation relative to the source; it is not a universal error bound for every well-mixed model.

Reproduce the calculation — JavaScript

No external libraries are required. The code evaluates an exact steady-state solution rather than a numerical time-stepping simulation. It also generates the coordinates used for the three plotted curves. 

const D = 7.7;       // µm²/s: GFP measurement used as a reference
const L = 1.0;       // µm: assumed compartment length
const rates = [1, 10, 100]; // s⁻¹: hypothetical inactivation rates

function profile(x, k) {
  const lambda = Math.sqrt(D / k);
  return Math.cosh((L - x) / lambda) / Math.cosh(L / lambda);
}

const rows = rates.map(k => ({
  k,
  reactionTime: 1 / k,
  Da: k * L * L / D,
  lambda: Math.sqrt(D / k),
  endPercent: 100 * profile(L, k)
}));

const diffusionTime = L * L / D;
const daLimit = Math.acosh(1 / 0.9) ** 2;
const kLimit = D * daLimit / (L * L);

// The static figure samples this exact profile every 0.005 µm.
const curves = rates.map(k => Array.from({length: 201}, (_, i) => {
  const x = L * i / 200;
  return {x, relativeConcentration: profile(x, k)};
}));

console.table(rows);
console.log({diffusionTime, daLimit, kLimit});

What I would argue against / where this breaks

I would argue against “bacteria are small, therefore their signals are uniform.” However, the calculation does not show that every small cell has a gradient. With a uniform source and a uniform sink, a uniform steady state can exist even at large Da. The localized source is essential to this example.

The quantitative threshold also depends on the geometry and boundary conditions. A fixed-flux source or spherical compartment requires a different solution. Saturation invalidates the linear sink; binding, crowding, and active transport may change mobility or add transport mechanisms. The GFP diffusion coefficient cannot automatically be assigned to another protein. At very low molecule counts, a deterministic concentration profile is only a mean description.

I would test the idea by comparing source-proximal and distant signal levels while changing inactivation capacity and independently checking mobility. A failure to see the predicted gradient would prompt examination of source localization and kinetics, rather than the conclusion that diffusion is always fast enough.
