WEEK 5 — Extension: Integral feedback makes adaptation exact

Author: Weihan Luo · Week 5 (2026-10-19) · CCBS 2026

One sentence: In this simple adaptation model, integral feedback removes the steady error by storing a persistent correction, while the plant’s relaxation makes that memory stable.

The point I am adding

Lecture 10 begins with a deliberately small model. The output error is x, the control action is u, and an external disturbance d stays on. The plant is

ẋ = −x + u + d

The term −x is intrinsic relaxation: left alone, the output returns toward its baseline. With no controller, a constant disturbance leaves a steady error. Proportional feedback improves this but does not solve the problem. If u = −kPx, then the equilibrium is

x* = d/(1 + kP)

Increasing the gain makes the error smaller, but it cannot make the error exactly zero for a nonzero disturbance. The extension in the presentation is to let the controller remember the error rather than react only to the current value. Introduce a memory variable z:

ż = x,    u = −kIz

If the error is positive, the memory keeps increasing; if it is negative, the memory decreases. Once x = 0, the memory stops changing, but it does not need to return to zero. At equilibrium, ż = 0 forces x* = 0. Balancing the plant then gives z* = d/kI. The disturbance has not disappeared: it is stored as a compensating control value in the memory.

That equilibrium calculation is only half a proof. To show that the system actually approaches it, substitute the integral controller into the plant and differentiate. For a constant disturbance,

ẍ + ẋ + kIx = 0

The characteristic roots are

r± = (−1 ± √(1 − 4kI))/2

For every positive kI, both roots have negative real part. Therefore every exponential mode decays. This is where Lecture 9’s discussion of oscillations becomes useful: when kI > 1/4, the roots are complex and the response can overshoot, but the real part remains negative, so the oscillation is damped rather than persistent. If the plant’s relaxation term −x were removed, the equation would become ẍ + kIx = 0; its roots would be purely imaginary and the controller would oscillate forever. Perfect adaptation therefore needs two ingredients: memory to remove the steady error and relaxation to make convergence possible.

Work it

Take a unit step disturbance d = 1, the proportional gain kP = 1, and the integral gain kI = 2. Both systems start at x(0) = z(0) = 0. The proportional controller settles at x = 1/2. The integral controller overshoots because its roots are −1/2 ± i√7/2, but its oscillations decay and its output error returns to zero. For comparison, the same integral controller without intrinsic relaxation has purely imaginary roots and never settles.

Reproduce the figure 
import numpy as np
import matplotlib.pyplot as plt

time = np.linspace(0, 8, 161)
disturbance = 1.0
proportional_gain = 1.0
integral_gain = 2.0
frequency = np.sqrt(integral_gain - 0.25)

proportional_error = disturbance / (1 + proportional_gain) * (
    1 - np.exp(-(1 + proportional_gain) * time)
)
integral_error = (
    disturbance * np.exp(-time / 2) * np.sin(frequency * time) / frequency
)
undamped_error = (
    disturbance * np.sin(np.sqrt(integral_gain) * time) / np.sqrt(integral_gain)
)

figure, axes = plt.subplots(2, 1, sharex=True, figsize=(7, 6))
axes[0].plot(time, integral_error, color="#14897d", label="integral")
axes[0].plot(time, proportional_error, color="#c9536b", label="proportional")
axes[1].plot(time, integral_error, color="#14897d", label="damped")
axes[1].plot(time, undamped_error, "--", color="#c9536b", label="undamped")
for axis in axes:
    axis.axhline(0, color="0.7", lw=0.8)
    axis.legend(loc="lower left", bbox_to_anchor=(0, 1), ncol=2)
    axis.set_ylabel("output error x")
axes[0].set_ylim(-0.15, 0.75)
axes[1].set_ylim(-0.8, 0.8)
axes[1].set_xlabel("time")
figure.tight_layout()
plt.show()

What I would argue against / where this breaks

“Integral feedback always produces perfect adaptation” is too strong. The proof assumes a constant disturbance after the step, a linear first-order plant, no actuator saturation, no delay, and a positive gain. If the disturbance keeps changing, the memory must keep chasing it. If the actuator saturates, the memory can continue accumulating while the plant cannot respond, producing windup. Higher-order plants and delays can also become unstable even when the gain is positive.

The narrower claim is stronger: in this simple model, equilibrium analysis explains why the error must be zero, while the characteristic-root calculation explains when the trajectory reaches that equilibrium. Adaptation is not just a clever controller value; it is a memory whose state stores the persistent correction, stabilized by the plant’s own relaxation.
