Fold-change detection: the front end picks the coordinate, the integral loop keeps it

Leo Sin (施延庆) · Week 5, lectures 9–10 · CCBS 2026 · 19 October 2026

One sentence: When a sensor reports the logarithm of its ligand and an integral loop cancels the sensor's report, the response to a step L → rL is the same at every background L — fold-change detection is not an extra gadget a circuit adds, but the symmetry that appears when the integrator and the sensor live in the same (log) coordinate.

The point I am adding

Lecture 9 listed adaptation among the five behaviors a binding–catalysis circuit computes (its §6, “adaptation comes from high-gain feedback or from opposing input paths”); Lecture 10 opened the loop and asked what chemical object the memory is. It gave three constructions that hold an integral — zero-order removal, an antithetic pair of species, and multiplicative growth, whose logarithm integrates the error exactly while Z > 0 (its §3b and A2) — and spent §5 on the chemotaxis teaching model, where receptor methylation integrates the error of kinase activity: ṁ = VR − VBa/(KB+a), so a rest of the memory forces a back to its reference a*. I want to add one observation about the sensor side and one consequence for the whole loop.

The observation: an allosteric (MWC) receptor in its low-concentration regime reports activity as a logistic in ln L, not in L. Writing the Monod–Wyman–Changeux activity as a(m,L) = (1+L/KI)N / [(1+L/KI)N + eε(m)(1+L/KA)N], the argument of the logistic is a function of ln L alone, and for KI ≪ L ≪ KA it reduces to N·ln L − g·m + const. Keymer et al. call these the two regimes of a two-state receptor.4

The consequence takes two lines. The closed loop ṁ = VR − VBa/(KB+a),  a = logistic(N·ln L − g·m + const) depends on (m, L) only through the combination N·ln L − g·m. Multiplying L by r and shifting m by N·ln r/g leaves that combination unchanged, so every trajectory started from rest superposes: the pulse of kinase activity after a doubling is identical whether the cell sits at 0.1 or at 10. This is exactly the scale-invariance Shoval et al. prove for adapting systems,5 and it is what Lazova et al. measured in E. coli: the response to a step rescales with the background, a property called fold-change detection (FCD).6 The methylation integral itself is the Barkai–Leibler robust-adaptation mechanism,2 read as integral feedback by Yi et al.3

So the answer to "why does the cell sense ratios?" is almost disappointing: the receptor already computes in log-coordinates, and the controller can only cancel what the sensor reports. Lecture 10's A2 made the same point about the memory side — a multiplicative memory integrates in ln Z. FCD is what you get when both sides of the loop agree on the coordinate; the molecular identity of the integral construction is secondary.

Work it

I simulated the teaching model with the MWC front end above (N = 6, KI = 0.01 µM, KA = 100 µM, g = 2; VR = 1, VB = 4, KB = 1, so a* = 1/3), stepping L from L0 to 2L0. As a control I replaced only the front end with a level-sensing logistic of matched local gain (slope 5.881 per e-fold at 1 µM, same methylation coupling, same integral loop). All parameters are illustrative; the numbers below are my RK4 integration (step 0.002 min), not fits to data.

Code that produced Figures 1 and 2 (Python 3, standard library) 
import math

N, KI, KA, g = 6, 1e-2, 1e2, 2.0          # MWC receptor, illustrative
VR, VB, KB = 1.0, 4.0, 1.0                # Barkai-Leibler teaching law
CSTAR = KB*VR/(VB-VR)                     # = 1/3, the rest activity
EPS0 = math.log(2) + g*2.0 - N*math.log((1+1/KI)/(1+1/KA))  # m*(1 uM) = 2
A0 = N*(1/(KI+1) - 1/(KA+1))              # front-end gain at 1 uM: 5.881

def a(m, L, log_front=True):
    if log_front:
        S = N*math.log((1+L/KI)/(1+L/KA)) - g*m + EPS0
    else:
        S = A0*(L-1.0) - g*(m-2.0) + math.log(2)   # same gain, level coordinate
    return 1.0/(1.0+math.exp(max(-40.0, min(40.0, S))))

def mstar(L0, log_front):
    lo, hi = -60.0, 60.0                       # bisection on a = CSTAR
    for _ in range(200):
        mid = 0.5*(lo+hi)
        if a(mid, L0, log_front) < CSTAR: lo = mid
        else: hi = mid
    return 0.5*(lo+hi)

def step(L0, r=2.0, log_front=True, T=40.0, h=0.002):
    m, L = mstar(L0, log_front), L0*r
    out = [(0.0, a(m, L, log_front))]
    for i in range(1, int(T/h)+1):
        f = lambda mm: VR - VB*a(mm, L, log_front)/(KB + a(mm, L, log_front))
        k1 = f(m); k2 = f(m+0.5*h*k1); k3 = f(m+0.5*h*k2); k4 = f(m+h*k3)
        m += h*(k1+2*k2+2*k3+k4)/6
        if i % 100 == 0:
            out.append((i*h, a(m, L, log_front)))
    return out

What I would argue against / where this breaks

Direction of the implication. I showed log-sensing + integral ⇒ FCD. The converse is false, so FCD cannot diagnose integral feedback: an incoherent feedforward loop — no memory at all — can also produce FCD,7 and β-catenin signaling reads fold-changes with no integral loop in the picture.8 My claim is about what the chemotaxis-style architecture guarantees, not about what FCD proves.

The window is finite. The invariance is exact only for KI ≪ L ≪ KA; the crossover "+1" terms break it at the edges. My own numbers show both: the in-window peak spread is ~1.5%, while a doubling below KI gives a pulse five times smaller (Figure 1, dashed). FCD is a regime property, like every other behavior in this course.

A coordinate is also a commitment. A cell that must act on absolute level — osmotic shock, essential-nutrient thresholds — cannot spend this loop on log-coordinates; and a log sensor throws away resolution at high L. The absorbing boundary that A2 warns about for the multiplicative memory (Z = 0 rests anywhere) is the same commitment in another costume: log-coordinates have no zero.
