Week 5 — Extension: The set point is the part an integrator cannot protect

Author: fanglipei · Student ID 20261203497 · Week 5 (2026-10-18) · CCBS 2026

One sentence: An integral memory that makes an output exactly independent of its input also makes it exactly set by its own reference parameters, so perfect adaptation and perfect set-point sensitivity are the same property seen from two sides.

The point I am adding

Lecture 10 builds three chemical memories. A saturated enzyme removes a memory at a nearly constant rate; an antithetic pair stores the difference of two nonnegative totals; a feedforward loop hides an integral in the coordinate x1 − (k1/k2)x2. Each calculation ends with a return level: a* = KBVR/(VB − VR) for receptor methylation, X* = μ/θ for the antithetic controller, and x1* = k1γ/(δk2) with δ = kcat/Kd for the bilinear feedforward loop. The lecture stresses that these levels do not contain the input. It also notes, in one sentence, that changing an enzyme abundance can move the return value while preserving input invariance. I want to take that sentence seriously. The return level is not a detail of the calculation. It is the phenotype the loop defends, and it is the one quantity the loop does not defend against.

The internal model principle says why. A controller that rejects every constant disturbance must contain a model of the constant signal: an integrator driven by the error. In a stable loop, the output then tracks the reference exactly. The same zero that makes the disturbance sensitivity vanish at zero frequency makes the reference gain equal to one: the sensitivity function is 0 at DC, and the complementary sensitivity is 1. A biochemical controller does not receive a separate reference signal; it builds the set point from a parameter combination. The same argument then says that the output is exactly set by that combination. The loop is blind to the plant and perfectly sighted on its own set point. This is not a defect of the antithetic or methylation designs; it is what “perfect adaptation” means. The three architectures differ in which parameters set the return level, not in whether some parameter sets it.

In a cell, those parameters are protein concentrations. CheR, CheB, SigW, RsiW, and the enzymes that make and remove the output all vary from cell to cell. The prediction is therefore sharp: an adapting cell should return to the same activity after every attractant step, while its absolute resting activity varies with its modification enzymes. The lecture’s own numbers show this. Cutting CheR tenfold moves the adapted activity from 1/3 to 0.0175 while the attractant step still returns. Precision is robust; the set point is not. The design lesson is to encode the set point as a ratio. A cell that transcribes the two controller genes from one operon buffers their ratio against copy-number and growth-rate fluctuations. The chemotaxis genes do exactly this: cheR and cheB sit in the same meche operon, the operon uses translational coupling between adjacent genes, and Løvdok and colleagues argue that coupling opposing enzymes buffers the pathway against gene-expression noise.

Work it

Differentiate the methylation set point. Let r = VR/VB, so a* = KBr/(1 − r). The logarithmic sensitivities are

∂ ln a* / ∂ ln VR = 1/(1 − r) = VB/(VB − VR) = 1 + a*/KB,
∂ ln a* / ∂ ln VB = −VB/(VB − VR) = −(1 + a*/KB),    ∂ ln a* / ∂ ln KB = 1.

The first identity is the one to remember: S = 1 + a*/KB. For a fixed KB, a higher operating activity makes the set point more sensitive to CheR. The lecture quotes two activities for the same model: a* = 1/3 at baseline, and a* = 0.0175 after a tenfold CheR cut. Setting VB = 1 and solving the two equations gives VR/VB = 0.5013, KB = 0.3316, and S = 2.005. The two quoted numbers are therefore consistent with a local CheR sensitivity of 2.0. The tenfold cut changes a* by a factor of 19, not 100, because the curve flattens as a* → 0. In the other direction the same formula diverges as a* → 1: from the feasibility condition VB > (1 + KB)VR, the lecture’s operating point has only a 50% upward margin in CheR before the required activity exceeds 1, and at a* = 0.5 with KB = 0.1 the margin is 9%. The set point is fragile in the direction the cell cannot exceed.

The same bookkeeping for the other architectures gives Table 1. The antithetic controller is blind to every plant parameter and has unit sensitivity to μ and θ. The feedforward loop is blind to w but has unit sensitivity to each of k1, γ, δ, and k2. Negative autoregulation, the approximate adapter of Lecture 9, is different: it buffers both its production and its removal by 1/(1 + H), but it never reaches zero error. The integral buys exact disturbance rejection by giving up parameter buffering.

Python code that generated Figure 2 
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp
from scipy.optimize import brentq

plt.rcParams.update({
    "font.family": "DejaVu Sans",
    "font.size": 9,
    "axes.spines.top": False,
    "axes.spines.right": False,
    "svg.fonttype": "none",
})

# ---- reduced methylation model (Lecture 10, eq. E2) ----
M0, W, BETA, KI = 2.0, 0.15, 0.5, 1.0
def activity(m, L):
    m_half = M0 + BETA*np.log1p(np.asarray(L)/KI)
    return 1.0/(1.0 + np.exp(-(np.asarray(m) - m_half)/W))

def simulate(VR, VB=1.0, KB=0.1, t_step=5.0, t_end=20.0):
    a_star = KB*VR/(VB - VR)
    m0 = M0 + W*np.log(a_star/(1.0-a_star))
    def rhs(t, y):
        L = 0.0 if t < t_step else 5.0
        a = activity(y[0], L)
        return [VR - VB*a/(KB + a)]
    t = np.linspace(0.0, t_end, 3000)
    sol = solve_ivp(rhs, (0.0, t_end), [m0], t_eval=t, rtol=1e-10, atol=1e-12)
    L = np.where(t < t_step, 0.0, 5.0)
    return t, activity(sol.y[0], L), a_star

# ---- recover the lecture's parameters from its two quoted activities ----
# a*(VR)=1/3, a*(VR/10)=0.0175, with VB=1
ratio = 10.0
a1, a2 = 1.0/3.0, 0.0175
r = brentq(lambda r: (1.0/ratio)*(1.0-r)/(1.0-r/ratio) - a2/a1, 1e-9, 1-1e-9)
KB_lecture = a1*(1.0-r)/r
S_lecture = 1.0 + a1/KB_lecture
print(f"lecture fit: VR/VB={r:.6f}, KB={KB_lecture:.6f}, S={S_lecture:.4f}")
margin = lambda a, KB: KB*(1.0-a)/(a*(1.0+KB))
print(f"upward CheR margin at a*=1/3: {margin(a1, KB_lecture):.3%}; at a*=0.5, KB=0.1: {margin(0.5, 0.1):.1%}")

# ---- figure ----
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10.2, 3.7))

for VR, color, label in [(0.50, "#1f4e79", r"$V_R=0.50$"),
                         (0.75, "#c0504d", r"$V_R=0.75$")]:
    t, a, a_star = simulate(VR)
    ax1.plot(t, a, color=color, lw=1.8, label=label + rf", $a^*={a_star:.2f}$")
    ax1.hlines(a_star, 5.0, 20.0, color=color, lw=0.8, ls=(0, (4, 3)), alpha=0.75)

ax1.axvline(5.0, color="#777777", lw=0.9, ls=":")
ax1.text(5.25, 0.92, "attractant step\n$L: 0 \\rightarrow 5K_I$", fontsize=8, va="top")
ax1.set_xlabel("time (units of $1/V_B$)")
ax1.set_ylabel("receptor activity $a$")
ax1.set_xlim(0, 20)
ax1.set_ylim(-0.02, 1.02)
ax1.legend(frameon=False, fontsize=7.5, loc="center right")
ax1.set_title("(a) each cell adapts to its own set point", fontsize=9.5, loc="left")

a_grid = np.linspace(0.01, 0.95, 400)
for KB, color, ls in [(0.05, "#4f81bd", "-"),
                      (0.10, "#9bbb59", "-"),

             label=rf"$K_B={KB:.3g}$")

What I would argue against / where this breaks

The strongest objection is that the set point may not be the property the cell selects. Alon and colleagues varied chemotaxis protein levels and found that steady-state behavior and adaptation time changed strongly while precision stayed robust. That is exactly the pattern I describe, but it also shows that the cell tolerates a moving set point. Chemotaxis may care about the precision of the return and the motor’s operating range, not about a fixed absolute activity. The calculation is a structural statement, not evidence of selection.

The local sensitivity is not the whole story. Near the feasibility boundary the finite change can be larger than the local slope suggests, and the asymmetry matters. A bounded methylation range makes the failure concrete: once the required methylation exceeds the available sites, the activity cannot return. Set-point sensitivity and adaptation range are coupled. Co-expression also buffers only the shared component of the noise. Translational coupling reduces the variance of the ratio, but it does not remove independent noise in ribosomes, proteases, or the shared mRNA. And the methylation set point depends on KB as well as on VR and VB, and it is limited by the receptor total through the available methylation sites; co-expressing CheR and CheB does not buffer those. The antithetic reference μ could be stabilized by a second feedback loop, but that adds a layer and moves the same problem to the new reference. The claim is about the module, not about the whole cell.
