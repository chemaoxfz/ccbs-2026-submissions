Week 5 — Extension: When can a biochemical oscillator follow an external clock?

Author: Chengwei Jin · Week 5 (2026-10-18) · CCBS 2026

One sentence: A stable autonomous rhythm can fail as an environmental clock when phase correction is weaker than frequency mismatch.

The point I am adding

Lecture 9, §7 explains how a repression ring sustains an autonomous cycle.1 My extension asks a different question: can an oscillator keep a fixed phase relationship with a periodic environment? Mondragón-Palomino and colleagues tested this by periodically varying arabinose around synthetic genetic oscillators and tracking single-cell phases.2 I use an illustrative phase model to calculate a locking range. This is not a fit to their data or a reduction derived from the lecture's specific ring.

Work it

Let θ be oscillator phase and Ωt the phase of an external drive. Their difference is ψ=θ−Ωt. If ω is the natural angular frequency, the mismatch is Δω=ω−Ω. Assume weak forcing near 1:1 resonance, with a sinusoidal phase correction:

dψ/dt = Δω − K sinψ.

Time is in minutes and phase in radians. The positive constant K is the maximum correction rate, in rad min−1. A fixed phase requires sinψ*=Δω/K. Thus |Δω|<K gives a stable branch ψ*=arcsin(Δω/K), because the local slope −K cosψ* is negative. At equality that restoring slope vanishes.

Choose a natural period of 60 min and K=0.010 rad min−1. Since Ω=2π/Tdrive, stable locking requires 54.77<Tdrive<66.33 min. At Δω=0.006 rad min−1, the simulation approaches a fixed phase difference of 36.87°. Increasing the mismatch to 0.014 rad min−1 removes the fixed point. The phase then advances by one full cycle every 641.27 min, calculated from

Tslip = ∫02π dψ/(Δω−K sinψ)
= 2π/√(Δω²−K²), for Δω>K.

This is the time to gain one cycle relative to the drive, not the oscillator's own period. A continuing rhythm can therefore lose synchronization.

Reproduce the calculation and figure

Save the following complete Python code as reproduce.py and run python reproduce.py. Requires NumPy and SciPy. It writes the values, trajectories and SVG beside the script. Numerical integration is checked against the fixed phase and analytical slip period.

"""Reproduce the illustrative Week 5 phase model, checks, and inline-SVG data.
Run: python reproduce.py. Requires numpy and scipy.
Outputs are created beside this script. Parameters are not fitted to a circuit.
"""
from pathlib import Path
import json
import math
import numpy as np
from scipy.integrate import solve_ivp, quad

OUT = Path(__file__).resolve().parent
K = 0.010  # rad/min: maximum phase correction rate in this model
omega = 2 * math.pi / 60  # rad/min: illustrative natural frequency
times = np.linspace(0, 3000, 1201)
curves = []
for mismatch in (0.006, 0.014):
    sol = solve_ivp(
        lambda t, p: [mismatch - K * np.sin(p[0])],
        (0, 6000), [0.2], dense_output=True,
        rtol=1e-10, atol=1e-12, max_step=2,
    )
    assert sol.success
    curves.append(sol.sol(times)[0] / (2 * math.pi))
    if mismatch < K:
        phase = math.asin(mismatch / K)
        phase_error = abs(sol.y[0, -1] - phase)
        assert phase_error < 1e-8

slip_exact = 2 * math.pi / math.sqrt(0.014**2 - K**2)
slip_quad = quad(lambda p: 1 / (0.014 - K * np.sin(p)),
                 0, 2 * math.pi, epsabs=1e-10)[0]
def revolution(t, p):
    return p[0] - 2 * math.pi
revolution.terminal = True
revolution.direction = 1
slip_sol = solve_ivp(lambda t, p: [0.014 - K * np.sin(p[0])],
                     (0, 1000), [0.0], events=revolution,
                     rtol=1e-10, atol=1e-12, max_step=1)
slip_event = float(slip_sol.t_events[0][0])
assert abs(slip_quad - slip_exact) < 1e-8
assert abs(slip_event - slip_exact) < 1e-6

results = {
    "natural_period_min": 60,
    "K_rad_per_min": K,
    "initial_phase_rad": 0.2,
    "strict_locking_period_min": [2*math.pi/(omega+K), 2*math.pi/(omega-K)],
    "locked_phase_deg_at_detuning_0.006": phase*180/math.pi,
    "slip_period_min_at_detuning_0.014": slip_exact,
    "checks": {"locked_phase_error_rad": phase_error,
               "quadrature_error_min": abs(slip_quad-slip_exact),
               "ODE_event_error_min": abs(slip_event-slip_exact)},
    "interpretation": "Illustrative phase model; not an experimental fit or a reduction derived from Lecture 9's circuit."
}
(OUT/'results.json').write_text(json.dumps(results, indent=2), encoding='utf-8')
np.savetxt(OUT/'trajectories.csv', np.column_stack([times, *curves]),
           delimiter=',', header='time_min,locked_phase_cycles,slipping_phase_cycles', comments='')

# A single common scale makes persistent phase drift visible.
W, H = 720, 350
left, right, top, bottom = 78, 46, 55, 62
X = lambda x: left + x/3000*(W-left-right)
Y = lambda y: H-bottom-y/5*(H-top-bottom)
parts = ['<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 720 350" role="img" aria-label="Relative phase stays bounded when locked and repeatedly advances when slipping">',
         '<g font-family="Arial,sans-serif" font-size="13" fill="var(--fg,#20201e)">']
for x in (0, 750, 1500, 2250, 3000):
    parts += [f'<line x1="{X(x):.2f}" y1="{top}" x2="{X(x):.2f}" y2="{H-bottom}" stroke="var(--gridc,#ede7e0)"/>',
              f'<text x="{X(x):.2f}" y="{H-bottom+25}" text-anchor="middle">{x}</text>']
for y in (0, 1, 2, 3, 4, 5):
    parts += [f'<line x1="{left}" y1="{Y(y):.2f}" x2="{W-right}" y2="{Y(y):.2f}" stroke="var(--gridc,#ede7e0)"/>',
              f'<text x="{left-10}" y="{Y(y)+4:.2f}" text-anchor="end">{y}</text>']
parts += [f'<path d="M{left},{top}V{H-bottom}H{W-right}" fill="none" stroke="var(--fg,#20201e)"/>',
          '<text x="376" y="338" text-anchor="middle">time (min)</text>',
          '<text x="78" y="20">unwrapped relative phase (cycles)</text>']
for i, (curve, label, color) in enumerate(zip(curves,
        ('locked: Δω = 0.006', 'slipping: Δω = 0.014'),
        ('var(--rose,#d75567)', 'var(--peri,#5a73ce)'))):
    pts = ' '.join(f'{X(t):.2f},{Y(y):.2f}' for t, y in zip(times, curve))
    lx = left + 260*i
    parts += [f'<polyline points="{pts}" fill="none" stroke="{color}" stroke-width="2.6"/>',
              f'<line x1="{lx}" y1="37" x2="{lx+20}" y2="37" stroke="{color}" stroke-width="3"/>',
              f'<text x="{lx+27}" y="41" font-size="12">{label}</text>']
parts.append('</g></svg>')
(OUT/'phase-locking.svg').write_text('\n'.join(parts), encoding='utf-8')
print(json.dumps(results, indent=2))

What I would argue against / where this breaks

This model assumes a stable underlying cycle whose amplitude recovers rapidly compared with changes in relative phase. It omits strong forcing, intrinsic noise and cell-to-cell variation. The experiment also shows higher-order locking and heterogeneous responses,2 which this deterministic, single-harmonic model does not reproduce. A useful test is to sweep the forcing period and track each cell's unwrapped relative phase. Population fluorescence peaks alone could conceal cells that still drift. Autonomous oscillation and entrainment should therefore be tested separately.
