Sampling faster, more derivative noise?

Author: Zheng Haobo · Week 5 (2026-10-19) · CCBS 2026

One sentence: For independent, equal-variance additive measurement noise, a finite-difference derivative has noise SD √2σ/Δt, so halving the sampling interval doubles that SD.

The point I am adding

Derivative action reads how quickly an error changes [2]. Let a measured sample be x[n] = s[n] + ε[n], where s[n] is the underlying signal and ε[n] is additive measurement error; samples are spaced by Δt. The forward difference (x[n+1] − x[n])/Δt therefore contains the noise term (ε[n+1] − ε[n])/Δt.

Assume the errors have mean zero, common variance σ², and are independent across samples. This is a modeling assumption, not a measured conclusion about noise in cells. Independence makes the covariance zero, so:

Var[(ε[n+1] − ε[n])/Δt] = (σ² + σ²)/Δt² = 2σ²/Δt²

Taking the square root gives SD = √2σ/Δt. This exact result follows from the stated model; more generally, numerical differentiation can magnify a small, rapidly varying perturbation [1].

Work it

Set σ = 0.01 arbitrary signal units (a.u.) and Δt in seconds. Theory gives log(SD) = log(√2σ) − log(Δt), hence slope −1. Gaussian Monte Carlo is an in-model numerical check, not a proof or sensor test; the law does not require Gaussian noise.

"""Calculate derivative-noise theory, check it by Monte Carlo, and plot both."""

import math
import random

SIGMA = 0.01
SAMPLE_INTERVALS = (1.0, 0.5, 0.25)
SEEDS = (20261016, 20261017, 20261018)
TRAJECTORIES = 100
SAMPLES_PER_TRAJECTORY = 1001
SQRT_TWO = math.sqrt(2.0)


def monte_carlo():
    """Return (interval, seed, pooled RMS SD, relative error) for each group.

    Each interval gets fresh Gaussian draws from its own fixed-seed generator.
    Gaussian noise is an example, not a requirement of the analytic law.
    Known zero mean allows sqrt(mean(d**2)); pool equal-length trajectories
    by averaging their mean squares before taking the square root.
    Neighboring differences share a sample: no independent-observation CI.
    """
    rows = []
    for (dt, _, theory_sd), seed in zip(calculate(), SEEDS, strict=True):
        rng = random.Random(seed)
        mean_squares = []
        for _ in range(TRAJECTORIES):
            noise = [rng.gauss(0.0, SIGMA) for _ in range(SAMPLES_PER_TRAJECTORY)]
            differences = [(later - earlier) / dt for earlier, later in zip(noise, noise[1:])]
            mean_squares.append(math.fsum(d * d for d in differences) / len(differences))
        sd = math.sqrt(math.fsum(mean_squares) / TRAJECTORIES)
        rows.append((dt, seed, sd, sd / theory_sd - 1.0))
    return rows


def doubling_ratios(mc_rows):
    """Use unrounded group SDs for successive interval-halving ratios."""
    return [later[2] / earlier[2] for earlier, later in zip(mc_rows, mc_rows[1:])]


def rho_scale(rho=0.5):
    """Conditional covariance-model SD ratio; no correlated-noise simulation."""
    return math.sqrt(1.0 - rho)


def calculate():
    """Return (interval, variance, standard deviation) in model units."""
    return [
        (dt, 2.0 * SIGMA**2 / dt**2, SQRT_TWO * SIGMA / dt)
        for dt in SAMPLE_INTERVALS
    ]


def loglog_slope(rows):
    """Fit log10(standard deviation) against log10(sampling interval)."""
    xs = [math.log10(dt) for dt, _, _ in rows]
    ys = [math.log10(sd) for _, _, sd in rows]
    x_mean = sum(xs) / len(xs)
    y_mean = sum(ys) / len(ys)
    numerator = sum((x - x_mean) * (y - y_mean) for x, y in zip(xs, ys))
    denominator = sum((x - x_mean) ** 2 for x in xs)
    return numerator / denominator


def render_svg(rows, mc_rows):
    """Keep the exact curve, add true-scale MC squares and an exact-law step."""
    width, height = 760, 300
    left, right, top, bottom = 86.0, 728.0, 42.0, 220.0
    x_min, x_max = 0.25, 1.0
    y_min, y_max = 0.01, 0.1
    log_x_span = math.log10(x_max) - math.log10(x_min)
    log_y_span = math.log10(y_max) - math.log10(y_min)

    def map_x(dt):
        fraction = (math.log10(dt) - math.log10(x_min)) / log_x_span
        return left + fraction * (right - left)

    def map_y(value):
        fraction = (math.log10(y_max) - math.log10(value)) / log_y_span
        return top + fraction * (bottom - top)

    def text(x, y, value, *, size=13, fill="var(--ink)", anchor="middle", weight="400"):
        return (
            f'<text x="{x:.2f}" y="{y:.2f}" text-anchor="{anchor}" '
            f'font-size="{size}" font-weight="{weight}" fill="{fill}" '
            f'font-family="var(--sans)">{value}</text>'
        )

    parts = [
        f'<svg class="fig" viewBox="0 0 {width} {height}" xmlns="http://www.w3.org/2000/svg" '
        'role="img" aria-labelledby="plot-title plot-desc">',
        '<title id="plot-title">Derivative-noise standard deviation versus sampling interval</title>',
        '<desc id="plot-desc">The analytic log–log line is square root of two times sigma divided by the sampling interval, with slope minus one. The step marks exact halving of the interval and doubling of SD on that line. Three unconnected squares are independent Monte Carlo estimates, plotted without magnifying their deviations. All values are model calculations, not sensor measurements.</desc>',
        '<defs><marker id="step-arrow" viewBox="0 0 6 6" refX="5" refY="3" '
        'markerWidth="6" markerHeight="6" orient="auto">'
        '<path d="M 0,0 L 6,3 L 0,6" fill="none" stroke="var(--accent)" stroke-width="1" />'
        '</marker></defs>',
        text(left, 24, "Derivative-noise SD (a.u./s)", size=15, anchor="start", weight="650"),
    ]

    for tick in (0.01, 0.02, 0.05, 0.1):
        y = map_y(tick)
        parts.append(
            f'<line x1="{left:.2f}" y1="{y:.2f}" x2="{right:.2f}" y2="{y:.2f}" '
            'stroke="var(--gridc)" stroke-width="1" />'
        )
        parts.append(text(left - 12, y + 4, f"{tick:g}", size=12, fill="var(--muted)", anchor="end"))

    for tick in (0.25, 0.5, 1.0):
        x = map_x(tick)
        parts.append(
            f'<line x1="{x:.2f}" y1="{top:.2f}" x2="{x:.2f}" y2="{bottom:.2f}" '
            'stroke="var(--gridc)" stroke-width="1" />'
        )
        parts.append(
            f'<line x1="{x:.2f}" y1="{bottom:.2f}" x2="{x:.2f}" y2="{bottom + 5:.2f}" '
            'stroke="var(--muted)" stroke-width="1.2" />'
        )
        parts.append(text(x, bottom + 22, f"{tick:g}", size=12, fill="var(--muted)"))

    parts.extend([
        f'<line x1="{left:.2f}" y1="{top:.2f}" x2="{left:.2f}" y2="{bottom:.2f}" '
        'stroke="var(--muted)" stroke-width="1.3" />',
        f'<line x1="{left:.2f}" y1="{bottom:.2f}" x2="{right:.2f}" y2="{bottom:.2f}" '
        'stroke="var(--muted)" stroke-width="1.3" />',
    ])

    curve = []
    point_count = 101
    for index in range(point_count):
        fraction = index / (point_count - 1)
        dt = x_min * (x_max / x_min) ** fraction
        sd = SQRT_TWO * SIGMA / dt
        curve.append((map_x(dt), map_y(sd)))
    path_data = " ".join(
        ("M" if index == 0 else "L") + f" {x:.2f},{y:.2f}"
        for index, (x, y) in enumerate(curve)
    )
    parts.append(
        f'<path d="{path_data}" fill="none" stroke="var(--peri)" stroke-width="3.5" '
        'stroke-linecap="round" stroke-linejoin="round" />'
    )
    parts.append(text(right - 7, top + 18, "log–log slope = −1", size=13, fill="var(--accent)", anchor="end", weight="650"))

    theory = {dt: sd for dt, _, sd in rows}
    x_start, x_half = map_x(1.0), map_x(0.5)
    y_start, y_double = map_y(theory[1.0]), map_y(theory[0.5])
    parts.extend([
        f'<line x1="{x_start:.2f}" y1="{y_start:.2f}" x2="{x_half:.2f}" y2="{y_start:.2f}" '
        'stroke="var(--accent)" stroke-width="1.5" marker-end="url(#step-arrow)" />',
        f'<line x1="{x_half:.2f}" y1="{y_start:.2f}" x2="{x_half:.2f}" y2="{y_double:.2f}" '
        'stroke="var(--accent)" stroke-width="1.5" marker-end="url(#step-arrow)" />',
        text((x_start + x_half) / 2, y_start + 20, "Δt ÷ 2", size=13, fill="var(--accent)", weight="650"),
        text(x_half - 12, (y_start + y_double) / 2 + 4, "SD × 2", size=13, fill="var(--accent)", anchor="end", weight="650"),
    ])

    for dt, _, sd, _ in sorted(mc_rows, key=lambda row: row[0]):
        x, y = map_x(dt), map_y(sd)
        parts.append(
            f'<rect x="{x - 5.4:.2f}" y="{y - 5.4:.2f}" width="10.8" height="10.8" '
            'fill="var(--bg)" stroke="var(--accent)" stroke-width="2.8" />'
        )

    parts.extend([
        text((left + right) / 2, 286, "Sampling interval, Δt (s)", size=13, fill="var(--ink)"),
        "</svg>",
    ])
    return "\n".join(parts)


def main():
    rows = calculate()
    mc_rows = monte_carlo()
    print("Assumption: independent, equal-variance additive measurement errors")
    print(f"sigma = {SIGMA:.6f} a.u.; derivative-noise units = a.u./s")
    print("Theory: dt_s variance_(a.u./s)^2 SD_(a.u./s)")
    for dt, variance, sd in rows:
        print(f"{dt:g} {variance:.8f} {sd:.17g}")
    print(f"least-squares log10(SD) vs log10(dt) slope = {loglog_slope(rows):.12f}")
    print(f"MC: {TRAJECTORIES} trajectories x {SAMPLES_PER_TRAJECTORY} independent N(0, sigma^2) samples per dt")
    print("Known-zero-mean pooled RMS; shared-sample differences are not independent; no CI")
    print("dt_s seed MC_SD_(a.u./s) relative_error_percent")
    for dt, seed, sd, relative_error in mc_rows:
        print(f"{dt:g} {seed} {sd:.17g} {100.0 * relative_error:+.12f}")
    for earlier, later, ratio in zip(mc_rows, mc_rows[1:], doubling_ratios(mc_rows)):
        print(f"MC doubling ratio {earlier[0]:g} -> {later[0]:g} s = {ratio:.17g}; exact = 2")
    rho = 0.5
    print(f"rho = {rho:g}: sqrt(1-rho) = {rho_scale(rho):.17g}; increment variance = {2 * SIGMA**2 * (1 - rho):.8f}")
    print(f"Fixed-rho SD = sigma/dt = {SIGMA:.8f} a.u./s at dt = 1 s; exact doubling ratio = 2")
    print("Monte Carlo is an in-model numerical check, not proof or sensor validation")


if __name__ == "__main__":
    main()

What I would argue against / where this breaks

If adjacent errors have variance σ² and Cov(ε[n+1], ε[n]) = ρσ², then Var(ε[n+1] − ε[n]) = 2σ²(1 − ρ). Fixed ρ = 1/2 gives derivative-noise SD = σ/Δt, or √(1 − ρ) ≈ 0.707 times the independent SD; halving Δt still doubles it. If ρ varies with Δt, the log–log slope need not be −1. This is conditional on the covariance model, not a sensor fact. Real or filtered measurements require their post-measurement covariance; none was measured here. The plotted law assumes independent, equal-variance errors.
