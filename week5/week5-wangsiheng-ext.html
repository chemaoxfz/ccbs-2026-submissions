Week 05 · Feedback & adaptation

A short read + an experiment

When memory fades,
adaptation drifts.

A small leak in an integral controller turns perfect adaptation into a measurable error budget.

The point I am adding

In this minimal model, keeping the residual at or below 5% requires a memory leak no greater than one nineteenth of the integral gain.

Author: Siheng WangLectures 9–1016 October 2026

01

Let the memory forget.

An integral controller can retain a corrective action after an output returns to its target.[1] But a memory encoded in molecular concentrations can fade through dilution or degradation.[2] Add one leak term to a two-state feedback model, then ask a practical question: how little forgetting is little enough?

Output dynamics

dx/dt = d − x − z

Memory dynamics

dz/dt = kx − λz

x: signed output error · z: stored corrective action · d: disturbance.
k > 0 accumulates error; λ ≥ 0 erases memory. All quantities and time are dimensionless; the plant relaxation rate is scaled to 1. These are deviation variables, not molecular concentrations.

02

Same disturbance. Different return.

Apply a unit step at t = 2 and keep it on. Change the leak, then try a stronger integral gain.

03

Turn “almost perfect” into a number.

At rest, the equations require z* = 1 − x* and kx* = λz*. Therefore x* = λ/(k + λ). When λ = 0, memory can hold the full action at zero error. When λ > 0, a persistent error must keep replenishing what is lost. With k = 0.5 and λ = 0.15, the exact residual is 0.15/0.65 ≈ 23.1% of the unit disturbance.

Requiring x* ≤ 0.05 gives a concrete design rule. At k = 0.5, λ must be at most 0.0263: the unforced memory half-life must be at least 26.34 scaled time units. These numbers follow from this model, not from a measured cell.

A 5% steady-state budget
λ / (k + λ) ≤ 0.05
⇔ λ ≤ k / 19

Equivalently, for λ > 0:
unforced half-life ≥ 19 ln(2) / k.
The useful quantity is the leak relative to the gain, under the stated normalization.

Where this breaks. This is a linear, deterministic deviation model with constant disturbance, unlimited corrective action and no sensing delay. Its characteristic polynomial, s² + (1 + λ)s + (k + λ), is stable for k > 0 and λ ≥ 0, so the calculated equilibrium is reached. That does not establish stability or chemical feasibility for a molecular circuit. Dilution motivates the leak; it need not change only this one term in a real cell. Qian and Del Vecchio analyze how sufficiently fast controller reactions can mitigate dilution under additional assumptions;[2] increasing this toy model’s k alone is not a general biological design prescription.
