Why faster growth can mean
less biomass harvest

Author: Siheng Wang · Week 7 (2026-10-30) · Lectures 13–14

One sentence: In a chemostat with fixed feed concentration, the dilution rate that maximizes biomass harvested per hour is below the washout threshold, because faster-growing cells can be offset by fewer cells in the vessel.

The point I am adding

Lecture 14 shows that a nonzero steady chemostat satisfies λ(c*) = D: cellular growth replaces biomass carried out by the flow.[1] I change the objective from how fast cells grow to how much biomass we collect. For a fixed vessel volume, the relevant quantity is P = DX*, the biomass harvested per unit vessel volume per hour. Increasing D improves one factor while potentially reducing the other.

Work it

Keep the lecture’s Monod model and constant biomass yield Y.[1][2] Here c is residual substrate concentration, cin is feed concentration, K is the half-saturation concentration, and X is biomass concentration. On the positive steady-state branch,

λ(c)=λmaxcK+c,c*=KDλmax−D,X*=Y(cin−c*) 0<D<Dwash=λmaxcinK+cin.

Substitution gives P(D) = YD[cin − KD/(λmax − D)]. My extension is to optimize this expression. Setting its derivative to zero gives an interior maximum:

Dopt=λmax(1−KK+cin)<Dwash.
Check the derivative and the maximum

Write L = λmax. Then P/Y = D(cin + K) − KLD/(L − D), so

P′Y=cin+K−KL2(L−D)2,P″=−2YKL2(L−D)3<0.

Thus the stationary point is the unique maximum on the positive branch. For q = K/(K + cin) in (0, 1), √q > q, hence Dopt = L(1 − √q) < L(1 − q) = Dwash.

λmax = 1h⁻¹
K = 1g substrate / L
cin = 9g substrate / L
Y = 0.5g biomass / g substrate

Chosen for illustration; these values are not experimental measurements.

Reproduce the figure and numbers · complete Python code

Requires Python 3, NumPy and Matplotlib. Running this script prints the results and creates chemostat.svg and chemostat.png. The figure above is already embedded in this file; opening the page requires no packages or network connection.

"""Original model calculation for week7-wangsiheng-ext.html.
Requires numpy and matplotlib. Run with Python 3.
All parameters are illustrative, not fitted to an organism.
"""
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

L, K, c_in, Y = 1.0, 1.0, 9.0, 0.5
# L: h^-1; K, c_in: g substrate/L; Y: g biomass/g substrate.
D_w = L * c_in / (K + c_in)
D_opt = L * (1 - np.sqrt(K / (K + c_in)))

def steady(D):
    c = K * D / (L - D)
    X = Y * (c_in - c)
    return X, D * X

# D=0 is only a right-hand limit; it is not a selected steady culture.
D = np.linspace(0.0001, D_w, 1001)
X, P = steady(D)
X_opt, P_opt = steady(D_opt)
X_fast, P_fast = steady(0.85)
print(f"D_opt={D_opt:.6f}, D_w={D_w:.6f}")
print(f"At optimum: X={X_opt:.6f}, P={P_opt:.6f}")
print(f"At D=0.85: X={X_fast:.6f}, P={P_fast:.6f}")
print(f"Harvest decrease: {100 * (1 - P_fast / P_opt):.2f}%")

plt.rcParams.update({"font.family": "DejaVu Sans", "font.size": 10,
                     "svg.fonttype": "path", "axes.spines.top": False,
                     "axes.spines.right": False, "axes.labelcolor": "#263f4b",
                     "xtick.color": "#526570", "ytick.color": "#526570"})
fig, axes = plt.subplots(2, 1, figsize=(7.6, 5.8), sharex=True,
                         layout="constrained")
teal, blue, coral = "#137b72", "#245e8e", "#b64e38"
for ax, values, color, title, ylabel, ymax in zip(
    axes, [X, P], [blue, teal],
    ["A   Less biomass remains as flow increases", "B   Harvest peaks before washout"],
    ["Biomass X* (g/L)", "Harvest P (g/L/h)"], [5.2, 3.0]
):
    ax.plot(D, values, color=color, lw=2.7)
    ax.fill_between(D, 0, values, color=color, alpha=0.06)
    ax.axvline(D_opt, color=teal, ls=(0, (4, 3)), lw=1.2)
    ax.axvline(D_w, color="#73818b", ls=(0, (2, 3)), lw=1.2)
    ax.set(xlim=(0, 0.96), ylim=(0, ymax), ylabel=ylabel)
    ax.set_title(title, loc="left", fontsize=11, weight="bold", pad=12)
    ax.grid(axis="y", alpha=0.15)
    ax.set_axisbelow(True)
    ax.spines["left"].set_color("#acb8bf")
    ax.spines["bottom"].set_color("#acb8bf")
axes[0].text(D_opt - .018, 4.78, "Best harvest\nD = 0.684", color=teal,
             ha="right", va="top", fontsize=9)
axes[0].text(D_w - .015, 4.78, "Washout\nD = 0.900", color="#526570",
             ha="right", va="top", fontsize=9)
axes[0].scatter([D_opt, .85], [X_opt, X_fast], color=[teal, coral], zorder=4)
axes[1].scatter([D_opt, .85], [P_opt, P_fast], color=[teal, coral], zorder=4)
axes[1].annotate("Maximum: 2.338", (D_opt, P_opt), xytext=(.34, 2.60),
                 color=teal, arrowprops={"arrowstyle": "-", "color": teal})
axes[1].annotate("Faster growth,\n39.4% less harvest", (.85, P_fast),
                 xytext=(.37, .62), color=coral,
                 arrowprops={"arrowstyle": "-", "color": coral})
axes[1].set_xlabel("Dilution rate D (h⁻¹); specific growth equals D on the positive branch")
fig.savefig("chemostat.svg", metadata={"Date": None})
fig.savefig("chemostat.png", dpi=160)

With these parameters, increasing D from 0.684 to 0.850 h⁻¹ raises the surviving culture’s specific growth rate by about 24%, yet reduces biomass harvest by 39.4%. The residual substrate rises from 2.162 to 5.667 g/L: more incoming substrate leaves unused, while biomass concentration falls. Near washout, growth of each unit of biomass is fast, but almost no biomass remains to harvest. These are model calculations, not measured outcomes.

What I would argue against / where this breaks

I would reject “maximize the specific growth rate” as a complete production objective. The formula optimizes steady biomass output at fixed feed concentration and vessel volume; it does not optimize profit or a secreted product. It assumes sterile feed, perfect mixing, constant volume and yield, Monod kinetics, and no maintenance, death or cell retention. Changing these assumptions can move the optimum. Start-up time and uncertainty in the washout boundary are also absent. The transferable lesson is to define the collected output before choosing which rate to maximize.
