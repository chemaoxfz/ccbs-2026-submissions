WEEK 7 — Extension: Growth, investment and delayed reward

Author: Weihan Luo · Week 7 (2026-11-03) · CCBS 2026

One sentence: When building productive machinery sacrifices present growth, uncertainty about how long nutrients will last can reverse the best investment decision—a tradeoff expressible through the same future-value calculation used in reinforcement learning.

The point I am adding

A cell needs machinery to grow: enzymes process nutrients, and ribosomes make proteins, including more machinery. Lecture 14, Section 11, treats resource allocation as productive investment. Lecture 13, Sections 23–24, shows how a growth objective can select different allocations when the future horizon changes [1][2]. My question is slightly different: what if the nutrient episode has no known end? An investment can increase future growth yet be a poor choice if its payoff rarely arrives.

Consider my deliberately simplified two-state model. The initial state has low productive capacity. During each equal-length interval, the cell can grow, multiplying biomass by 1.2 and keeping that capacity, or invest, forgoing net biomass growth for one interval to reorganize its machinery. Investment permanently changes the growth multiplier to 1.3 for subsequent intervals of the episode. These are illustrative choices, not measured cellular rates or a biochemical mass-balance model.

After every completed interval, nutrients remain available with probability p, independently of the action and previous history. Otherwise growth stops, with existing biomass retained and no later reward. Let reward be the log biomass increase: r = ln(Bnext/B). Summing rewards gives total log growth. A reward t intervals ahead is received with probability pt; continuation therefore has the same mathematical role as the RL discount factor, γ = p. Here that factor comes from an explicit environmental assumption.

Work it

Write r0 = ln(1.2) and r1 = ln(1.3). The optimal values VL and VH are the expected remaining log growth from low and high capacity, respectively. They obey the Bellman equations:

VH=r1+pVH VL=max{ r0+pVL, pVH}

The first low-state choice collects growth immediately; the second collects zero now and gains high capacity for later. Growing leaves both the state and continuation probability unchanged, so waiting supplies no new information. Solving the equations selects between growing forever and investing immediately. Their expected log returns are

Jgrow= r01−p , Jinvest= pr11−p

Investment wins precisely when p > ln(1.2)/ln(1.3) ≈ 0.695. Nothing about the machinery changed: only the probability of reaching its payoff changed. For two example environments, my calculation gives:

Reproduce the figure and Bellman check (Python, NumPy and Matplotlib) 
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

low_multiplier = 1.2
high_multiplier = 1.3
low_reward = np.log(low_multiplier)
high_reward = np.log(high_multiplier)
threshold = low_reward / high_reward

def rollout(invest, intervals=10):
    biomass = [1.0]
    upgraded = False
    for interval in range(intervals):
        if invest and interval == 0:
            multiplier = 1.0
            upgraded = True
        else:
            multiplier = high_multiplier if upgraded else low_multiplier
        biomass.append(biomass[-1] * multiplier)
    return np.array(biomass)

def bellman(continuation):
    value = np.zeros(2)
    for iteration in range(10000):
        grow_value = low_reward + continuation * value[0]
        invest_value = continuation * value[1]
        updated = np.array([
            max(grow_value, invest_value),
            high_reward + continuation * value[1],
        ])
        if np.max(np.abs(updated - value)) < 1e-13:
            return updated
        value = updated
    raise RuntimeError("Value iteration did not converge")

probabilities = np.linspace(0, 0.95, 191)
grow_values = low_reward / (1 - probabilities)
invest_values = probabilities * high_reward / (1 - probabilities)
optimal_values = np.array([bellman(chance)[0] for chance in probabilities])
np.testing.assert_allclose(
    optimal_values, np.maximum(grow_values, invest_values), atol=3e-12, rtol=0
)
print(f"Continuation threshold: {threshold:.6f}")
for chance in (0.5, 0.9):
    grow_value = low_reward / (1 - chance)
    invest_value = chance * high_reward / (1 - chance)
    print(f"p={chance:.1f}: grow={grow_value:.6f}, invest={invest_value:.6f}")

This is the connection to deep learning: a Q-network estimates an action’s cumulative future reward from experience, allowing a low-immediate-reward action to be valuable. Mnih and colleagues’ Playing Atari with Deep Reinforcement Learning uses a neural network for that action-value function [3]. Our two-state problem is small enough to solve exactly. It makes the underlying decision visible before introducing a learned neural approximation.

What I would argue against / where this breaks

A useful investment rule does not establish that cells learn a Q-network. My model specifies the payoffs, assumes a permanent upgrade with a one-interval opportunity cost, and omits precursor, protein and energy balances. Real investments take time, face dilution and may alter survival. Also, maximizing expected log biomass differs from maximizing expected biomass; changing that objective can change the preferred action. If nutrient persistence depends on history, the state and Bellman equations need that history. The result is a testable modeling lesson: a growth pause can be rational under delayed reward, but whether it pays depends on the environmental statistics and the stated objective.
