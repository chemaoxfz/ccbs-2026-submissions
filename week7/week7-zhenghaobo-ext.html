Week 7 — Extension: The map is exact; the ceiling belongs to the sensor

Author: Zheng Haobo · Week 7 (2026-11-02) · CCBS 2026
One sentence: These two models are one model in two coordinate systems, yet h ∈ (1, 2.7) belongs to the one sensor that ties angle to rate in the ratio κ : −1. Free both weights and stability becomes two half-planes with no ceiling; a standard PD point 25× past the angle threshold still decays.

The point I am adding

Both are two-state linear models dx/dt = A x + b u with one input, in deviations from an operating point. Glycolysis has x = (intermediate pool, ATP pool), with κ the intermediate reaction rate and g the strength of ATP's downstream feedback; the cart has z = (θ, ω), angle from upright and its rate, ω = dθ/dt. At κ = 1.1 and g = 0.3 the plants, their measurements and a single-gain controller are

Agly = −κ1 + g2κ−1 − 2g, bgly = (−1, 1)T,   y = (0  1) x,   u = h y;
Acart = 01κ−(κ + 1 + 2g), bcart = (0, −(κ + g))T,   ycart = (κθ − ω)/(κ + g),   u = h ycart.

One change of coordinates, z = T x with

T = 11κ−g = 111.1−0.3,   Acart = T Agly T−1,   bcart = T bgly,   ycart = x2,

links them. These are matrix equalities, not an analogy: below, the largest elementwise difference is 2.2 × 10−16, floating-point zero. They do not say that θ is ATP: T's first row reads θ = x1 + x2, so the angle is the sum of both pools, and the course page says the map does not identify a metabolite with a mechanical angle.

Read Acart by rows: the first row (0, 1) only integrates the rate; the second holds the destabilising κ and the whole input column (0, −(κ + g)). A controller using both measurements, u = hθθ + hωω, touches only that row:

Acl = 01κ − (κ + g)hθ−(κ + 1 + 2g) − (κ + g)hω,   det = (κ + g)hθ − κ,   trace = −(κ + 1 + 2g) − (κ + g)hω.

Det is minus the off-diagonal product and trace is the diagonal, so det holds only hθ and trace only hω. Stability for a real 2 × 2 matrix is exactly trace < 0 and det > 0: hθ > κ/(κ + g) = 0.785714, hω > −(κ + 1 + 2g)/(κ + g) = −1.928571. The first cancels the unstable mode, the second stops over-cancelling damping; neither has an upper bound.

The course's single gain is one line through this plane: u = h ycart gives (hθ, hω) = h(0.785714, −0.714286), a ray. Substituting gives det = κ(h − 1) and trace = h − (κ + 1 + 2g), so both tests collapse to 1 < h < 2.7: the window is the segment of that ray inside the stable set, entering at h = 1 where det vanishes and leaving at h = 2.7 where trace vanishes. On the ray 2.7 is exactly right (purely imaginary eigenvalues), but it is not a property of the glycolysis plant.

Work it

The script below recomputes it. Isomorphism: max |T Agly T−1 − Acart| = 2.220446 × 10−16 and max |T bgly − bcart| = 0, both open-loop determinants −κ = −1.1. Stable set: at the four gain pairs the script tests, closed-loop det and trace match the formulas above to 3.6 × 10−15; the boundaries 0.785714 and −1.928571 come from those formulas, not from the spot checks.

Eigenvalues: along the ray the pair is real and negative at h = 1.2, a decaying complex pair at 2.0 and 2.5, on the imaginary axis at 2.7 and positive at 2.8 (numbers in the caption) — the window, and the same statement as the course's 2b − κ < a < 0, where a = 1 − h and b = −g = −0.3 are the ATP reaction orders (log-slopes of each flux against ATP) of the upstream and downstream reactions. Counterexample: at (20, 0.5) the loop has trace −3.4, det 26.9 and eigenvalues −1.7 ± 4.9i: stable and ringing, at 25.45 times the angle threshold and far from every boundary.

Reproduce it — the full script that produced every number above
Python 3.12.3; NumPy 2.4.1. Dimensionless throughout: normalized pools, normalized time, κ = 1.1, g = 0.3, so κ + g = 1.4. The script prints one JSON object; the figure and every number in the text and caption are read from it.
"""Exact coordinate change between the two-pool glycolysis plant and the cart-pole plant,
then the closed-loop stability set when angle and rate feedback carry separate weights.
All quantities are dimensionless (normalized pools, normalized time, κ = 1.1, g = 0.3)."""

import json
import platform
import numpy as np

KAPPA, G = 1.1, 0.3                     # intermediate rate; downstream ATP feedback strength
KP = KAPPA + G                          # input gain of the cart plant
A_GLY = np.array([[-KAPPA, 1 + G], [2 * KAPPA, -1 - 2 * G]])
B_GLY = np.array([-1.0, 1.0])
A_CART = np.array([[0.0, 1.0], [KAPPA, -(KAPPA + 1 + 2 * G)]])
B_CART = np.array([0.0, -KP])
T = np.array([[1.0, 1.0], [KAPPA, -G]])
H_THETA_STAR = KAPPA / KP                         # det = 0
H_OMEGA_STAR = -(KAPPA + 1 + 2 * G) / KP          # trace = 0
XMIN, XMAX, YMIN, YMAX = 0.4, 40.0, -2.4, 1.2     # plotting frame of the (h_θ, h_ω) plane


def closed_loop(h_theta, h_omega):
    """u = h_theta*theta + h_omega*omega, with the input entering A_cart's second row."""
    return A_CART + np.outer(B_CART, [h_theta, h_omega])


def eigenvalues(matrix):
    """Eigenvalues as (re, im) pairs, positive imaginary part first, then larger real part."""
    pairs = sorted(((complex(z).real, complex(z).imag) for z in np.linalg.eigvals(matrix)),
                   key=lambda p: (round(p[1], 9), round(p[0], 9)), reverse=True)
    return [{"re": round(re, 12), "im": round(im, 12)} for re, im in pairs]


def report(h_theta, h_omega, **extra):
    """Closed-loop determinant, trace, eigenvalue pair, and the two test inequalities."""
    m = closed_loop(h_theta, h_omega)
    det, trace = round(float(np.linalg.det(m)), 12), round(float(np.trace(m)), 12)
    entry = dict(h_theta=h_theta, h_omega=h_omega, det=det, trace=trace,
                 det_linear=round(KP * h_theta - KAPPA, 12), trace_linear=round(-(KAPPA + 1 + 2 * G) - KP * h_omega, 12),
                 stable=bool(det > 0 and trace < 0), eigenvalues=eigenvalues(m))
    entry.update(extra)
    return entry


# (a) the coordinate change: A_cart = T A_gly T^-1 and b_cart = T b_gly, elementwise
A_MAPPED, B_MAPPED = T @ A_GLY @ np.linalg.inv(T), T @ B_GLY
isomorphism = {"T": T.tolist(), "T_inv": np.linalg.inv(T).tolist(),
               "A_cart_mapped": A_MAPPED.tolist(), "A_cart": A_CART.tolist(),
               "max_abs_diff_A": float(np.max(np.abs(A_MAPPED - A_CART))),
               "b_cart_mapped": B_MAPPED.tolist(), "b_cart": B_CART.tolist(),
               "max_abs_diff_b": float(np.max(np.abs(B_MAPPED - B_CART))),
               "det_gly": float(np.linalg.det(A_GLY)), "det_cart": float(np.linalg.det(A_CART))}

# (b) two independent weights: thresholds, plus a symbolic-versus-numeric audit on a grid
probes = [report(ht, hw) for ht in (0.5, H_THETA_STAR, 2.0, 20.0) for hw in (-2.5, H_OMEGA_STAR, 0.5)]
weights = {"det_const": round(KP, 12), "det_offset": -KAPPA, "trace_const": round(-(KAPPA + 1 + 2 * G), 12), "trace_slope": round(-KP, 12),
           "h_theta_star": H_THETA_STAR, "h_omega_star": H_OMEGA_STAR,
           "formula_max_error": float(max(max(abs(np.linalg.det(closed_loop(a, b)) - (KP * a - KAPPA)),
                                              abs(np.trace(closed_loop(a, b)) - (-(KAPPA + 1 + 2 * G) - KP * b)))
                                          for a, b in ((0.5, -2.5), (2.0, 0.5), (20.0, -1.9), (0.9, 1.1)))),
           "probes": probes}

# (c) the metabolic sensor u = h*(kappa*theta - omega)/(kappa+g) is a ray through the origin
direction = np.array([KAPPA, -1.0]) / KP
h_at_det_zero = float(H_THETA_STAR / direction[0])          # 1
h_at_trace_zero = float(H_OMEGA_STAR / direction[1])        # 1 + kappa + 2g
h_lo, h_hi = XMIN / direction[0], YMIN / direction[1]       # ray clipped to the plotting frame
ray_h = np.linspace(h_lo, h_hi, 81)
ray = {"direction": direction.tolist(), "h_at_det_zero": h_at_det_zero, "h_at_trace_zero": h_at_trace_zero,
       "point_at_det_zero": (h_at_det_zero * direction).tolist(),
       "point_at_trace_zero": (h_at_trace_zero * direction).tolist(),
       "h_frame": [float(h_lo), float(h_hi)], "points": (np.outer(ray_h, direction)).tolist(),
       # the stable window, sampled so that a plot can follow the ray itself rather than a chord
       "stable_points": (np.outer(np.linspace(h_at_det_zero, h_at_trace_zero, 41), direction)).tolist()}

# (d) eigenvalues along the ray and at a standard PD point
ray_cases = [report(h * direction[0], h * direction[1], h=float(h)) for h in (1.2, 2.0, 2.5, 2.7, 2.8)]
pd = report(20.0, 0.5)
pd["ratio_to_threshold"] = 20.0 / H_THETA_STAR

# (e) everything the figure needs, in data coordinates
figure = {"h_theta_range": [XMIN, XMAX], "h_omega_range": [YMIN, YMAX],
          "shade": [[H_THETA_STAR, H_OMEGA_STAR], [XMAX, YMAX]],
          "det_boundary": {"h_theta": H_THETA_STAR, "h_omega": [YMIN, YMAX]},
          "trace_boundary": {"h_omega": H_OMEGA_STAR, "h_theta": [XMIN, XMAX]},
          "ray_visible": ray["points"],
          "ray_stable": [ray["point_at_det_zero"], ray["point_at_trace_zero"]],
          "ray_stable_points": ray["stable_points"],
          "pd": {"h_theta": pd["h_theta"], "h_omega": pd["h_omega"]},
          "corner": report(XMAX, YMAX, label="upper-right corner of the frame")}

checks = {"isomorphism_A_exact": isomorphism["max_abs_diff_A"] < 1e-15,
          "isomorphism_b_exact": isomorphism["max_abs_diff_b"] == 0.0,
          "det_trace_formulas": weights["formula_max_error"] < 1e-14,
          "ray_window_is_1_to_2p7": bool(abs(h_at_det_zero - 1) < 1e-12 and abs(h_at_trace_zero - 2.7) < 1e-12),
          "ray_segment_ends_on_boundaries": bool(np.allclose(ray["stable_points"][0], ray["point_at_det_zero"])
                                                 and np.allclose(ray["stable_points"][-1], ray["point_at_trace_zero"])),
          "thresholds": bool(abs(H_THETA_STAR - 0.785714) < 1e-6 and abs(H_OMEGA_STAR + 1.928571) < 1e-6),
          "pd_stable": bool(pd["stable"] and abs(pd["ratio_to_threshold"] - 25.45) < 0.01),
          "corner_stable": bool(figure["corner"]["stable"])}

print(json.dumps({"versions": {"python": platform.python_version(), "numpy": np.__version__},
                  "parameters": {"kappa": KAPPA, "g": G, "kappa_plus_g": round(KP, 12)},
                  "isomorphism": isomorphism, "weights": weights, "ray": ray,
                  "eigenvalues": {"ray": ray_cases, "pd": pd},
                  "figure": figure, "checks": checks}, indent=2))

What I would argue against / where this breaks

The arithmetic of 2.7 is not in dispute: on the metabolic ray it is exact. What I would argue against is the sentence that usually follows, that the glycolysis plant destabilises once feedback exceeds 2.7. The plant has two knobs, both bounded below and neither above; the bound appears only when the mixing ratio is fixed.

Where this breaks. Everything above is a linearisation at one operating point: small angles, matched gravity, no saturation, delay or noise; large tilts, a force limit or a lagging measurement deform the stable set, and I have not computed those. A demand step moves the operating point, so both thresholds need a fresh Jacobian. And in a cell the sensor is not a knob: if ATP sensing really is the fixed mixture of the two pools the model assumes, then 1 < h < 2.7 is a true constraint on that organism — my claim is about what the constraint is a property of, not about gains one could install.
