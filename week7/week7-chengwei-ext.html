Why the speed of an ATP demand increase matters

Author: Chengwei Jin · Week 7 (2026-10-29) · CCBS 2026

One sentence: A metabolic machine can sustain a demand at a stable operating point yet lose its ATP reserve while trying to reach that point too quickly.

The point I am adding

Lecture 13 shows how ATP feedback responds to a demand step.1 I change the question: does a stable final operating point guarantee a safe transition? I compare a sudden increase with a gradual increase to the same demand. The final ATP budget is identical, but the routes to it differ.

Work it

Keep the lecture’s normalized intermediate pool q¯I, ATP pool q¯ATP, and time t¯. One investment event consumes one ATP; its downstream payoff returns two. The effective rates and balances are12

v¯1=2q¯ATP1+q¯ATP2h,v¯2=2κq¯I1+q¯ATP2g.
dq¯Idt¯=v¯1−v¯2,dq¯ATPdt¯=−v¯1+2v¯2−w¯.

Use κ=1.1, g=0.3, h=2.6. Start from (q¯I,q¯ATP)=(1/κ,1) at demand one. This initial equilibrium is stable because 1<h<1+κ+2g=2.7.2 Either step directly to 1.224, or increase demand linearly from 1 to 1.224 over ten time units and then hold it there.

First check that the destination is sustainable. At steady state, both balances require v¯1=v¯2=w¯. Differentiating the first rate gives its maximum:

q¯ATP,peak=(2h−1)−1/(2h),h>12,
v¯1,max=2q¯ATP,peak1+q¯ATP,peak2h≈1.2258.

The chosen demand lies just below this capacity. Solving the steady equations gives an upper-ATP state (q¯I*,q¯ATP*)≈(1.035,0.779). Its two Jacobian eigenvalues are negative, so small perturbations decay. The algebra and stability check are below.

The trajectories nevertheless separate. The step crosses an illustrative ATP floor of 0.6 at time 14.52. The ten-unit ramp stays above the floor and approaches ATP 0.779. Independent adaptive solvers and a fixed-step Runge–Kutta calculation confirm the contrast. I stop the falling trajectory at ATP 0.2, before extrapolating this positive-concentration model to zero.

The mechanism is ATP’s dual role. Falling ATP initially relieves inhibition, but below q¯ATP≈0.759 the investment rate decreases: the pathway is running short of the substrate needed to replenish its intermediate. A steady flux balance cannot describe that loss of operating reserves.

Check the capacity and local stability

For this calculation only, abbreviate A=q¯ATP, I=q¯I. Write f(A)=2A/(1+A2h). Differentiating gives

f′(A)=2[1+(1−2h)A2h](1+A2h)2.

For h>1/2, the derivative changes from positive to negative at A=(2h−1)−1/(2h). At each steady solution of f(A*)=w¯, the other balance gives I*=w¯[1+(A*)2g]/(2κ). There are two positive roots at the chosen demand.

Define the local rate derivatives a=f′(A*), b=∂v¯2/∂I, c=∂v¯2/∂A. Then

J=[−ba−c2b−a+2c].
b=2κ1+(A*)2g,c=−2gw¯(A*)2g−11+(A*)2g.

At the upper root, the eigenvalues are λ1≈−1.754, λ2≈−0.121. Both are negative. The lower root has ATP 0.739 and one positive eigenvalue, so it is a saddle. This ATP value alone is not a threshold for recovery: the intermediate pool also matters. Local stability guarantees return from sufficiently small perturbations near the upper state, not from every state reached after a finite demand change.

Reproduce the figure and all reported numbers

Save as reproduce.py and run python reproduce.py. Requires NumPy, SciPy and Matplotlib. Results, CSV trajectories, and SVG/PDF/PNG figures are written into generated/ beside the script. The calculation checks equilibria, the analytic Jacobian, DOP853 against Radau, tighter tolerances, a fixed-step RK4 crossing time, several ATP thresholds, and a smaller demand step.

"""Reproduce the Week 7 step-versus-ramp ATP example.

Run: python reproduce.py
Dependencies: numpy, scipy, matplotlib. Outputs go to generated/ beside this file.
All concentrations, fluxes and times are normalized teaching quantities.
The model is Lecture 13 section 3 / Chandra et al. (2011), Eq. 1.1,
with ATP investment stoichiometry and substrate exponent both equal to one.
The demand protocols, h=2.6, and ATP comparison floor are chosen here.
The solver stops at ATP=0.2, before the positive-state model becomes invalid.
"""
from pathlib import Path
import json
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import brentq, minimize_scalar
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from matplotlib import font_manager

OUT = Path(__file__).resolve().parent / 'generated'
KAPPA, G, H = 1.1, 0.3, 2.6
FINAL_DEMAND, RAMP_LENGTH = 1.224, 10.0
HORIZON, FLOOR, STOP = 200.0, 0.6, 0.2
INITIAL = np.array([1.0 / KAPPA, 1.0])  # intermediate, ATP

def rates(I, A):
    assert A > 0, 'Do not extend the fractional-power model to negative ATP'
    return 2*A/(1+A**(2*H)), 2*KAPPA*I/(1+A**(2*G))

def demand(t, duration, final=FINAL_DEMAND):
    return final if duration == 0 else 1+(final-1)*min(max(t/duration, 0), 1)

def rhs(t, y, duration, final=FINAL_DEMAND):
    v1, v2 = rates(*y)
    return np.array([v1-v2, -v1+2*v2-demand(t, duration, final)])

def jacobian(I, A):
    v1, v2 = rates(I, A)
    a = 2*(1+(1-2*H)*A**(2*H))/(1+A**(2*H))**2
    b = 2*KAPPA/(1+A**(2*G))
    c = -2*G*v2*A**(2*G-1)/(1+A**(2*G))
    return np.array([[-b, a-c], [2*b, -a+2*c]])

def equilibria(w):
    peak = (2*H-1)**(-1/(2*H))
    roots = [brentq(lambda a: rates(1, a)[0]-w, 1e-8, peak, xtol=1e-14),
             brentq(lambda a: rates(1, a)[0]-w, peak, 2, xtol=1e-14)]
    states = [np.array([w*(1+a**(2*G))/(2*KAPPA), a]) for a in roots]
    return states

def integrate(duration, final=FINAL_DEMAND, method='DOP853', rtol=1e-10, max_step=0.05):
    def stop_event(t, y):
        return y[1]-STOP
    stop_event.terminal = True
    stop_event.direction = -1
    events = [stop_event]
    for threshold in [0.7, FLOOR, 0.4]:
        def event(t, y, threshold=threshold):
            return y[1]-threshold
        event.direction = -1
        events.append(event)
    # Integrate separately across the ramp's derivative discontinuity.
    breaks = [0.0] + ([duration] if duration else []) + [HORIZON]
    pieces, state = [], INITIAL.copy()
    for start, end in zip(breaks[:-1], breaks[1:]):
        sol = solve_ivp(lambda t,y: rhs(t,y,duration,final), (start,end), state,
            method=method, rtol=rtol, atol=rtol*0.01, max_step=max_step,
            events=events, dense_output=True)
        assert sol.success, sol.message
        pieces.append(sol)
        state = sol.y[:,-1]
        if sol.status == 1:
            break
    return pieces

def evaluate(pieces, times):
    times = np.atleast_1d(times)
    out = np.empty((2,len(times)))
    for i,t in enumerate(times):
        piece = next(s for s in pieces if t <= s.t[-1]+1e-12)
        out[:,i] = piece.sol(t)
    return out

def metrics(pieces):
    end = pieces[-1].t[-1]
    samples = np.linspace(0,end,5001)
    vals = evaluate(pieces,samples)[1]
    minima = [(vals[0],samples[0]),(vals[-1],samples[-1])]
    for i in np.flatnonzero((vals[1:-1] < vals[:-2]) & (vals[1:-1] < vals[2:]))+1:
        result = minimize_scalar(lambda t: evaluate(pieces,[t])[1,0],
            bounds=(samples[i-1],samples[i+1]), method='bounded', options={'xatol':1e-11})
        minima.append((result.fun,result.x))
    minimum, tmin = min(minima)
    crossings = {}
    for idx,label in enumerate(['0.2','0.7','0.6','0.4']):
        ts = [float(t) for piece in pieces for t in piece.t_events[idx]]
        crossings[label] = ts[0] if ts else None
    return {'end_time':float(end), 'end_state':pieces[-1].y[:,-1].tolist(),
            'minimum_ATP':float(minimum), 'minimum_time':float(tmin),
            'first_downward_crossings':crossings}

def rk4_crossing(duration, threshold=FLOOR, dt=0.002):
    t, y = 0.0, INITIAL.copy()
    while t < 35:
        step = min(dt, 35-t)
        if t < duration < t+step:
            step = duration-t
        k1=rhs(t,y,duration);k2=rhs(t+step/2,y+step*k1/2,duration)
        k3=rhs(t+step/2,y+step*k2/2,duration);k4=rhs(t+step,y+step*k3,duration)
        new = y+step*(k1+2*k2+2*k3+k4)/6
        if new[1] <= threshold < y[1]:
            return float(t+step*(y[1]-threshold)/(y[1]-new[1]))
        t, y = t+step, new
    return None

def main():
    OUT.mkdir(exist_ok=True)
    peak = (2*H-1)**(-1/(2*H))
    capacity = rates(1,peak)[0]
    low, high = equilibria(FINAL_DEMAND)
    assert FINAL_DEMAND < capacity
    assert 1 < H < 1+KAPPA+2*G
    assert np.max(np.real(np.linalg.eigvals(jacobian(*INITIAL)))) < 0
    assert np.max(np.real(np.linalg.eigvals(jacobian(*high)))) < 0
    assert np.linalg.det(jacobian(*low)) < 0
    assert np.max(np.abs(rhs(0,high,0))) < 1e-12
    # A nearby steady state is stable throughout the ramp's demand range.
    max_real = max(float(np.max(np.real(np.linalg.eigvals(jacobian(*equilibria(w)[1])))))
                   for w in np.linspace(1, FINAL_DEMAND, 201))
    assert max_real < 0
    step, ramp = integrate(0), integrate(RAMP_LENGTH)
    ms, mr = metrics(step), metrics(ramp)
    assert ms['first_downward_crossings']['0.6'] is not None
    assert mr['first_downward_crossings']['0.7'] is None
    assert np.max(np.abs(ramp[-1].y[:,-1]-high)) < 1e-9
    # Check an analytic Jacobian against a centered numerical derivative.
    eps=1e-6
    numerical=np.column_stack([(rhs(0,high+eps*np.eye(2)[j],0)-
         rhs(0,high-eps*np.eye(2)[j],0))/(2*eps) for j in range(2)])
    jac_error=float(np.max(np.abs(numerical-jacobian(*high))))
    assert jac_error < 1e-7
    radau_step, radau_ramp = integrate(0,method='Radau'), integrate(RAMP_LENGTH,method='Radau')
    common=np.linspace(0,min(step[-1].t[-1],radau_step[-1].t[-1]),2001)
    method_error=float(np.max(np.abs(evaluate(step,common)-evaluate(radau_step,common))))
    ramp_error=float(np.max(np.abs(evaluate(ramp,np.linspace(0,200,2001))-
                                      evaluate(radau_ramp,np.linspace(0,200,2001)))))
    refined = metrics(integrate(0,rtol=1e-12,max_step=0.025))
    crossing=ms['first_downward_crossings']['0.6']
    refined_error=abs(refined['first_downward_crossings']['0.6']-crossing)
    rk4_time=rk4_crossing(0)
    assert max(method_error,ramp_error,refined_error) < 1e-7
    assert abs(rk4_time-crossing) < 2e-6
    assert rk4_crossing(RAMP_LENGTH) is None
    smaller=metrics(integrate(0,final=1.20))
    assert smaller['first_downward_crossings']['0.7'] is None
    assert np.max(np.abs(np.array(smaller['end_state'])-equilibria(1.20)[1])) < 1e-9
    result={'parameters':{'kappa':KAPPA,'g':G,'h':H,'initial':INITIAL.tolist(),
        'final_demand':FINAL_DEMAND,'ramp_length':RAMP_LENGTH,'floor':FLOOR,
        'stop_ATP':STOP,'horizon':HORIZON},
        'capacity':float(capacity),'ATP_at_capacity':float(peak),
        'equilibrium_low':low.tolist(),'equilibrium_high':high.tolist(),
        'eigenvalues_high':np.linalg.eigvals(jacobian(*high)).tolist(),
        'eigenvalues_low':np.linalg.eigvals(jacobian(*low)).tolist(),
        'max_real_eigenvalue_along_steady_branch':max_real,
        'step':ms,'ramp':mr,'smaller_step_1_20':smaller,
        'checks':{'jacobian_max_error':jac_error,'Radau_step_max_error':method_error,
            'Radau_ramp_max_error':ramp_error,'refined_crossing_time_error':refined_error,
            'RK4_crossing_time':rk4_time,'RK4_crossing_time_error':abs(rk4_time-crossing)}}
    (OUT/'results.json').write_text(json.dumps(result,indent=2),encoding='utf-8')
    for name,pieces,duration in [('step',step,0),('ramp',ramp,RAMP_LENGTH)]:
        times=np.linspace(0,pieces[-1].t[-1],4001)
        states=evaluate(pieces,times)
        flux=np.array([rates(*y) for y in states.T])
        np.savetxt(OUT/(name+'.csv'),np.column_stack([times,states.T,
            [demand(t,duration) for t in times],flux]),delimiter=',',
            header='time,intermediate,ATP,demand,v1,v2',comments='')
    # Use bundled Computer Modern faces, with vector outlines in SVG for portability.
    fontdir=Path(matplotlib.get_data_path())/'fonts/ttf'
    font_manager.fontManager.addfont(str(fontdir/'cmr10.ttf'))
    matplotlib.rcParams.update({'font.family':'cmr10','mathtext.fontset':'cm',
        'axes.formatter.use_mathtext':True,'axes.unicode_minus':False,
        'svg.fonttype':'path','pdf.fonttype':42,'font.size':13,
        'axes.labelsize':14,'axes.titlesize':15,'axes.spines.top':False,
        'axes.spines.right':False,'axes.edgecolor':'#877F77','text.color':'#20201E',
        'axes.labelcolor':'#20201E','xtick.color':'#20201E','ytick.color':'#20201E'})
    rose, teal = '#D75567','#1F9A8E'
    fig,(a,b)=plt.subplots(2,1,figsize=(8.1,6.2),sharex=True,
        gridspec_kw={'height_ratios':[1,2.1]},layout='constrained')
    times=np.linspace(0,40,1601)
    a.plot([-2,0,0,40],[1,1,FINAL_DEMAND,FINAL_DEMAND],color=rose,lw=2.3,label='Sudden step')
    a.plot([-2,0,10,40],[1,1,FINAL_DEMAND,FINAL_DEMAND],color=teal,lw=2.3,ls='--',label='10-unit ramp')
    a.set(title='A  Same final demand, different onset',ylabel=r'Demand $\bar w$')
    a.set_ylim(.98,1.27);a.set_yticks([1,1.1,1.224]);a.set_yticklabels(['1.0','1.1','1.224'])
    a.legend(loc='lower right',frameon=False,ncol=2,fontsize=12)
    for pieces,color,style in [(step,rose,'-'),(ramp,teal,'--')]:
        t=np.linspace(0,min(40,pieces[-1].t[-1]),2001)
        b.plot(np.r_[-2,t],np.r_[1,evaluate(pieces,t)[1]],color=color,ls=style,lw=2.5)
    b.axhline(high[1],color='#877F77',ls=':',lw=1.2)
    b.text(27,high[1]+.035,f'Stable ATP = {high[1]:.3f}',fontsize=12,color='#666159')
    b.axhline(FLOOR,color='#877F77',ls='--',lw=1.2)
    b.text(27,FLOOR+.028,'Chosen floor = 0.6',fontsize=12,color='#666159')
    b.axhspan(STOP,FLOOR,color='#F5E6EB',alpha=.5)
    b.plot(crossing,FLOOR,'o',color=rose,ms=7,mec='white',mew=1)
    b.annotate(f'Floor crossed at {crossing:.2f}',xy=(crossing,FLOOR),xytext=(2,.38),
        fontsize=12,color=rose,arrowprops={'arrowstyle':'-','color':rose})
    b.plot(step[-1].t[-1],STOP,'x',color=rose,ms=8,mew=2)
    b.text(step[-1].t[-1]+1,.245,'Stop before ATP reaches zero',fontsize=11,color=rose)
    b.set(title='B  A stable endpoint does not guarantee a safe transition',
        ylabel=r'ATP $\bar q_{\mathrm{ATP}}$',xlabel=r'Normalized time $\bar t$',
        ylim=(.15,1.06),xlim=(-2,40))
    for ax in [a,b]:
        ax.grid(axis='y',color='#EDE7E0',lw=.6,zorder=-10)
        ax.axvline(0,color='#B8AEA5',lw=.7,zorder=-1)
    for ext in ['svg','pdf','png']:
        fig.savefig(OUT/('demand-onset.'+ext),dpi=180,metadata={'Creator':'Week 7 reproducible analysis'})
    plt.close(fig)
    print(json.dumps(result,indent=2))

if __name__ == '__main__':
    main()

What I would argue against / where this breaks

I would reject the inference “a stable balanced state exists, so the machine will reach it safely.” This example deliberately operates near capacity. A smaller step to 1.20 recovers above 0.75. The ramp also postpones some ATP consumption, so the comparison does not establish an efficiency gain at equal total work. The floor, clock and parameters are illustrative, and fixed demand near depletion is biologically incomplete. The result is a model counterexample, not a cell-death prediction. Its lesson is to test the path through retained metabolic pools, as well as the final budget.3
