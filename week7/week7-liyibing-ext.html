Lecture 15 — Extension: Report every AlphaFold seed

Author: liyibing · Lecture 15 (2026-11-01) · CCBS 2026

One sentence: When screening a designed protein with AlphaFold2, report the passing fraction across a fixed seed budget, because the best run alone hides how many attempts were needed to find it.

The point I am adding

Lecture 15 explains how AlphaFold2 (AF2) learns to predict structure; the protein-design lecture places it after RFdiffusion and ProteinMPNN as a computational check.1,2 My question concerns that check: should a sequence count as promising if we keep changing the random seed until one prediction looks good? The design lecture shows that changing seeds can change even whether a predicted protein is knotted.2 I would therefore make the sampling budget part of the reported result.

A high score needs interpretation. pLDDT estimates local structural accuracy, while PAE estimates uncertainty in relative residue placement; neither is a measured binding probability.2,3 For a binder, I would define a screen using local confidence, interchain PAE, and recovery of the intended geometry, then ask how consistently the same sequence passes. This tests repeatability of the computational screen, rather than treating one attractive structure as sufficient evidence.

Work it

Consider a hypothetical nonbinding candidate with a 5% chance per independent run of passing a predefined computational screen. That rate is my teaching assumption, not a measured AF2 error rate. If the rate stays constant, all n runs fail with probability (1 − p)n, so:

P(at least one pass) = 1 − (1 − p)n,   p = 0.05.

My calculation gives 64.2% for 20 seeds and 92.3% for 50 seeds. The candidate has not improved; we have given it more opportunities to look convincing. Meanwhile, its expected fraction of passing runs remains 5%. This is why I would preselect the seed count and screening rules, hold the sequence, MSA, model weights, recycling count, templates, and initial-guess setting fixed, and report k/n passes plus every run’s scores.

Reproduce the figure and numbers: Python 3, standard library only. Save as seed_selection.py and run python3 seed_selection.py. 

"""Teaching model, not AF2 measurements. Python 3, standard library only."""
from pathlib import Path

p = 0.05  # Assumed per-run pass probability for a nonbinding candidate.
ns = range(1, 51)  # Assume independent runs with the same probability.
q = lambda n: 1 - (1 - p) ** n
x = lambda n: 60 + 10.8 * n
y = lambda v: 260 - 208 * v

svg = [
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 320"',
    ' role="img" aria-labelledby="title desc">',
    '<title id="title">A lucky pass becomes likely with more attempts</title>',
    '<desc id="desc">Toy model with independent runs and p=0.05. '
    'At least one pass: 64.2% at 20 runs, 92.3% at 50.</desc>',
    '<rect width="640" height="320" fill="white"/>',
    '<g font-family="Arial,sans-serif" font-size="13" fill="#273746">',
    '<text x="60" y="25" font-size="16" font-weight="bold">'
    'More attempts, more chances for one lucky pass</text>',
    '<text x="60" y="45" fill="#566573">'
    'Illustrative model: independent runs; assumed p = 0.05</text>'
]

for v in (0, .25, .5, .75, 1):
    svg += [
        f'<path d="M60 {y(v)}H600" stroke="#e1e6eb"/>',
        f'<text x="49" y="{y(v)+4}" text-anchor="end">'
        f'{v:.0%}</text>'
    ]

for n in (0, 10, 20, 30, 40, 50):
    svg += [
        f'<text x="{x(n)}" y="282" text-anchor="middle">{n}</text>'
    ]

svg += [
    '<path d="M60 52V260H600" fill="none" stroke="#84919d"/>',
    '<text x="330" y="308" text-anchor="middle">'
    'Number of seeds tried (n)</text>',
    f'<path d="M{x(1)} {y(p)}H600" stroke="#b36a18" '
    'stroke-width="2" stroke-dasharray="6 4"/>',
    '<polyline fill="none" stroke="#1f4e79" stroke-width="3" points="'
    + ' '.join(f'{x(n):.2f},{y(q(n)):.2f}' for n in ns)
    + '"/>',
    '<text x="120" y="90" fill="#1f4e79">'
    'Chance of at least one pass</text>',
    '<text x="267" y="238" fill="#945510">'
    'Expected fraction of runs passing: 5%</text>'
]

for n, dx, dy, anchor in (
    (1, 8, -13, 'start'),
    (20, 9, 19, 'start'),
    (50, -9, -11, 'end')
):
    svg += [
        f'<circle cx="{x(n)}" cy="{y(q(n))}" r="4" fill="#1f4e79"/>',
        f'<text x="{x(n)+dx}" y="{y(q(n))+dy}" '
        f'text-anchor="{anchor}">{n} seeds: {q(n):.1%}</text>'
    ]

svg += ['</g></svg>']

out = Path(__file__).resolve().parent
(out / 'seed-selection.svg').write_text(
    '\n'.join(svg), encoding='utf-8'
)
(out / 'seed-selection.csv').write_text(
    'seeds,at_least_one_pass,expected_pass_fraction\n'
    + '\n'.join(f'{n},{q(n):.10f},{p}' for n in ns)
    + '\n',
    encoding='utf-8'
)

for n in (1, 5, 20, 50):
    print(
        f'{n:2d} seeds: at least one pass = {q(n):.1%}; '
        f'expected pass fraction = {p:.1%}'
    )

What I would argue against / where this breaks

Best-of-many sampling can be useful for discovering candidates, provided its budget is disclosed. My objection is to presenting its winner as evidence of repeatability. The toy formula assumes independent runs; actual seeds share a model and inputs, so their errors may be correlated. The tutorial also supplies the design as an initial structural guess.2 Agreement across seeds could therefore repeat the same bias, and disagreement could reflect predictor limitations rather than a bad protein. The passing fraction is a diagnostic, not a probability of biological success: binding still needs experimental measurement, as the lecture’s validation pipeline illustrates.2
