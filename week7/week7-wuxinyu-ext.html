Can starting protein expression later give a higher yield?

Xinyu Wu · Week 7 · CCBS 2026

Suppose two cultures start with the same biomass and are harvested six hours later. One is induced immediately; the other grows first. The first gets more time to make protein. The second may have more cells doing the work. Lecture 14 describes growth as investment in future production capacity. Here, I use that idea to ask when to switch from growth to protein expression.

Count both the cells and their production time

Heterologous expression can burden the host, as Ceroni and colleagues showed.[3] Let B be the amount of producing biomass and P the accumulated target protein in a fixed culture volume. Before induction, B′ = μ₀B and P′ = 0. After induction, B′ = μ₁B and P′ = qB, where q is a constant production rate per unit biomass. Assume ample nutrients, negligible cell death and protein degradation, and an immediate switch with 0 ≤ μ₁ < μ₀. Starting from B₀ and zero product, induction at time τ gives:

P(T; τ) = qB₀ eμ₀τ (eμ₁(T−τ) − 1) / μ₁.

The first exponential counts the biomass built before induction; the remaining factor adds up production until harvest at T. If expression causes no growth penalty, μ₁ = μ₀, the model favors immediate induction. This is the no-burden baseline.

What does waiting buy?

For an illustrative calculation, set μ₀ = 0.50 h⁻¹, μ₁ = 0.25 h⁻¹ and T = 6 h. Immediate induction gives P/(qB₀) = 13.93 h. Waiting until 3.23 h gives 20.09 h: 44.2% more protein, despite a shorter expression period. The peak is broad. Inducing anywhere from 2.22 to 4.03 h gives at least 95% of the maximum.

How much time should be left for expression?

Write s = T − τ for the expression period. Differentiating log yield gives μ₀ − μ₁/(1 − e−μ₁s): the gain from building more biomass minus the loss from shortening production. Setting this to zero gives:

s* = ln[μ₀/(μ₀ − μ₁)] / μ₁,
τ* = max(0, T − s*).

Here s* = 2.77 h. With a two-hour deadline, immediate induction wins; with six hours, the first 3.23 h go to growth. Once the deadline is long enough, this model reserves a fixed expression period and spends the extra time growing cells.

To test this, measure growth before and after induction, then vary induction time at a fixed harvest time and measure total protein. Nutrient depletion would reduce the benefit of waiting. Induction delays, protein degradation or changes in q would shift the optimum. Repeating the experiment with a different harvest time would test the prediction of a fixed optimal expression period.

Derivation and reproducible calculation

For 0 < μ₁ < μ₀ and 0 ≤ τ < T, the log-yield derivative decreases with τ, so its zero is the unique interior maximum. If T ≤ s*, the maximum is at τ = 0. At μ₁ = 0, P = qB₀eμ₀τ(T−τ) and s* = 1/μ₀. As μ₁ approaches μ₀, s* diverges and immediate induction becomes optimal for any fixed T.

The code reproduces all three panels, the parameter sweep and numerical results. It checks the analytical yield against independent midpoint integration and the optimum against a grid search. Run with Python, NumPy and Matplotlib.

from pathlib import Path
import math, csv, json, html
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

OUT = Path(__file__).resolve().parent
OUT.mkdir(parents=True, exist_ok=True)
MU0, MU1, T = .5, .25, 6.

def product(tau, T=T, mu0=MU0, mu1=MU1):
    """P/(q B0), hours; stable even when induced growth is zero."""
    s = T-tau
    return math.exp(mu0*tau)*(math.expm1(mu1*s)/mu1 if mu1 else s)

def optimum(T=T, mu0=MU0, mu1=MU1):
    if mu1 >= mu0:
        return 0.
    s = math.log(mu0/(mu0-mu1))/mu1 if mu1 else 1/mu0
    return max(0., T-s)

def numerical(tau, n=4000):
    # Independent midpoint quadrature of biomass during the expression phase.
    dt=(T-tau)/n
    return sum(math.exp(MU0*tau+MU1*(i+.5)*dt)*dt for i in range(n))

best=optimum()
for tau in [0., 1., best, 5., 6.]:
    assert math.isclose(product(tau), numerical(tau), rel_tol=1e-8, abs_tol=1e-10)
assert optimum(T=2)==0 and optimum(mu1=MU0)==0
assert math.isclose(optimum(mu1=0),4.)
grid=np.linspace(0,T,1201)
assert abs(grid[np.argmax([product(x) for x in grid])]-best)<.005
peak=product(best)
def crossing(lo,hi):
    for _ in range(60):
        mid=(lo+hi)/2
        if (product(lo)-.95*peak)*(product(mid)-.95*peak)<=0: hi=mid
        else: lo=mid
    return (lo+hi)/2
window=[crossing(0,best),crossing(best,T)]
results={'mu0_per_h':MU0,'mu1_per_h':MU1,'harvest_h':T,'optimal_induction_h':best,
         'production_duration_h':T-best,'immediate_P_over_qB0_h':product(0),
         'optimal_P_over_qB0_h':peak,'gain_ratio':peak/product(0),'95_percent_window_h':window}
(OUT/'calculation-results.json').write_text(json.dumps(results,indent=2),encoding='utf-8')
with (OUT/'induction-sweep.csv').open('w',newline='',encoding='utf-8') as f:
    w=csv.writer(f);w.writerow(['induction_h','P_over_qB0_h','relative_to_immediate']);w.writerows((x,product(x),product(x)/product(0)) for x in grid)

plt.rcParams.update({'font.family':'DejaVu Sans','font.size':10,'axes.spines.top':False,'axes.spines.right':False,'svg.fonttype':'none'})
fig,axs=plt.subplots(1,3,figsize=(13,3.8),layout='constrained')
teal='#087f8c';gold='#d47725'
ax=axs[0]
for tau,color,label in [(0,gold,'Induce immediately'),(best,teal,'Induce at 3.23 h')]:
    ts=np.linspace(0,T,301)
    ps=[0 if t<=tau else product(tau,T=t) for t in ts]
    ax.plot(ts,ps,color=color,lw=2.5,label=label)
ax.set(xlabel='Culture time (h)',ylabel='Protein amount / (q B₀)  [h]',title='A  Less expression time, more product')
ax.legend(frameon=False,fontsize=8,loc='upper left')
ax=axs[1]
ax.axvspan(*window,color=teal,alpha=.1)
ax.plot(grid,[product(x)/product(0) for x in grid],color=teal,lw=2.5)
ax.axhline(1,color='#777777',ls='--',lw=1)
ax.scatter([best],[peak/product(0)],color=gold,zorder=3)
ax.annotate(f'{peak/product(0):.2f}× at {best:.2f} h',xy=(best,peak/product(0)),xytext=(.35,1.6),arrowprops={'arrowstyle':'->','color':gold})
ax.set(xlabel='Induction time τ (h)',ylabel='Protein / immediate-induction protein',title='B  A broad optimum',ylim=(0,1.85))
ax.text(.35,.18,f'Shading: ≥95% of peak\n{window[0]:.2f}–{window[1]:.2f} h',fontsize=9)
ax=axs[2]
for mu1,color,label in [(.45,'#899ba1','10% slower'),(.25,teal,'50% slower'),(0,gold,'Growth arrest')]:
    horizons=np.linspace(0,8,201)
    ax.plot(horizons,[optimum(T=t,mu1=mu1) for t in horizons],color=color,lw=2,label=label)
ax.set(xlabel='Harvest time T (h)',ylabel='Optimal induction time τ* (h)',title='C  Burden and deadline change the choice')
ax.legend(frameon=False,fontsize=8,title='After induction',title_fontsize=9)
for ax in axs: ax.grid(alpha=.15)
fig.savefig(OUT/'induction-strategy.svg');fig.savefig(OUT/'induction-strategy.png',dpi=170)
