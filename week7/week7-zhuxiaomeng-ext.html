Week 7: Same Drug Effect, Different Apparent Sensitivity

Week 7 (2026-11-02) · CCBS 2026 · Lecture 14

One sentence: Equal fractional inhibition of cell growth can produce different endpoint cell-count ratios, so a lower ratio alone does not establish greater intrinsic drug sensitivity or more cell killing.

The point I am adding

Lecture 14 describes how cell populations accumulate through exponential growth.1 That accumulation also changes how an anticancer drug appears to work. A common readout divides the treated population by its vehicle control at the end of an assay. If the control grows faster, this denominator becomes larger. Hafner and colleagues showed that division number can confound conventional drug-response metrics.2 I use a two-population example to ask what an apparent “50% viability” actually establishes.

Work it

Assume equal initial cell numbers, constant exponential growth and one fixed drug concentration. Choose untreated doubling times of 24 and 48 hours. These are illustrative values, not measurements from named cell lines. In each population, the drug halves the positive net growth rate. With treatment beginning at time zero:

Nctrl=N0eλctrlt,Ndrug=N0eλdrugt.

Here the subscripts distinguish control and drug-treated cell counts, the initial count is N0, time is in hours, and each growth rate has units of inverse hours. Thus λdrug=0.5λctrl. Define the endpoint ratio as R. Compare it with the normalized growth-rate inhibition value, GR, introduced by Hafner et al.:2

R=NdrugNctrl=e−0.5λctrlt,GR=2log2(Ndrug/N0)log2(Nctrl/N0)−1.

At 48 hours, the endpoint ratios differ, but the GR values agree:

Calculated model outputs at 48 hours; counts are multiples of the initial count.
Control doubling timeControl countTreated countTreated / controlGR
24 hours4.0002.00050.0%0.414
48 hours2.0001.41470.7%0.414

Both treated populations increase above their starting counts. Their lower endpoint ratios do not demonstrate cell loss. Substitution into the GR equation gives GR=20.5−1≈0.414 for either population. This value is not a “41.4% survival” measurement. GR equals 1 for unchanged growth, 0 for no net growth and becomes negative for a net decrease in cell number.2

What I would argue against / where this breaks

I would not rank cell lines by endpoint ratio without checking baseline growth and assay duration. GR calculation requires an initial count and a growing control; GRcalculator provides one implementation.3 It does not remove every biological or measurement confounder. Density effects and changing drug responses require suitable growth windows or time-resolved measurements.4 Metabolic signals also need validation: Chan et al. found discrepancies between direct counts and ATP/MTS readouts.5 Their study does not directly validate CCK-8. My conclusion is narrower: distinguish reduced accumulation from net loss before calling an endpoint change “killing.”

Reproduce the calculation and figure (Python 3)

Save the code as analysis.py and run python analysis.py. It uses only the Python standard library and writes growth_comparison.svg and growth_metrics.csv.

"""Reproduce the Week 7 illustrative model. Python 3, standard library only.
Run: python analysis.py
Writes growth_comparison.svg and growth_metrics.csv in the current folder.
All doubling times and effects are assumptions, not experimental observations.
GR definition: Hafner et al., Nature Methods (2016), doi:10.1038/nmeth.3853.
"""
import csv
import math
from pathlib import Path

DOUBLING_TIMES = (24.0, 48.0)  # hours, chosen for illustration
RATE_FRACTION = 0.5  # drug-treated net growth rate / control net growth rate

def metrics(doubling_time, time, rate_fraction=RATE_FRACTION):
    if time <= 0:
        raise ValueError('GR from endpoint counts requires a positive interval.')
    rate = math.log(2) / doubling_time
    control = math.exp(rate * time)
    treated = math.exp(rate_fraction * rate * time)
    ratio = treated / control
    gr = 2 ** (math.log2(treated) / math.log2(control)) - 1
    return control, treated, ratio, gr

def make_svg():
    colors = ('#5a73ce', '#1f9a8e')
    top, height = 108, 180
    l1, l2, width = 56, 444, 284
    x1 = lambda t: l1 + width * t / 48
    x2 = lambda t: l2 + width * t / 96
    y1 = lambda f: top + height * (4 - f) / 3
    y2 = lambda f: top + height * (1 - f)
    parts = ['<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 760 350" role="img" aria-labelledby="growth-title growth-desc">',
    '<title id="growth-title">Equal fractional growth-rate inhibition gives different endpoint ratios</title>',
    '<desc id="growth-desc">Illustrative exponential growth for 24-hour and 48-hour control doubling times. The treatment halves each net growth rate. At 48 hours the treated-to-control ratios are 50 percent and 70.7 percent, but both GR values are 0.414. Treated cell numbers increase above baseline in both cases.</desc>',
    '<rect width="760" height="350" fill="white"/>',
    '<g font-family="Arial, Helvetica, sans-serif" font-size="12" fill="#20201e">',
    '<text x="56" y="23" font-size="14" font-weight="bold">A. Both treated populations still grow</text>',
    '<text x="444" y="23" font-size="14" font-weight="bold">B. Endpoint ratios depend on duration</text>']
    for i, (label,col) in enumerate(zip(('24 h control doubling time','48 h control doubling time'),colors)):
        yy = 46 + 19*i
        parts += [f'<line x1="56" y1="{yy-4}" x2="78" y2="{yy-4}" stroke="{col}" stroke-width="2.5"/>',f'<text x="86" y="{yy}">{label}</text>',
        f'<line x1="444" y1="{yy-4}" x2="466" y2="{yy-4}" stroke="{col}" stroke-width="2.5"/>',f'<text x="474" y="{yy}">Cell-count ratio: {label[:4].strip()}</text>']
    parts += ['<text x="56" y="85" fill="#566">Solid: control; dashed: treated (rate halved)</text>',
    '<line x1="444" y1="81" x2="466" y2="81" stroke="#77488c" stroke-width="2.5" stroke-dasharray="4 3"/>',
    '<text x="474" y="85">GR: both populations (0.414)</text>']
    for value in (1,2,3,4):
        yy=y1(value)
        parts += [f'<line x1="{l1}" y1="{yy}" x2="{l1+width}" y2="{yy}" stroke="#e5e7eb"/>', f'<text x="47" y="{yy+4}" text-anchor="end">{value}</text>']
    for value in (0,.5,1):
        yy=y2(value)
        parts += [f'<line x1="{l2}" y1="{yy}" x2="{l2+width}" y2="{yy}" stroke="#e5e7eb"/>',f'<text x="435" y="{yy+4}" text-anchor="end">{value:g}</text>']
    for l in (l1,l2):
        parts += [f'<path d="M {l},{top} V {top+height} H {l+width}" fill="none" stroke="#20201e"/>']
    for t in (0,24,48):
        parts += [f'<text x="{x1(t)}" y="308" text-anchor="middle">{t}</text>']
    for t in (0,48,96):
        parts += [f'<text x="{x2(t)}" y="308" text-anchor="middle">{t}</text>']
    parts += ['<text x="198" y="337" text-anchor="middle">Time after treatment (hours)</text>',
    '<text x="586" y="337" text-anchor="middle">Time after treatment (hours)</text>',
    '<text x="17" y="198" transform="rotate(-90 17 198)" text-anchor="middle">Cell count / initial cell count</text>',
    '<text x="399" y="198" transform="rotate(-90 399 198)" text-anchor="middle">Treated / control, or GR</text>']
    for fraction,dash in ((1,''),(RATE_FRACTION,'6 4')):
        for td,col in zip(DOUBLING_TIMES,colors):
            points=' '.join(f'{x1(i/5):.2f},{y1(2**(fraction*i/5/td)):.2f}' for i in range(241))
            parts += [f'<polyline points="{points}" fill="none" stroke="{col}" stroke-width="2.5" stroke-dasharray="{dash}"/>']
    for td,col in zip(DOUBLING_TIMES,colors):
        points=' '.join(f'{x2(i/5):.2f},{y2(2**((RATE_FRACTION-1)*i/5/td)):.2f}' for i in range(481))
        parts += [f'<polyline points="{points}" fill="none" stroke="{col}" stroke-width="2.5"/>']
        ratio=metrics(td,48)[2]
        parts += [f'<circle cx="{x2(48)}" cy="{y2(ratio)}" r="4" fill="{col}" stroke="white"/>',f'<text x="{x2(48)+8}" y="{y2(ratio)-8:.2f}" fill="{col}">{100*ratio:.1f}%</text>']
    gr=2**RATE_FRACTION-1
    parts += [f'<line x1="{x2(.1)}" y1="{y2(gr)}" x2="{x2(96)}" y2="{y2(gr)}" stroke="#77488c" stroke-width="2" stroke-dasharray="4 3"/>']
    return '\n'.join(parts+['</g></svg>'])

if __name__ == '__main__':
    Path('growth_comparison.svg').write_text(make_svg(),encoding='utf-8')
    with open('growth_metrics.csv','w',newline='') as stream:
        w=csv.writer(stream)
        w.writerow(['control_doubling_time_h','time_h','control_fold','treated_fold','treated_over_control','GR'])
        for td in DOUBLING_TIMES:
            for time in range(1,97):
                w.writerow([td,time,*metrics(td,time)])
    for td in DOUBLING_TIMES:
        print(f'Control doubling time {td:g} h; at 48 h: {metrics(td,48)}')
