Week 7 — Extension: who pays 0.6786? The waterbed bill of ATP controllers

Author: Álvaro Bátrez · Week 7 (lecture 13, metabolic biomachine) · 2026-11-02 · CCBS 2026

One sentence: lecture 13 quotes the sensitivity integral 0.6786 for "every stable gain in this family" of ATP feedbacks — I verify numerically that the bill is identical for every single-sensor controller (P at two gains, the lecture's PI, a PD: all 0.6786 = ln[(z+p)/(z−p)], the plant's RHP pole p = 0.3595 seen through the ATP sensor's RHP zero z = κ = 1.1), while the lecture's freely-designed cart, which measures two states, pays something else (−0.74: it escapes) — the number belongs to the plant-plus-sensor, not to the controller, and the only exit is a second sensor, which sharpens the lecture's own thesis that components restrict the available controls.

The point I am adding

Lecture 13's Part 1 is a control course in miniature: the two-pool glycolysis plant (unstable: p ≈ 0.36), ATP inhibition as proportional feedback with window 1 < h < 2.7 and offset 1/(h−1), the memory-state PI with cubic and window 0 < kI < 1.1(h−1)(2.7−h)/(3.8−h), the cart equivalence, and one striking number: the weighted sensitivity integral ≈ 0.6786, stated for every stable gain in this family. Two questions that number begs: does it depend on the family? And who, exactly, is being billed?

The answer is textbook theory that the lecture invokes but does not fire at other controllers: a plant with RHP pole p and RHP zero z bills any stabilizing single-loop controller through the Poisson kernel centered at z, (2/π)∫ z/(z²+ω²) ln|S(iω)| dω = ln[(z+p)/(z−p)] — controller-independent, because S(z)=1 and S(p)=0 are interpolation constraints every loop inherits. I verified it four ways (table below): same 0.6786 to four decimals for two P gains, the lecture's PI, and a PD on the same ATP sensor. The fifth controller — state feedback, the cart designer's two-sensor freedom the lecture explicitly contrasts — does not inherit the sensor's RHP zero: its weighted integral is −0.74. The bill is not the controller's and not even the plant's alone: it is the plant's as seen through the ATP sensor. The metabolic architecture (one sensor, ATP) is stuck with 0.6786; the exit is measurement, not tuning — which is precisely "different components restrict the available controls," now with a number on it.

Along the way I verified the lecture's windows on the full nonlinear rate laws and found two nonlinear boundaries the linear analysis cannot see: the investment-flux capacity wmax(h) (at h = 1.2, v₁ saturates at 1.014, so a +10% demand step collapses ATP instead of settling at the promised 0.5), and integral windup (at (h, kI) = (2.5, 0.2) — inside the linear window — a +20% step throws the loop into a large oscillation: local stability is not global, and the unbounded ekIη actuator has no anti-windup).

The code (core)

import numpy as np
from scipy.integrate import quad, solve_ivp

kappa, g = 1.1, 0.3                      # lecture 13 parameters
D_P  = lambda s, h: s**2 + (2.7-h)*s + kappa*(h-1)      # P window: 1<h<2.7
chi  = lambda s, h, kI: s**3 + (2.7-h)*s**2 + (kappa*(h-1)-kI)*s + kappa*kI
kImax = lambda h: kappa*(h-1)*(2.7-h)/(3.8-h)           # lecture's PI window

p = max(np.roots([1, 2.7, -1.1]).real)   # 0.3595  (unstable plant pole)
z = kappa                                # 1.1     (RHP zero of the ATP channel)
print(np.log((z+p)/(z-p)))               # 0.6786  — the bill, closed form

def waterbed(S):                         # Poisson-weighted integral of ln|S|
    f = lambda w: np.log(abs(S(1j*w)))*z/(z**2+w**2)
    return 2/np.pi*quad(f, 1e-8, 1e8, limit=800)[0]

D_open = lambda s: s**2 + 2.7*s - 1.1
S_P  = lambda w, h: D_open(1j*w)/D_P(1j*w, h)
S_PI = lambda w, h, kI: 1j*w*D_open(1j*w)/chi(1j*w, h, kI)
kd = -8.7545/11.5545; kp = 2.3 + 6.1*kd          # PD on the SAME sensor, poles -2,-3
D_PD = lambda s: (1+kd)*s**2 + (2.7+kp-1.1*kd)*s + (-1.1-1.1*kp)
S_PD = lambda w: D_open(1j*w)/D_PD(1j*w)
from scipy.signal import place_poles
A = np.array([[-kappa, 1+g],[2*kappa, -1-2*g]]); b_ = np.array([-1.,1.])
K = place_poles(A, b_.reshape(2,1), [-2,-3]).gain_matrix.ravel()   # two sensors
def S_SF(w):                                     # state feedback: S = D_open/D_closed
    w = np.atleast_1d(w)
    M = 1j*w[:,None,None]*np.eye(2)[None] - (A-np.outer(b_,K))[None]
    return D_open(1j*w)/np.linalg.det(M)
print([waterbed(lambda w: S_P(w, 1.9)),        # 0.6786
       waterbed(lambda w: S_PI(w, 1.9, 0.2)),  # 0.6786
       waterbed(S_PD),                          # 0.6786
       waterbed(S_SF)])                         # -0.739 : two sensors escape

def rates(qI, qA, h):
    return 2*qA/(1+qA**(2*h)), 2*kappa*qI/(1+qA**(2*g))
def pi_step(h, kI, w=1.1, T=600):        # full nonlinear model, +10% demand
    def rhs(t, x):
        v1, v2 = rates(x[0], x[1], h); v1 *= np.exp(kI*x[2])
        return [v1-v2, -v1+2*v2-w, -(x[1]-1.0)]
    return solve_ivp(rhs, [0,T], [1/kappa,1,0], method="LSODA",
                     rtol=1e-11, atol=1e-13)
# pi_step(1.9, 0.2): ATP -> 1.00000000 (exact restoration)

What I would argue against / where this breaks

  • The universality is for linear controllers on the linearized plant. The nonlinear model pays the bill only near the operating point; the windup case ((2.5, 0.2), +20%) shows a loop that is window-stable yet oscillates wildly — the waterbed says nothing about basins.
  • The capacity limit is my addition, not the lecture's, and it is actuator-model-specific: I only cap v₁ through its Hill law; real glycolysis has more flux routes, so 1.014–1.239 is that two-reaction toy's ceiling, not glycolysis's.
  • The PD and state-feedback designs (poles at −2, −3) are arbitrary choices — they demonstrate that the integral's value does not move with the design, but they are not optimized; a different placement changes the shape of |S| (where the bill is spent), never the total.
  • I claim only the weighted integral. The unweighted Bode integral (the unstable-pole waterbed) is delicate for these proper loops — S → 1 only as 1/ω — and I did not verify it; no claim about it is made.
  • The biomolecular realization question is open: the lecture's η is an unbounded signed memory (ekₜη needs no saturation here); a real integral built from nonnegativity-preserving chemistry (lecture 10's constructions) saturates, and a saturating integral will pay its waterbed differently — the honest limit of this essay.
