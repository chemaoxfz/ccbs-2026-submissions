Overflow metabolism is the corner solution of the proteome budget

Leo Sin (施延庆) · Week 7, lectures 13–14 · CCBS 2026 · 2026-11-02

In one sentence: merging the lecture-13 overflow logic (“respiration saves carbon but costs protein, fermentation costs carbon but saves protein”1) with the lecture-14 proteome-allocation picture turns overflow into a theorem: acetate excretion starts exactly when the carbon supply outgrows the proteome budget, at the corner where the carbon constraint and the protein constraint first intersect.

The point I am adding

Lecture 13 gave the qualitative tradeoff behind the acetate switch: fully oxidising glucose through respiration yields far more ATP per carbon but demands the large respiratory machinery, whereas fermentation wastes carbon as acetate yet runs on a cheap, tiny enzyme set1. Lecture 14 then taught us to think of the cell as an economy that allocates a fixed proteome budget across sectors, with growth rate as the return on that budget2,3. Each lecture is convincing alone; what I want to add is that together they make a falsifiable quantitative prediction — the growth rate (equivalently, the carbon uptake rate) at which overflow must begin.

Write the two ATP-producing pathways as fluxes Jr (respiration) and Jf (fermentation), and maximise growth λ = Jr + Jf subject to two constraints:

proteome budget: (ar+αcr)Jr + (af+αcf)Jf ≤ F,    carbon capacity: crJr + cfJf ≤ C

where ar > af are protein costs per unit flux, cf >> cr are carbon costs per unit flux, α is the protein cost of uptake machinery per carbon, F is the proteome budget, and C is the environment-imposed carbon uptake capacity. Because fermentation is simultaneously protein-cheaper and carbon-costlier, the optimal vertex migrates: at low C the carbon constraint binds and the cell runs pure respiration (λ = C/cr); at high C the proteome constraint binds and the cell dilutes expensive respiration with cheap fermentation. The onset is where the two constraint lines meet at Jf = 0, which is algebraically immediate:

C* = F cr / (ar + αcr),    λ* = F / (ar + αcr)

So the “mysterious” acetate switch is not a regulatory accident; it is the point where the cell becomes rich in carbon but still poor in protein, and starts spending the abundant resource (carbon) to save the scarce one (proteome). The same proteome-economics logic is what Scott et al. measured as ribosomal-sector growth laws2 and Molenaar et al. formalised as growth-strategy shifts under cellular economic tradeoffs3; Basan et al. confirmed specifically that E. coli begins excreting acetate once its growth (hence carbon uptake) exceeds what the respiratory proteome can serve1.

Work it

I set ar=1, af=0.5, cr=1/26, cf=1/2, α=0.02, F=1 (order-unity toy units: respiration ≈ 26 ATP per glucose, fermentation ≈ 2). The LP has only three candidate vertices, so I solve it analytically on a grid of C rather than calling a solver. The grid sweep gives λ*(C), the pathway mix, and the onset.

Simulation code (Python, standard library only) 
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
week7 ext simulation: overflow metabolism as the corner solution of the
proteome-budget LP.

Model (units: fluxes in ATP equivalents per unit time, protein mass fractions
dimensionless):

  Two ATP-producing pathways feed the cell's energy demand J_r + J_f = lambda:
    - respiration:  protein cost a_r per unit flux (expensive machinery),
                    carbon cost c_r per unit flux (very efficient per carbon)
    - fermentation: protein cost a_f < a_r  (cheap, few enzymes),
                    carbon cost c_f >> c_r   (wasteful per carbon)

  Uptake machinery itself costs protein alpha per unit carbon taken up.

  Proteome budget:  a_r J_r + a_f J_f + alpha (c_r J_r + c_f J_f) <= F
  Carbon capacity:  c_r J_r + c_f J_f <= C      (environment-limited uptake)

Maximize lambda = J_r + J_f s.t. both constraints.
Because fermentation is both protein-cheaper and carbon-costlier, at low C the
carbon constraint binds and respiration alone is optimal; above a threshold C*
the proteome constraint binds and the cell mixes in fermentation (overflow).
C* is found where both constraints are simultaneously tight with J_f = 0.
"""
import json, math

# --- parameters (order-unity toy model) ---
a_r = 1.0      # protein cost per unit respiration flux
a_f = 0.5      # protein cost per unit fermentation flux
c_r = 1.0/26.0 # carbon cost per unit respiration flux (PDH+TCA: ~26 ATP/glucose)
c_f = 0.5      # carbon cost per unit fermentation flux (acetate: ~2 ATP/glucose)
alpha = 0.02   # protein cost of uptake machinery per unit carbon taken up
F = 1.0        # total proteome budget fraction

# --- analytic solution ---
# Candidate vertices (Jr, Jf) of the feasible polygon:
#  A: origin;  B: carbon-only corner (Jf=0, c_r Jr = C);
#  C: protein-only corner (Jr=0, a_f Jf + alpha c_f Jf = F);
#  D: intersection of both constraints (when it exists with Jf >= 0)
def solve(C):
    p_r, p_f = a_r + alpha * c_r, a_f + alpha * c_f
    best_lam, mix = 0.0, (0.0, 0.0)
    # vertex B: carbon-tight, Jf = 0
    Jr = C / c_r
    if p_r * Jr <= F + 1e-12 and Jr > best_lam:
        best_lam, mix = Jr, (Jr, 0.0)
    # vertex C: protein-tight, Jr = 0
    Jf = F / p_f
    if c_f * Jf <= C + 1e-12 and Jf > best_lam:
        best_lam, mix = Jf, (0.0, Jf)
    # vertex D: both constraints tight
    det = c_r * p_f - c_f * p_r
    Jr = (C * p_f - c_f * F) / det
    Jf = (c_r * F - C * p_r) / det
    if Jr >= -1e-12 and Jf >= -1e-12:
        lamD = Jr + Jf
        if lamD > best_lam + 1e-12:
            best_lam, mix = lamD, (max(Jr, 0.0), max(Jf, 0.0))
    return best_lam, mix

# overflow onset: C* where intersection D has Jf = 0  =>  C* = F * c_r / p_r
p_r, p_f = a_r + alpha * c_r, a_f + alpha * c_f
C_star = F * c_r / p_r
lam_star, _ = solve(C_star)

grid = [0.02 * (100.0 ** (i / 120.0)) for i in range(121)]    # 0.02 .. 2.0
rows = []
for C in grid:
    lam, (Jr, Jf) = solve(C)
    rows.append((C, lam, Jr, Jf))

# --- build smooth polylines for SVG (viewBox 0 0 560 380, margins l=58 t=14) ---
W, H, ML, MT = 560, 380, 58, 14
def px(C):  return ML + (C - grid[0]) / (grid[-1] - grid[0]) * (W - ML - 12)
def py(lam): return MT + (1 - (lam - 0) / (rows[-1][1] * 1.05)) * (H - MT - 34)

lam_path = "M " + " L ".join(f"{px(C):.1f},{py(lam):.1f}" for C, lam, _, _ in rows)
# respiration/fermentation stacks
resp_path = "M " + " L ".join(f"{px(C):.1f},{py(Jr):.1f}" for C, _, Jr, _ in rows) + \
            " L " + f"{px(grid[-1]):.1f},{py(0):.1f} L {px(grid[0]):.1f},{py(0):.1f} Z"
ferm_path = "M " + " L ".join(f"{px(C):.1f},{py(Jr+Jf):.1f}" for C, _, Jr, Jf in rows) + \
            " L " + " L ".join(f"{px(C):.1f},{py(Jr):.1f}" for C, _, Jr, _ in reversed(rows)) + " Z"
# onset marker
onset = f"M {px(C_star):.1f},{MT} L {px(C_star):.1f},{H-34}"
onset_dot = f"{px(C_star):.1f},{py(lam_star):.1f}"
# annotation text x/y (kept inside box)
ann_x, ann_y = px(C_star) - 6, py(lam_star) + 26

# --- panel 2: LP geometry at a C above onset (mix) vs below (pure resp) ---
C_geo = 2.0 * C_star
lam_g, (Jr_g, Jf_g) = solve(C_geo)
S = 300.0  # scale flux -> px for the geometry panel
ox, oy = 90, 330
gx = lambda j: ox + j * S * 0.55
gy = lambda j: oy - j * S
carb_line = f"M {gx(C/c_r):.1f},{gy(0):.1f} L {gx(0):.1f},{gy(C_geo/c_f):.1f}"
prot_line = f"M {gx(F/p_r):.1f},{gy(0):.1f} L {gx(0):.1f},{gy(F/p_f):.1f}"
opt_pt = f"{gx(Jr_g):.1f},{gy(Jf_g):.1f}"
low_pt = f"{gx(C_star*0.6/c_r):.1f},{gy(0):.1f}"

out = {
    "C_star": C_star, "lam_star": lam_star,
    "rows_head": rows[:3], "rows_mid": [r for r in rows if abs(r[0]-C_star) < 0.05][:3],
    "rows_tail": rows[-2:],
    "pure_resp_lam_at_Cstar": C_star / c_r,
    "svg": {"lam_path": lam_path, "resp_path": resp_path, "ferm_path": ferm_path,
            "onset": onset, "onset_dot": onset_dot, "ann_x": round(ann_x,1), "ann_y": round(ann_y,1),
            "carb_line": carb_line, "prot_line": prot_line, "opt_pt": opt_pt, "low_pt": low_pt},
}
print(json.dumps(out, indent=1))

What I would argue against

“Overflow is wasteful, so it must be a failure of regulation.” No: within the proteome-economics picture, excreting acetate is the optimal corner of a well-posed LP — the cell is rationally trading abundant carbon for scarce protein, and blocking overflow (e.g. forcing full respiration) would lower growth, exactly as Basan et al.’s proteome-cost measurements imply1. “Then the onset point is arbitrary / culture-dependent.” Also no: C* is pinned by only two things, the proteome budget F and the protein-per-flux cost of respiration (ar+αcr), so perturbing translation capacity or ribosome content should shift the onset predictably — which is the direction of the nutrient-shift versus chloramphen-shift asymmetry we saw in lecture 14: the two interventions move along different constraint axes, hence opposite effects on φ̇R2.
