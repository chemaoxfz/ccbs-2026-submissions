Week 2 — Extension: A constitutive gene can remember if it slows its own dilution

Author: Siheng Wang · Lectures 3–4 · due 2026-09-14 · CCBS 2026

One sentence: Combining Lecture 3's growth-dilution term with Lecture 4's three-crossing test shows that a constitutively produced protein can have two stable expression levels without cooperative transcription: enough protein slows growth, slower growth weakens dilution, and weaker dilution lets still more protein accumulate.

The point I am adding

Lecture 3 derives dilution from concentration bookkeeping: if cell volume grows at rate λ, every intracellular concentration receives the removal term −λx [1]. It then leaves a precise question open: if protein burden reduces λ, can dilution feedback create more than one steady level? Lecture 4 supplies the test—two stable states require addition and removal to cross stable–unstable–stable [2]. Put the two statements together and dilution stops being a passive drain. It becomes a feedback edge.

more proteinlarger circuit burden
⟶
slower growthλ decreases
⟶
weaker dilutionless −λx, so x rises

Use the smallest model that exposes this loop. Let x be a dimensionless concentration made at a constant rate α. Molecular degradation contributes δx. Growth decreases ultrasensitively with burden, λ(x) = 1/(1+x4). Then

dx/dt = α − x[δ + λ(x)],    λ(x) = 1/(1+x4).

The promoter is deliberately unregulated: addition is the horizontal line α. All nonlinearity sits in removal. At low x, growth is fast and dilution rises approximately as x. Near the burden threshold, λ collapses faster than x rises, so total removal can fall. At still larger x, molecular degradation δx wins and removal rises again. This N-shaped removal curve is enough for three crossings.

Work it

For the declared teaching values α=0.55 and δ=0.20, the model has fixed points at x≈0.478, 1.486 and 2.398. The slope of the net rate is negative, positive and negative respectively, so the outer crossings are stable and the middle one is the switching threshold. Starting below 1.486 reaches the low-expression, fast-growth state; starting above it reaches the high-expression, slow-growth state. History matters even though transcription itself has no Hill curve.

0.478stable · low expression
1.486unstable · threshold
2.398stable · high expression
Reproducible calculation embedded in this file 
# Python 3; no packages
alpha, delta, n = 0.55, 0.20, 4

def growth(x):
    return 1 / (1 + x**n)

def removal(x):
    return x * (delta + growth(x))

def net(x):
    return alpha - removal(x)

def bisect(a, b, steps=60):
    for _ in range(steps):
        m = (a + b) / 2
        if net(a) * net(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2

roots = [bisect(a, b) for a, b in
         [(0.4, 0.6), (1.4, 1.6), (2.3, 2.5)]]
print(roots)  # 0.478120, 1.486450, 2.398083

for x in roots:
    h = 1e-5
    slope = (net(x+h) - net(x-h)) / (2*h)
    print(x, slope)  # negative, positive, negative

# RK4 trajectories used in the right panel
def step(x, dt=0.02):
    k1 = net(x)
    k2 = net(x + dt*k1/2)
    k3 = net(x + dt*k2/2)
    k4 = net(x + dt*k3)
    return x + dt*(k1 + 2*k2 + 2*k3 + k4)/6

for x0 in (0.10, 1.00, 1.70, 3.20):
    x = x0
    for _ in range(2000):
        x = step(x)
    print(x0, x)

This mechanism is not only algebraic. Tan, Marguet and You built an E. coli circuit in which mutant T7 RNA polymerase activated its own expression noncooperatively. The circuit was nevertheless bistable; their measurements and model attributed the extra effective feedback to circuit-induced growth retardation and nonlinear dilution [3]. A later modeling study made the complementary prediction tested here: sufficiently ultrasensitive growth feedback can give a constitutive circuit bistability even without a direct positive-regulation edge [4].

The extension: a circuit diagram drawn only with transcriptional arrows is incomplete whenever its products measurably change host growth. The host supplies a hidden double-negative loop—protein inhibits growth, and growth dilutes protein—that can create memory or erase it depending on its shape.

What I would argue against / where this breaks

This toy model proves possibility, not typicality. Its fourth-power growth curve is an effective assumption; if λ(x) decreases gently, total removal stays monotone and constant production has only one crossing. The model also treats a population growth rate as the instantaneous dilution rate of one cell, holds production and degradation independent of growth, ignores resource competition and stochastic switching, and lets the high-expression branch approach very slow growth. Those omissions matter experimentally. The defensible conclusion is therefore conditional: growth feedback can create bistability when it makes the total removal curve nonmonotonic, not that burdened genes are generally bistable.
