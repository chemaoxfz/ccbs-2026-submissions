Week 2 Extension: Flux Can Recover without Enzyme Recovery

Author: Chengwei Jin · Week 2 (2026-09-09) · CCBS 2026

One sentence: After a finite irreversible inhibitor exposure, substrate accumulation can restore the original throughput despite permanent enzyme loss, provided the surviving catalytic capacity exceeds the constant supply.

The point I am adding

Lecture 3 holds an enzyme pool fixed and asks whether its capacity can balance input.1 I let that pool lose activity during an externally imposed inhibitor pulse. The question is whether a recovered product flux would prove that the enzyme recovered. In this model it would not: more substrate can compensate for fewer active enzymes. This is a theoretical extension, with illustrative parameters rather than a fitted inhibitor experiment.

Work it

Let bare symbols denote free concentrations and let CES denote the enzyme–substrate complex. Upstream supply is constant. H irreversibly inactivates free and bound enzyme at the same rate; inactivation of a complex releases its substrate. Einactive denotes the inactive reaction product, including the reacted inhibitor.

∅ ⇝ S   (rate vin) E + S ⇌ CES → E + P association k+ · dissociation k− · catalysis kcat E + H → Einactive CES + H → Einactive + S both inactivation steps: kinact

Define the active enzyme pool qE = E + CES and the unconverted substrate pool qS = S + CES. Summing mass-action balances cancels binding terms. Substituting E = qE − CES and S = qS − CES closes the exact model for the declared reactions:

dqE/dt = −kinactH(t)qE dqS/dt = vin − kcatCES dCES/dt = k+(qE − CES)(qS − CES) − [k− + kcat + kinactH(t)]CES.

H(t) equals H0 for an exposure lasting T, starting at t0, and is zero otherwise. This assumes excess inhibitor during exposure and selective removal afterward. Integration gives the surviving active fraction a∞ = exp(−kinactH0T). Washout stops further inactivation; it does not reactivate enzyme.

After washout, a finite steady state requires kcatqE,∞ > vin. At that state, CES* = vin/kcat and:

S* = KMvinkcatqE,∞ − vin,   qS* = S* + vinkcat KM = (k− + kcat)/k+

These are exact steady-state identities, not a quasi-steady approximation. With the parameters below, a 20-minute exposure at H0 = 0.20 μM leaves 67.0% activity. The predicted substrate pool rises from 1.50 to 3.44 μM while flux returns to the input. At 0.50 μM, only 36.8% activity survives, leaving insufficient capacity. The calculated threshold for this exposure duration is H0 < 0.347 μM.

Step-by-step derivation and assumptions

The five internal event rates are k+ES, k−CES, kcatCES, kinactHE, and kinactHCES. Each contributes a positive sign where it produces a species and a negative sign where it consumes one.

dE/dt = −k+ES + (k− + kcat)CES − kinactHEdS/dt = vin − k+ES + k−CES + kinactHCESdCES/dt = k+ES − (k− + kcat + kinactH)CES

Add the E and complex equations to obtain dqE/dt. Add the S and complex equations to obtain dqS/dt. Inactivation cancels only from the latter because it releases, rather than destroys, the substrate. Active plus inactive enzyme is conserved. Product generation is vcat = kcatCES; P itself would accumulate without an outlet.

If inhibitor consumption were tracked, dH/dt = −kinactHqE. We instead prescribe H(t), representing an externally maintained free concentration or the excess-inhibitor limit. Selective washout changes H without removing substrate or enzyme. A scheduled exposure makes the model nonautonomous during treatment.1

Separating dqE/qE = −kinactH(t)dt gives qE(t)/qE,0 = exp[−kinact∫H(t)dt]. Rectangular exposure gives the expression in the main text.

After washout, set dqS/dt = dCES/dt = 0. Then CES* = vin/kcat, E* = qE,∞ − CES*, and E*S* = KMCES*. Positive finite S* needs E* > 0, giving the strict capacity condition. Equality supplies no finite steady state when KM and input are positive.

The post-washout Jacobian in (qS, CES) has entries [0, −kcat; k+E*, −k+(E* + S*) − k− − kcat]. Its trace is negative and determinant kcatk+E* is positive, proving local attraction using Lecture 4.2 Simulation demonstrates recovery from the selected exposure, not a proof for every initial state.

Fast binding is not assumed in the integration. When inhibition is rapid, replacing the complex immediately by its usual Michaelis–Menten value need not be valid.

Parameters, numerical method and runnable source

All parameters are chosen for demonstration. Concentrations are in μM and time in minutes. k+ = 4 μM−1 min−1; k− = kcat = 2 min−1; kinact = 0.1 μM−1 min−1; vin = 1 μM min−1; qE,0 = 1 μM. Initially CES = 0.5 μM and qS = 1.5 μM, the untreated steady state. Exposure starts at 10 min; observation ends at 120 min.

The code below is the actual browser model. Copy into model.js and run with Node, for example: console.log(simulate(0.2,20));. RK4 steps shrink with the fastest reaction scale and stop at pulse boundaries. Independent SciPy DOP853 checks across seven cases gave maximum absolute disagreement below 10−8 μM. Positivity, complex bounds and the exact active-enzyme trajectory were checked.

/* Illustrative units: concentration uM, time min. No fitted inhibitor data.
   State: [active enzyme total qE, unconverted substrate total qS, complex C_ES]. */
const PARAM = Object.freeze({kp:4, km:2, cat:2, kinact:0.1, input:1, enzyme:1, start:10, end:120});
function rhs(y,H){
  const [e,s,c]=y,p=PARAM;
  return [-p.kinact*H*e,p.input-p.cat*c,p.kp*(e-c)*(s-c)-(p.km+p.cat+p.kinact*H)*c];
}
function rk4(y,h,H){
  const a=rhs(y,H),b=rhs(y.map((v,i)=>v+h*a[i]/2),H);
  const c=rhs(y.map((v,i)=>v+h*b[i]/2),H),d=rhs(y.map((v,i)=>v+h*c[i]),H);
  return y.map((v,i)=>v+h*(a[i]+2*b[i]+2*c[i]+d[i])/6);
}
function simulate(H0=0.2,duration=20){
  let y=[1,1.5,0.5],t=0; const out=[[0,...y]],stop=PARAM.start+duration;
  for(let n=1;n<=1200;n++){
    const target=n/10;
    while(t<target-1e-10){
      let boundary=target;
      if(t<PARAM.start-1e-10) boundary=Math.min(boundary,PARAM.start);
      if(t<stop-1e-10) boundary=Math.min(boundary,stop);
      const h=Math.min(boundary-t,0.02,0.3/(PARAM.kp*(y[0]+y[1])+PARAM.km+PARAM.cat+PARAM.kinact*H0));
      const mid=t+h/2,H=mid>=PARAM.start&&mid<stop?H0:0;
      y=rk4(y,h,H);t+=h;
    }
    out.push([target,...y]);
  }
  return out;
}
if(typeof module!=='undefined') module.exports={PARAM,rhs,rk4,simulate};

What I would argue against / where this breaks

A recovered flux is not evidence of restored enzyme activity. Here the compensation is paid for by a larger substrate pool, and it fails at the capacity threshold. Equal susceptibility of free and bound enzyme, intact substrate release, imposed inhibitor concentration and unchanged surviving-enzyme kinetics are assumptions. This is not an EDTA model. Growth, repair, regulated supply or inhibitor depletion require additional equations; fixed volume and no replenishment are deliberate departures from a growing cell.1
