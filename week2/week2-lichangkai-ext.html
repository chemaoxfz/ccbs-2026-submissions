Week 2 — Extension: A 10% asymmetry biases a genetic toggle without destroying memory

Author: Changkai Li · Week 2 (Lectures 3–4) · CCBS 2026

One sentence: In the Lecture 4 toggle, increasing only X's maximal production by 10% preserves two stable states, but on a uniform 101×101 grid of initial conditions in [0,5]² it expands the high-X basin from 50.0% to 62.0%: bistability survives while accessibility becomes biased.

The point I am adding

Lecture 4 uses the symmetric teaching model

ẋ = 4/(1+y²) − x,    ẏ = 4/(1+x²) − y.

That symmetry makes the diagonal x=y invariant, so the two memory states have mirror-image basins. But symmetry is a convenience, not a biological requirement: the more general reduced toggle has separate maximal production rates for the two arms. I therefore changed exactly one assumption: I kept the Y arm at αY=4 and increased the X arm by 10%, to αX=4.4:

ẋ = 4.4/(1+y²) − x,    ẏ = 4/(1+x²) − y.

The 10% is a deliberately small sensitivity test, not a measured experimental mismatch. The question is whether a small asymmetry destroys memory, or merely biases which memory is easier to reach.

Work it

1. The fixed points survive

I solved ẋ=ẏ=0 numerically and classified each fixed point from the eigenvalues of the Jacobian. The asymmetric system still has three fixed points:

fixed point (x*, y*)Jacobian eigenvalueslocal typestate
(0.3061, 3.6574)-0.4354, -1.5646stable nodelow X / high Y
(1.2094, 1.6242)+0.3125, -2.3125saddlesaddle
(4.2076, 0.2139)-0.5931, -1.4069stable nodehigh X / low Y

So a 10% production mismatch does not remove bistability. The high-X attractor moves outward to x≈4.208, the low-X attractor shifts toward larger x, and the saddle moves off the diagonal. Local stability alone, however, does not say how much of state space belongs to each attractor.

2. The basin boundary moves much more than the fixed-point count

I integrated the ODEs from every point on a 101×101 uniform grid over 0≤x0,y0≤5 using fourth-order Runge–Kutta (T=30, Δt=0.02), then assigned each endpoint to the nearer stable fixed point. In the symmetric system, the 101 grid points exactly on x=y approach the saddle; after excluding those threshold seeds, the remaining points split exactly 50:50 by symmetry. With αX=4.4, 62.02% of the grid flows to the high-X state and 37.98% to the low-X state.

Result: the qualitative statement “this circuit has two memories” is robust to this perturbation, but the quantitative statement “the two memories are equally accessible” is not. A 10% parameter change produces a 12.0-percentage-point shift in basin share under this sampling convention.

3. How much asymmetry would actually destroy the memory?

To find the folds, I solved the two steady-state equations together with det(J)=0. With αY=4, the model is bistable only for approximately

3.229 < αX < 5.796.

Thus the 10% increase to 4.4 is safely inside the bistable window. If αX rises to about 5.796, the low-X attractor and the saddle collide in a saddle-node bifurcation; if it falls below about 3.229, the opposite memory disappears. The basin can become strongly biased well before the fixed-point count changes.

What I would argue against / where this breaks

I would not interpret 62.0% as a biological probability of choosing the high-X state. It is a geometric fraction under one arbitrary measure: uniformly sampling the square [0,5]². A different initial-condition distribution or a different box changes the number. More importantly, this is a deterministic two-variable reduction. Molecular noise can drive rare transitions across the separatrix; unequal degradation rates, repression constants or Hill exponents can reshape it again; and the Hill laws assume fast hidden promoter-state dynamics. The defensible claim is narrower: for this reduced model and this defined sampling experiment, small expression asymmetry biases basin geometry before it destroys bistability.

This also separates two notions of robustness. Structural robustness asks whether two stable states still exist. operational robustness asks whether both states remain comparably reachable under the perturbations and initial conditions a cell actually experiences. The first survives this 10% change; the second already shifts substantially.

Reproducible code

Python 3 with NumPy, SciPy and Matplotlib. The code below recomputes the fixed points, Jacobian eigenvalues, basin fractions, saddle-node thresholds and the two basin figures. No numerical result in the essay is copied from the lecture page.

Show Python code 
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import root

def rhs(x, y, alpha_x=4.0, alpha_y=4.0):
    return alpha_x/(1+y*y)-x, alpha_y/(1+x*x)-y

def J(x, y, alpha_x=4.0, alpha_y=4.0):
    return np.array([
        [-1, -2*alpha_x*y/(1+y*y)**2],
        [-2*alpha_y*x/(1+x*x)**2, -1]
    ])

def fixed_points(alpha_x, alpha_y):
    ans = []
    for x0 in np.linspace(0, 5, 11):
        for y0 in np.linspace(0, 5, 11):
            s = root(lambda z: rhs(z[0], z[1], alpha_x, alpha_y), [x0, y0])
            if s.success and np.all(s.x >= -1e-9):
                if max(abs(np.array(rhs(*s.x, alpha_x, alpha_y)))) < 1e-8:
                    if not any(np.linalg.norm(s.x-q) < 1e-6 for q in ans):
                        ans.append(s.x)
    return sorted(ans, key=lambda z: z[0])

def basin(alpha_x, alpha_y=4.0, n=101, T=30.0, dt=0.02):
    g = np.linspace(0, 5, n)
    X0, Y0 = np.meshgrid(g, g)
    x, y = X0.copy(), Y0.copy()

    # Vectorized RK4: all 10,201 initial conditions evolve in parallel.
    for _ in range(int(T/dt)):
        k1x,k1y = rhs(x,y,alpha_x,alpha_y)
        k2x,k2y = rhs(x+dt*k1x/2,y+dt*k1y/2,alpha_x,alpha_y)
        k3x,k3y = rhs(x+dt*k2x/2,y+dt*k2y/2,alpha_x,alpha_y)
        k4x,k4y = rhs(x+dt*k3x,y+dt*k3y,alpha_x,alpha_y)
        x += dt*(k1x+2*k2x+2*k3x+k4x)/6
        y += dt*(k1y+2*k2y+2*k3y+k4y)/6

    low, saddle, high = map(np.asarray, fixed_points(alpha_x, alpha_y))
    dlow = (x-low[0])**2 + (y-low[1])**2
    dhigh = (x-high[0])**2 + (y-high[1])**2
    cls = (dhigh < dlow).astype(int)

    # Symmetric seeds exactly on x=y approach the saddle; exclude them
    # when quoting the two basin fractions.
    dsad = np.sqrt((x-saddle[0])**2 + (y-saddle[1])**2)
    threshold = dsad < 1e-4
    return X0, Y0, cls, threshold

# Fixed points and eigenvalues for the 10% asymmetric case.
fps = fixed_points(4.4, 4.0)
for p in fps:
    print(p, np.linalg.eigvals(J(*p, 4.4, 4.0)))

# Basin fractions in the square [0,5] x [0,5].
for ax in (4.0, 4.4):
    X0,Y0,c,t = basin(ax)
    keep = ~t
    print(ax, "high-X basin =", np.mean(c[keep] == 1))

# Fold thresholds: solve dx=0, dy=0 and det(J)=0 simultaneously.
def fold_eq(z):
    x,y,ax = z
    return (*rhs(x,y,ax,4.0), np.linalg.det(J(x,y,ax,4.0)))

for guess in ([2.2,0.65,3.2], [0.62,2.88,5.8]):
    print("fold:", root(fold_eq, guess).x)

# Basin figure (run once with ax=4.0 and once with ax=4.4).
def plot_basin(axmax):
    X0,Y0,c,t = basin(axmax)
    fps = fixed_points(axmax,4.0)
    fig, ax = plt.subplots(figsize=(6.2,5.2))
    ax.imshow(c, origin="lower", extent=(0,5,0,5),
              interpolation="nearest", alpha=0.6, aspect="equal")
    z = np.linspace(0,5,500)
    ax.plot(axmax/(1+z*z), z, linewidth=2, label="x-nullcline")
    ax.plot(z, 4/(1+z*z), linewidth=2, label="y-nullcline")
    for i,p in enumerate(fps):
        ax.scatter(*p, marker="x" if i==1 else "o", s=70)
    if axmax == 4.0:
        ax.plot(z,z,linestyle="--",label="separatrix x=y")
    ax.set(xlim=(0,5), ylim=(0,5), xlabel="x", ylabel="y")
    ax.legend(frameon=False)
    plt.show()

plot_basin(4.0)
plot_basin(4.4)
