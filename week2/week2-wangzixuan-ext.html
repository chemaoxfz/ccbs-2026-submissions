Why a two-variable genetic toggle can remember but cannot keep time

Zixuan Wang · Week 2 (2026-09-14) · CCBS 2026

One sentence: When it is bistable, the reduced two-variable mutual-repression toggle can store one bit, but its strictly negative divergence rules out an autonomous limit cycle for every parameter choice within this model class.

The point I am adding

Lecture 4 proves that one autonomous state variable cannot sustain a nonconstant cycle, while a second variable creates enough geometric room to go around [1]. It then builds a two-variable mutual-repression toggle with two stable expression states. Does being two-dimensional mean that the same circuit could also become a clock? No: dimension grants permission, but the toggle's particular vector field takes that permission away.

Write the whole reduced model family as

dx/dt = p(y) − δxx,    dy/dt = q(x) − δyy.

Here p and q are continuously differentiable, cross-regulated production laws—Hill repression is one choice—and δx, δy > 0 are linear loss rates combining degradation and dilution. The proof does not need the Hill coefficients, maximal production rates or exact fixed-point locations.

One derivative rules out a clock

The divergence is the trace of the Jacobian evaluated at every point, rather than only at a fixed point. Cross-regulation disappears from that trace:

div F = ∂(dx/dt)/∂x + ∂(dy/dt)/∂y = −δx − δy < 0.

Suppose a periodic orbit existed. Let its closed curve C enclose a region Ω in the positive concentration plane. Along C, the vector field is tangent to the trajectory, so its outward normal flux is zero. Green's theorem gives a second value for exactly the same flux:

0 = ∮C F·n ds = ∬Ω div F dA = −(δx+ δy) |Ω| < 0.

That contradiction is Bendixson's criterion (the Bendixson–Dulac criterion with Dulac function 1) [2]. Therefore this autonomous two-variable model has no nonconstant periodic orbit.

The same calculation gives useful intuition. Any material patch of initial conditions contracts in phase-space area as

A(t) = A(0) exp[−(δx+ δy)t].

Area contraction does not mean that both concentrations always decrease, or that every pair of trajectories gets closer: a saddle still contracts in one direction and expands in another. The Green-theorem contradiction, not a few simulated paths, is the global no-cycle certificate.

Work it: the Lecture 4 toggle

For the symmetric teaching model

dx/dt = 4/(1+y2) − x,    dy/dt = 4/(1+x2) − y,

the nullclines intersect at two stable nodes, (3.732, 0.268) and (0.268, 3.732), and a central saddle, (1.379, 1.379). The exact symmetry makes x = y the separatrix. Figure 1 shows the two memory basins with equal horizontal and vertical scales. Figure 2 then separates the numerical picture from the structural proof that no initial condition can settle onto a sustained cycle.

The trajectories suggest two memories and no cycle, but a finite simulation cannot prove that a cycle is absent elsewhere. The divergence calculation supplies that missing global argument:

Python code for the calculations underlying Figure 1 
import numpy as np
import matplotlib.pyplot as plt

def field(z):
    x, y = z
    return np.array([4 / (1 + y*y) - x,
                     4 / (1 + x*x) - y])

def jacobian(z):
    x, y = z
    return np.array([
        [-1, -8*y / (1 + y*y)**2],
        [-8*x / (1 + x*x)**2, -1]
    ])

def newton(guess):
    z = np.array(guess, dtype=float)
    for _ in range(30):
        step = np.linalg.solve(jacobian(z), field(z))
        z -= step
        if np.linalg.norm(step) < 1e-12:
            break
    return z

def rk4(seed, dt=0.01, T=12):
    z = np.array(seed, dtype=float)
    out = [z.copy()]
    for _ in range(round(T / dt)):
        k1 = field(z)
        k2 = field(z + dt*k1/2)
        k3 = field(z + dt*k2/2)
        k4 = field(z + dt*k3)
        z += dt*(k1 + 2*k2 + 2*k3 + k4)/6
        out.append(z.copy())
    return np.array(out)

guesses = [(0.2, 3.8), (1.4, 1.4), (3.8, 0.2)]
fixed = [newton(g) for g in guesses]
for z in fixed:
    print(z, np.linalg.eigvals(jacobian(z)))

s = np.linspace(0, 4.2, 500)
fig, ax = plt.subplots(figsize=(6, 6))
ax.plot(4/(1+s*s), s, label="dx/dt = 0")
ax.plot(s, 4/(1+s*s), label="dy/dt = 0")
ax.plot(s, s, "--", color="0.55", label="separatrix")

seeds = [(.45, .65), (.65, .45)]
for seed in seeds:
    path = rk4(seed)
    ax.plot(path[:, 0], path[:, 1], color="#72599b", lw=1.8)
    ax.plot(*seed, marker="o", ms=5, color="white",
            markeredgecolor="#72599b")

ax.scatter(*zip(*fixed), zorder=4)
ax.set(xlim=(0, 4.2), ylim=(0, 4.2),
       xlabel="relative amount of X", ylabel="relative amount of Y",
       aspect="equal")
ax.legend(frameon=False)
fig.tight_layout()
plt.show()

What the proof does—and does not—say

The conclusion is deliberately narrow. It excludes deterministic, sustained, autonomous oscillation in the smooth two-variable model above. It does not exclude damped transients, noise-driven switching, or tracking of a periodically forced input. Nor does negative divergence by itself create bistability; the nullclines still need two stable intersections separated by a saddle.

The certificate can also disappear when the model gains biology. Self-regulation or state-dependent removal changes the divergence. Explicit mRNA or promoter states raise the dimension. A time delay means that (x, y) is no longer the complete state, and external forcing makes the system nonautonomous. In those cases this proof becomes inconclusive—not reversed. A different architecture really can keep time: the three-repressor repressilator produced oscillatory fluorescence in Escherichia coli [4].

The distinction is the extension's point. Gardner, Cantor and Collins experimentally built the mutually inhibitory toggle as a bistable cellular memory [3]. The reduced model's no-cycle result is not a new experimental claim about every circuit carrying those parts. It is a structural theorem about a declared model class, precise enough to say which added mechanism would invalidate it.
