Week 2 — Extension: When deterministic balance is not enough

Author: Fang Lipei · Student ID: 20261203497 · Week 2 (2026-09-13) · CCBS 2026

One sentence: A mass-action ODE predicts the mean trajectory of a reaction network, but at finite molecule numbers the same network is a random jump process whose fluctuations can be as important as its mean.

The point I am adding

Lectures 3 and 4 turn reaction arrows into a deterministic vector field, then use crossings, nullclines and Jacobians to reason about possible behaviors. That is the right description when concentrations are large enough to be treated as smooth variables. It is not the complete description of a cell: a molecule is made, waits a random time, and is then removed. A cell with ten copies of a regulator cannot literally contain a concentration of 10.37 copies.

For the smallest useful example, let X be produced from an external source and degraded:

∅ → X at rate α,    X → ∅ at rate γn

Here n is an integer molecule count. The deterministic model is d x/dt = α − γx, so an initially empty cell approaches the steady mean x* = α/γ. The stochastic model instead assigns a propensity to each possible jump: the birth propensity is α, and the death propensity is γn. Gillespie's stochastic simulation algorithm samples the next reaction time and then chooses which reaction occurred. This adds no new biochemical arrow; it changes the accounting from smooth rates to discrete events.

The important consequence is quantitative. At stationarity this birth–death process has a Poisson distribution with mean α/γ, so its variance is also α/γ. Its coefficient of variation is therefore 1/√x*. Ten molecules have an intrinsic relative noise of about 32%; one hundred molecules have about 10%. Thus a stable deterministic fixed point does not mean every cell sits exactly at that value.

Work it

I simulated four independent cells with α = 2 molecules/min and γ = 0.2 min−1. The deterministic steady state is x* = 10 molecules and the relaxation time is 1/γ = 5 min. Each trace below starts at zero, but after the transient the cells fluctuate around the same mean rather than following the same path. The plotted trajectories use a fixed-seed implementation of the direct Gillespie algorithm; the code is included below the figure.

// Direct Gillespie SSA, one cell
alpha = 2; gamma = 0.2; t = 0; n = 0
while t < 20:
    a_birth = alpha
    a_death = gamma * n
    a_total = a_birth + a_death
    tau = -log(U()) / a_total
    t = t + tau
    if U() < a_birth / a_total:
        n = n + 1
    else:
        n = max(0, n - 1)
record n whenever t crosses the next minute

For this parameter choice, the predicted long-time variance is 10 molecules2, and the predicted coefficient of variation is 1/√10 ≈ 0.316. A practical simulation estimate will differ because four short traces are a small sample; that sampling error is itself a reminder that a single trajectory cannot establish a distribution.

What I would argue against / where this breaks

I would argue against treating every ODE fixed point as a cell-level prediction. The ODE still gets the mean exactly for this linear birth–death example, and at very large molecule counts the relative fluctuations become small. It is also much cheaper for a large network. But nonlinear reactions do not generally preserve this simplicity: for example, the mean of a product is not the product of the means, so replacing random species by their averages can change the predicted regulatory response. Noise can also trigger switching between deterministic basins, blur a bifurcation, or make an apparently stable state biologically unreliable.

The stochastic description is not automatically better. Gillespie simulation can be expensive when reactions are numerous or have widely separated timescales, and the rates still need experimental justification. A defensible workflow is therefore to ask which claim is needed: use the ODE for structural geometry and average behavior, then use a chemical master equation or SSA when copy-number fluctuations, event timing, or switching probabilities are part of the biological question.
