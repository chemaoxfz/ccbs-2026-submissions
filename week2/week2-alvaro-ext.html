Week 2 — Extension: how a cell subtracts — sequestration is biology's answer to "chemistry forbids most vector fields"

Author: Álvaro Bátrez · Week 2 (lectures 3–4) · 2026-09-14 · CCBS 2026

One sentence: the lecture's toggle equation appears to contain a negative interaction, but chemistry cannot subtract — the cell implements the "minus" by sequestration, and a from-scratch simulation of the full mass-action network shows the compact Hill model we analyze is exact for steady states yet fails, by a factor of two in switching time, when binding is slow.

The point I am adding

Lecture 4 closed with a constraint the zoo of phase portraits quietly ignores: a reaction network ẋ = Γv(x) (lecture 3) lives in the positive orthant, and every elementary event of mass-action kinetics only produces or transforms molecules. "Chemistry forbids most vector fields." Yet the toggle analyzed in the lecture and in my exposition is written as

Ẋ = α/(1 + (Y/K)ⁿ) − δX

with a repressive arrow, Y ⊣ G_X, behind it. That looks like subtraction, and a cell cannot implement "minus Y": there is no anti-protein, no negative flux. The trick biology uses instead is competition for a shared, conserved resource — the promoter. At the chemical level the "⊣" is not a negative term at all but a reversible binding reaction,

G + nY ⇌ C   (rates kon, koff),   G + C = q conserved,

with protein produced only from the free promoter G. Every rate law in the resulting network is a positive monomial: this is exactly the chemistry the lecture permits, and repression emerges because Y and the production machinery sequester each other. It is the native biological version of the dual-rail annihilation x₊ + x₋ → ∅ that the core page mentions as the generic repair for forbidden fields — and the same logic reappears in kinase–phosphatase pairs, miRNA–mRNA and receptor–ligand sequestration throughout the cell.

Work it — what the full network does that the Hill equation cannot

Solving the binding equilibrium at a fixed point gives G/q = 1/(1 + (Y/K)ⁿ) with K = (koff/kon)1/n: this is where the lecture's Hill repression comes from. But using it as a dynamical equation assumes promoter binding is fast compared with protein accumulation. That assumption is checkable, so I checked it. I built the full 6-species mass-action toggle (free and occupied promoters for both genes, plus the two proteins) and simulated it against the reduced Hill toggle with identical equilibrium parameters (α = 50, δ = 1, K = 0.5, n = 2, q = 1), varying only the binding speed: kon = 20 (fast) and 0.2 (comparable to dilution), with koff = konK² so the equilibrium constant never changes.

Two findings. First, the fixed points match exactly — for both binding speeds the full network settles on (0.005, 49.995), (2.285, 2.285) and (49.995, 0.005), numerically identical to the reduced model (verified to residual < 10⁻⁶). This is not luck: at any steady state binding and unbinding balance, so the promoter sits at its equilibrium occupancy no matter how slowly, and the Hill reduction of the nullclines is algebraically exact. Timescale separation is needed for dynamics, not for steady states.

Second, the dynamics do not match when binding is slow. I started the switch exactly on the separatrix (the diagonal saddle at (2.285, 2.285)) with a 1% bias toward X winning, and measured when the loser Y is repressed below half the saddle level:

modelbinding speedY crosses 1.14 at t =
reduced Hill toggle(instantaneous occupancy)4.77

With fast binding the full chemical network is indistinguishable from the Hill toggle: the compact equation we analyze is earned. With slow binding the trajectory is the same story told at half speed — repression takes effect only as fast as promoter turnover allows, a measurable delay that the forbidden vector field, with its instantaneous minus sign, cannot have.

The code

Self-written; runs with NumPy, SciPy and Matplotlib. It prints the fixed points and switching times listed above and renders both figures.

import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import fsolve

# Reduced Hill toggle (the lecture's equations)
ALPHA, DELTA, K, N = 50.0, 1.0, 0.5, 2

def reduced(t, s):
    x, y = s
    return [ALPHA/(1+(y/K)**N) - DELTA*x, ALPHA/(1+(x/K)**N) - DELTA*y]

# Full mass-action toggle: Gx + n Y <-> Cx (pool Gx + Cx = 1),
# production only from the free promoter, first-order dilution.
def make_full(kon):
    koff = kon * K**N               # keeps the equilibrium Kd identical
    def f(t, s):
        Gx, Cx, X, Gy, Cy, Y = s
        bx, rx = kon*Gx*Y**N, koff*Cx    # gene X promoter, bound by Y
        by, ry = kon*Gy*X**N, koff*Cy    # gene Y promoter, bound by X
        return [-bx+rx, bx-rx, ALPHA*Gx - DELTA*X,
                -by+ry, by-ry, ALPHA*Gy - DELTA*Y]
    return f

# Fixed points of the full network: stable nodes by long simulation,
# the saddle exactly on the invariant diagonal.
def fps_full(kon):
    f = make_full(kon)
    G0 = lambda v: 1/(1+(v/K)**N)
    out = []
    for gx, gy in [(0.01, 40), (40, 0.01)]:
        s0 = [G0(gy), 1-G0(gy), gx, G0(gx), 1-G0(gx), gy]
        sol = solve_ivp(f, [0, 5000], s0, method="LSODA", rtol=1e-10, atol=1e-12)
        out.append((sol.y[2,-1], sol.y[5,-1]))
    sd = fsolve(lambda s: ALPHA*G0(s) - s, 2.285)[0]   # saddle, on diagonal
    out.append((sd, sd))
    return sorted(out)

# Switching test: start on the separatrix, 1% bias toward X winning.
def full_traj(kon, ic2, T=120):
    f = make_full(kon); G0 = lambda v: 1/(1+(v/K)**N)
    s0 = [G0(ic2[1]), 1-G0(ic2[1]), ic2[0], G0(ic2[0]), 1-G0(ic2[0]), ic2[1]]
    sol = solve_ivp(f, [0, T], s0, method="LSODA", rtol=1e-9, atol=1e-11,
                    max_step=0.05, dense_output=True)
    t = np.linspace(0, T, 1200); y = sol.sol(t)
    return t, y[2], y[5]

ic2 = [2.2849*1.01, 2.2849*0.99]
for kon in (20.0, 0.2):
    t, X, Y = full_traj(kon, ic2)
    i = np.where(np.diff(np.sign(Y - 1.142)))[0][0]    # Y falls below half-saddle
    print(f"k_on={kon}: fixed points {fps_full(kon)}, "
          f"Y crosses half-height at t={t[i]:.2f}")

What I would argue against / where this breaks

The tidy split — exact steady states, delayed dynamics — is specific to how I built the reduction. It holds because the promoter pool is strictly conserved and binding is a genuinely reversible elementary reaction; break either idealization and even the fixed points shift. Concretely: if the repressor also degrades while bound (so the pool leaks), or if production leaks from the occupied promoter too (basal expression, as in the self-regulated gene of my exposition, which needed exactly such a 0.15 basal term), the Hill nullclines become approximations even at steady state, with a basal offset that grows with occupancy. And the two-timescale story is the weakest link in the other direction: for very slow binding the promoter is no longer at quasi-equilibrium during transients at all, so the right reduction is not a Hill function but a model with explicit promoter states — which is why lecture 6's QSSA machinery, not a bigger Hill coefficient, is the honest tool there. Finally, my "delay" was measured on one trajectory; a skeptic should ask for the switching-time distribution under molecular noise before calling it a design constraint rather than a curiosity.
