Week 2 — Extension: Connecting growth dilution to single-resource feedback

Author: Zheng Haobo · Week 2 (2026-09-14) · CCBS 2026

One sentence: The complete square-wave switch has no single time-invariant fixed point valid for all times; each constant-input platform can define its own equilibrium, but a finite pulse trajectory may not reach it.

The point I am adding

The course quotient rule writes concentration change as a reaction term minus a shared dilution term: with fixed λ, the minimal model is x˙=a−λx, so the fixed point is x∗=a/λ (see Sources 1). This result is not wrong; what I question is treating λ as independent of system state during the pulse.

Adding one resource state turns this assumption into a testable minimal model: x˙=a−λ(r)x,r˙=ρ(u(t)−r)−γxr,λ(r)=λmaxrKr+rHere r is normalized resource, u(t) is external nutrient input, and γxr is resource consumption. Resource-allocation studies link growth rate to proteome and resource limitation rather than treating growth feedback as a universal one-way rule (Sources 2–4). The saturation function and parameters here are minimal-model choices, not measured parameters copied from papers.

Work it

I use the same square-wave input u(t)=1.8 (8≤t<14), and 1.0 otherwise; I integrate to t=50 with a fourth-order Runge–Kutta method using an event-aligned segmented step size of 0.01. The input u is held constant within [0,8], [8,14], and [14,50], and the segments are concatenated, so no step crosses an input jump. The fixed λ baseline uses λ at the pre-pulse resource steady state rather than a separately chosen favorable value, so both models start from the same (x0,r0).

The calculation gives the following. Before and after the pulse, the joint equilibrium at constant input u=1.0 is (x∗,r∗,λ(r∗))=(1.0432,0.7968,0.7669); the pulse platform u=1.8 has its own joint equilibrium (0.8687,1.4847,0.9209), but a finite six-time-unit trajectory may not reach it. In the resource-feedback model, the minimum x is 0.8718, the maximum deviation from x₀ is 0.1714, and the deviation at pulse end is 0.1714. The fixed λ baseline starts exactly at the x₀=a/λ₀ steady state, and its x equation contains no u(t), so x=x₀ throughout: it has no pulse deviation, and its recovery time is 0.00 by construction. The feedback model needs 5.88 time units after pulse end to return within 1% of x₀; this is the feedback model's deviation/recovery, not a symmetric time difference between the two models. The peak resource is 1.4812, and the peak growth rate is 0.9204.

Show the complete Python source
#!/usr/bin/env python3
"""Simulate a nutrient pulse in fixed-growth and resource-feedback models."""
from math import isfinite


# All quantities are dimensionless and time uses an arbitrary scaled unit.
P = {
    "a": 0.8,
    "lambda_max": 1.2,
    "K_r": 0.45,
    "rho": 0.9,
    "gamma": 0.22,
    "u_base": 1.0,
    "pulse_amp": 0.8,
    "pulse_start": 8.0,
    "pulse_end": 14.0,
    "t_end": 50.0,
    "dt": 0.01,
}


def pulse(t):
    """Return the square-wave nutrient input at time t."""
    if P["pulse_start"] <= t < P["pulse_end"]:
        return P["u_base"] + P["pulse_amp"]
    return P["u_base"]


def lambda_of_r(r):
    """Convert resource state to growth rate."""
    r = max(0.0, r)
    return P["lambda_max"] * r / (P["K_r"] + r)


def resource_root(u):
    """Find the positive resource level at a constant input."""
    def balance(r):
        lam = lambda_of_r(r)
        x = P["a"] / lam if lam > 0 else float("inf")
        return r - P["rho"] * u / (P["rho"] + P["gamma"] * x)

    lo, hi = 1e-10, max(1.0, u)
    while balance(lo) * balance(hi) > 0:
        hi *= 2.0
        if hi > 1e6:
            raise RuntimeError("could not bracket the positive resource fixed point")
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        if balance(lo) * balance(mid) <= 0:
            hi = mid
        else:
            lo = mid
    return 0.5 * (lo + hi)


r0 = resource_root(P["u_base"])
x0 = P["a"] / lambda_of_r(r0)
lambda0 = lambda_of_r(r0)
r_pulse_star = resource_root(P["u_base"] + P["pulse_amp"])
x_pulse_star = P["a"] / lambda_of_r(r_pulse_star)
lambda_pulse_star = lambda_of_r(r_pulse_star)


def rhs_feedback(t, state, u):
    """Evaluate the resource-feedback vector field."""
    x, r = state
    lam = lambda_of_r(r)
    return (P["a"] - lam * x,
            P["rho"] * (u - r) - P["gamma"] * x * r)


def rhs_fixed(t, state, u):
    """Evaluate the fixed-growth-rate baseline vector field."""
    x, r = state
    return (P["a"] - lambda0 * x,
            P["rho"] * (u - r) - P["gamma"] * x * r)


def rk4_step(rhs, t, state, dt, u):
    """Advance one step while holding the input constant."""
    k1 = rhs(t, state, u)
    s2 = tuple(state[j] + 0.5 * dt * k1[j] for j in range(2))
    k2 = rhs(t + 0.5 * dt, s2, u)
    s3 = tuple(state[j] + 0.5 * dt * k2[j] for j in range(2))
    k3 = rhs(t + 0.5 * dt, s3, u)
    s4 = tuple(state[j] + dt * k3[j] for j in range(2))
    k4 = rhs(t + dt, s4, u)
    return tuple(state[j] + dt * (k1[j] + 2 * k2[j] + 2 * k3[j] + k4[j]) / 6.0 for j in range(2))


def simulate(rhs, fixed_lambda=False):
    """Integrate event-aligned segments so RK4 never crosses a jump."""
    segments = (
        (0.0, P["pulse_start"], P["u_base"]),
        (P["pulse_start"], P["pulse_end"], P["u_base"] + P["pulse_amp"]),
        (P["pulse_end"], P["t_end"], P["u_base"]),
    )
    state = (x0, r0)
    rows = []
    for segment_index, (t_start, t_stop, u) in enumerate(segments):
        n_steps = int(round((t_stop - t_start) / P["dt"]))
        t = t_start
        if segment_index == 0:
            rows.append((t, state[0], state[1], lambda0 if fixed_lambda else lambda_of_r(state[1])))
        for step in range(n_steps):
            state = rk4_step(rhs, t, state, P["dt"], u)
            if not all(isfinite(v) for v in state):
                raise RuntimeError("non-finite state encountered")
            t = t_start + (step + 1) * P["dt"]
            lam = lambda0 if fixed_lambda else lambda_of_r(state[1])
            rows.append((t, state[0], state[1], lam))
    return rows


def nearest(rows, time):
    """Return the trajectory row nearest to a requested time."""
    return min(rows, key=lambda row: abs(row[0] - time))


def recovery_time(rows, target, start, relative_tolerance=0.01):
    """Return the first post-pulse time that remains within tolerance."""
    start_i = next(i for i, row in enumerate(rows) if row[0] >= start - 1e-9)
    for i in range(start_i, len(rows)):
        if abs(rows[i][1] - target) / target <= relative_tolerance:
            if all(abs(row[1] - target) / target <= relative_tolerance for row in rows[i:]):
                return max(0.0, rows[i][0] - start)
    return float("nan")


feedback = simulate(rhs_feedback)
fixed = simulate(rhs_fixed, fixed_lambda=True)
pulse_end_feedback = nearest(feedback, P["pulse_end"])
metrics = {
    "feedback_x_min": min(row[1] for row in feedback),
    "feedback_max_deviation": max(abs(row[1] - x0) for row in feedback),
    "feedback_pulse_end_deviation": abs(pulse_end_feedback[1] - x0),
    "feedback_r_max": max(row[2] for row in feedback),
    "feedback_lambda_max": max(row[3] for row in feedback),
    "feedback_recovery": recovery_time(feedback, x0, P["pulse_end"]),
    "fixed_recovery": recovery_time(fixed, x0, P["pulse_end"]),
}


if __name__ == "__main__":
    print("trajectory rows:", len(feedback))
    for name, value in metrics.items():
        print(f"{name}: {value:.4f}")
    print("final feedback state:", tuple(round(v, 4) for v in feedback[-1][1:]))
    print("final fixed state:", tuple(round(v, 4) for v in fixed[-1][1:3]))

What I would argue against / where this breaks

This result cannot prove that real cells obey this Hill-like resource curve, nor can it attribute changes in λ to a single resource. The review by Klumpp and Hwa distinguishes passive growth-rate dependence from growth-mediated feedback caused by nutrient limitation, toxicity, or expression burden; the feedback direction depends on the type of limitation (Sources 2). My r simply compresses this coupling into one state variable.

More direct ways to break the model would be to use multiple resource pools, let a vary with resource, or add regulatory and translational delays. The complete square-wave switch has no single time-invariant fixed point valid for all times; each constant-input platform can define its own equilibrium, but a finite pulse trajectory may not reach it. After the pulse, the input is constant at u=1.0; if the system converges, the joint equilibrium satisfies x∗=a/λ(r∗) and r∗=ρu/(ρ+γx∗); in this example, that joint equilibrium is the reported (x₀,r₀,λ₀). Recovery dynamics after nutrient upshift/downshift also show that external input and internal resource reallocation have distinct time scales, so a post-pulse trajectory should not be misread as a new instantaneous steady state (Source 3). Thus the figure supports a boundary judgment: fixed λ can serve as a baseline, but its continued validity under explicit resource input must be tested jointly with a closed resource–growth model and data.
