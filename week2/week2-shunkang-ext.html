What does an extra battery change?

A stoichiometric and phase-line test of an intracellular energy module

CCBS · EST 5053 · extension mini-essay · on lectures 3–4 · Week 2 · 2026-09-14

The claim

In this minimal adenylate-pool model, an auxiliary module shifts the stable ATP fraction and raises productive flux while the work reaction is below saturation. As that reaction approaches its maximum rate, some additional input appears as leakage.

Here “battery” means one ATP-producing flux in the model. The outcome depends on where that flux is connected and on its rate law.

1The definition

Here I define the battery as a reaction flux.

Week 1 left the auxiliary energy source abstract. That was useful for locating the diffusion ceiling, but it is not yet a cell model. In a reaction network, adding a battery means adding a reaction with a stoichiometric column, a rate law, and an energy currency. I will use ATP/ADP as that currency and represent the new module as an ATP-producing reaction that consumes ADP and an external fuel.

This choice makes a prediction possible. If the battery only raises the ATP pool, it should move the balance of addition and removal. If it is wired to a capacity-limited work reaction, it should raise output only until that reaction saturates. Neither effect, by itself, implies a new attractor.

2The reaction network

Stoichiometry says what each event changes; kinetics says how often it happens.

Let A denote ATP, D denote ADP, and Y denote a productive cellular output. The minimal network contains an auxiliary generator, a useful ATP-consuming reaction, and an unproductive leak:

raux:D→A,rwork:A→D+Y,rleak:A→D(1)

Ordering the species as (A, D, Y), the stoichiometric matrix is:

S=1−1−1−111010,v=g(D)w(A)ℓA(2)

The resulting dynamics follow the Lecture 3 accounting rule:

x˙=Sv(x),Y˙=w(A)(3)

For the short-time energy-pool calculation, I hold the adenylate total Q = A + D fixed and scale it to 1. This is a conserved pool for the closed chemistry on the fast timescale, not a claim that a growing cell preserves the total forever. Growth dilution and pool synthesis are deliberately postponed.

g(D)=JauxDKg+D,w(A)=VwAKw+A(4)

With D = 1 − A, the ATP coordinate is governed by one addition-minus-removal function:

A˙=f(A)=g(1−A)−w(A)−ℓA(5)

3The phase-line test

A shifted fixed point is not automatically a new state.

Lecture 4 turns a one-dimensional addition-removal balance into a phase-line question. A fixed point A* is where f(A*) = 0. It is locally stable when the vector field points toward the crossing, equivalently when f′(A*) < 0 for a simple crossing.

In this model, every term has the same directional effect. Generator activity decreases as ATP replaces ADP; work removal increases with ATP; leak removal increases linearly. The slope at any crossing is therefore:

f′(A)=−JauxKg(Kg+1−A)2−VwKw(Kw+A)2−ℓ<0(6)

Thus every interior crossing is stable, and the monotonicity also prevents three crossings. Increasing Jaux can move the cell along a family of stable energy states, but this particular wiring cannot create the stable–unstable–stable pattern required for one-dimensional memory.

4The numerical test

More power raises useful flux only before the work branch saturates.

I set Kg = Kw = 0.1, Vw = 0.8, and ℓ = 0.05 in units where Q = 1. These numbers are illustrative model parameters, not measurements from a named cell. For each Jaux, I solve equation (5) for the stable ATP fraction and then evaluate the productive work flux w(A*).

The ATP fraction changes dramatically between Jaux = 0.6 and 1.2, but useful work barely changes between 1.2 and 2.0. The extra source still changes the pool, yet the output branch is close to its capacity Vw = 0.8. At high input, the model predicts an energy-rich but not proportionally more productive cell.

# Reproducible arithmetic for the table and Figure 2
from scipy.optimize import brentq

Kg, Kw, Vw, leak = 0.1, 0.1, 0.8, 0.05
g = lambda A, J: J * (1 - A) / (Kg + 1 - A)
w = lambda A: Vw * A / (Kw + A)
f = lambda A, J: g(A, J) - w(A) - leak * A

for J in [0.0, 0.2, 0.6, 1.2, 2.0]:
    A = 0.0 if J == 0 else brentq(lambda z: f(z, J), 0, 1 - 1e-10)
    print(J, A, 1 - A, w(A), leak * A)

5What the battery changes

The first effect is a flux redistribution; the second is a capacity limit.

This model gives three distinct meanings to “more energy.” First, Jaux changes the addition term for ATP and therefore changes the steady ATP/ADP composition. Second, because work depends on ATP, the same perturbation increases useful output. Third, work has a maximum rate and the leak grows with ATP, so the marginal benefit of the battery declines.

In this network, the auxiliary source adds neither a new dimension nor a positive feedback loop. Its one-dimensional phase line has one stable crossing, not the three crossings needed for biochemical memory. Under these assumptions, the battery moves the steady state without changing the type of steady state this network can support.

A sharper design rule

To study bistability or another new behavior, the energy flux would have to enter a nonlinear feedback or a nonequilibrium cycle. Raising the input to this monotone ATP pool alone produces a continuous shift and more leakage in the present model.

This conclusion is conditional. If ATP drives receptor reset, proofreading, cooperative regulation, or a switch with feedback, the energy flux enters a different column or a different rate law. That is where a later essay could test new function. It would be incorrect to infer those behaviors from the present pool model alone.

6The next model

The next useful extension is not to add every cellular process. I would keep the same ATP/ADP pool, add one ATP-consuming receptor-reset reaction, and compare two networks at matched Jaux: a battery connected only to downstream work, and a battery connected to repeated sensing. The observables would be useful output, independent sensing events, ATP cost per event, and the stability of the downstream state.

The Week 2 model makes “auxiliary battery” concrete: it is an added stoichiometric flux. Whether it changes the ATP/ADP pool, downstream throughput, or higher-level state structure depends on its connection and kinetics.
