Week 2 — Extension: Two zero eigenvalues can still mean recovery

Author: Kehan Lang · Week 2 (2026-09-14) · CCBS 2026

One sentence: In a closed reaction network, zero eigenvalues of the full Jacobian can record conserved totals rather than a failure of recovery; stability must be judged on the stoichiometric compatibility class that chemistry actually permits.

The point I am adding

Lecture 3 gives a structural route to conserved pools: each row vector in the left null space of the stoichiometric matrix defines a linear quantity invariant under the declared reactions. Lecture 4 gives the local rule that a Hurwitz Jacobian has no eigenvalue with nonnegative real part. Taken without their respective state-space domains, these statements can appear to conflict. Conserved pools often give zero eigenvalues, so the full Jacobian is not Hurwitz. Is the corresponding equilibrium therefore inconclusive or unstable?

Not necessarily. The zero modes can point between state-space slices with different conserved totals. A closed system cannot move in those directions, so they are not admissible perturbations when the initial totals are fixed. The relevant question is whether perturbations within the stoichiometric compatibility class return to the equilibrium in that same class. I make that distinction explicit for the smallest binding network, where every calculation can be checked by hand.

Work it

Consider reversible enzyme–substrate binding with mass-action kinetics:

E + S ⇌ C,v+ = k+ES,   v− = k−C.

For the state x = (E, S, C)T, the forward and reverse reaction columns give

Γ = [(-1, −1, 1)T, (1, 1, −1)T],   ẋ = Γv(x).

There are two independent left-null vectors, (1, 0, 1) and (0, 1, 1). Thus the enzyme and substrate totals

qE = E + C,   qS = S + C

are fixed by the reactions. An initial condition is therefore not free to explore all of three-dimensional concentration space. It stays on the one-dimensional line segment where both totals have their initial values. Put c = C; then E = qE − c and S = qS − c, and the full three-variable model reduces exactly—not approximately—to

dc/dt = f(c) = k+(qE − c)(qS − c) − k−c,0 ≤ c ≤ min(qE, qS).

This scalar equation has one equilibrium in the physical interval. Writing Kd = k−/k+, it is the smaller root

c* = [qE + qS + Kd − √((qE + qS + Kd)2 − 4qEqS)] / 2.

More important than the root is its slope. Throughout the physical interval,

f′(c) = −k+[(qE − c) + (qS − c)] − k− < 0.

Since f(0) > 0 and f(min(qE, qS)) < 0, every initial complex level in the same compatibility class moves toward c*. This is a global statement on that line segment, rather than a numerical observation or merely a local Jacobian result.

Now compute the full Jacobian at the equilibrium, with E* = qE − c* and S* = qS − c*:

J(x*) = [ [−k+S*, −k+E*, k−],[−k+S*, −k+E*, k−],[k+S*, k+E*, −k−] ].

Its spectrum is {0, 0, f′(c*)}. The two zeros mean that the full system has a two-dimensional family of equilibria as the two conserved totals vary. They do not describe motion available to a closed preparation with fixed qE and qS. The permitted tangent direction is the reaction vector γ = (−1, −1, 1)T, and direct multiplication gives Jγ = f′(c*)γ. Along that physical direction the one nonzero eigenvalue is strictly negative.

The coordinate change makes the interpretation even more transparent. Use y = (qE, qS, c) rather than (E, S, C). It is an exact invertible change of variables on the physical domain, because E = qE − c and S = qS − c. In these coordinates the complete system is already triangular:

dqE/dt = 0,   dqS/dt = 0,   dc/dt = f(c; qE, qS).

Its Jacobian at the equilibrium is

Jpool = [ [0, 0, 0], [0, 0, 0], [S*, E*, f′(c*)] ].

The first two rows identify the zero modes directly: qE and qS are constants of the closed dynamics. Although the equilibrium set is two-dimensional when totals are varied across preparations, any one preparation fixes a single pair of totals. The lower-right entry is the response to binding redistribution after those totals are held fixed. Thus the zero eigenvalues are visible before any characteristic polynomial is calculated; they are not restoring or growing modes within a fixed compatibility class.

This also distinguishes two experimentally different perturbations. A small redistribution δx = γ δc preserves both totals, stays within the original compatibility class, and has local decay rate f′(c*). Adding a small amount δqE of enzyme, in contrast, moves the system to a new compatibility class. Implicitly differentiating f(c*; qE, qS) = 0 gives

∂c*/∂qE = k+S*/|f′(c*)|,   ∂c*/∂qS = k+E*/|f′(c*)|.

Consequently, after an enzyme-addition experiment the complex concentration should settle to a different value; failure to return to the old value is not instability. It is the ordinary sensitivity of one equilibrium to a conserved total. This is precisely why a stability statement must name the perturbations it permits.

For the default calculation below, qE = 1, qS = 3, Kd = 1, and k+ = 1. The equilibrium is c* = 0.697 and the full spectrum is {0, 0, −3.606}. Classifying this equilibrium as unstable solely because the full matrix is not Hurwitz would ignore the chemical constraint that generates the two zero modes. The precise statement is that it is globally attracting relative to its compatibility class.

Explore the model. Change either conserved total or the dissociation scale. The displayed full Jacobian always contains two zeros, while the physical recovery rate remains negative as long as the reversible binding model is closed.

What I would argue against / where this breaks

The conclusion is not that zero eigenvalues can always be ignored. A zero real part can be genuinely inconclusive when it lies within the physically accessible state space, as Lecture 4’s nonlinear examples emphasize. Here the interpretation is earned from stoichiometry: two exact conservation laws leave only the γ direction available after the initial totals are fixed. If enzyme synthesis, substrate supply, product formation, degradation, growth dilution, or another reaction is added, the totals are no longer both conserved and the reduction must be redone.

This network is also unusually simple. It has one reversible binding step, one scalar compatibility class, and an exactly negative derivative everywhere on the physical interval. Larger biochemical networks may have higher-dimensional classes, multiple equilibria, or nonhyperbolic directions that do require nonlinear analysis. The transferable lesson is therefore not “zero means safe,” but “identify the conserved totals and restrict the stability claim to the state space the chemistry allows.”

Code used for both figures
// kPlus is set to 1, so kMinus = Kd and c is the only dynamic coordinate.
function cStar(qE, qS, Kd) {
  const b = qE + qS + Kd;
  return 2 * qE * qS / (b + Math.sqrt(b*b - 4*qE*qS));
}
function rate(c, qE, qS, Kd) { return (qE - c) * (qS - c) - Kd * c; }
function recoveryRate(qE, qS, Kd) {
  const c = cStar(qE, qS, Kd);
  return qE + qS + Kd - 2*c; // equals -f'(c*) > 0
}
