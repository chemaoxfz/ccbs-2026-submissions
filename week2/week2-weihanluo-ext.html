WEEK 2 — Extension: Fixed points in neural-network dynamics

Author: Weihan Luo · Week 2 (2026-09-14) · CCBS 2026

One sentence: A recurrent neural network can be understood as a dynamical system whose useful representations are stable fixed points, while changing the recurrent weight can create a bifurcation and new memory states.

The point I am adding

Lecture 4 studies fixed points as states where a dynamical system stops moving. For a discrete neural-network update, the same idea is immediate: if the hidden state obeys ht+1 = F(ht), then a fixed point h* satisfies F(h*) = h*. Repeatedly applying the network is therefore like following a trajectory through a phase portrait.

Consider the smallest recurrent network I can write down: ht+1 = tanh(w ht). The state h* = 0 is always a fixed point. Near it, tanh(wh) ≈ wh, so a small perturbation is multiplied by roughly w at every step. The zero fixed point is stable when |w| < 1 and unstable when |w| > 1.

This gives a machine-learning version of a bifurcation. When w passes through 1, two additional fixed points appear, approximately h* ≈ ±0.80 when w = 1.4. Those two stable states can act like two attractor memories: the sign of a noisy initial state determines which state the network remembers.

Work it

The figure below iterates the same one-neuron network from several initial states. With w = 0.8, all trajectories return to zero. With w = 1.4, zero repels nearby trajectories and they settle near one of the two new stable fixed points.

The local test generalizes beyond one neuron. For ht+1 = F(ht), linearizing around a fixed point gives δht+1 ≈ JF(h*)δht. The fixed point is locally stable when every eigenvalue of the Jacobian has magnitude below 1. This is the discrete-time analogue of the lecture’s Jacobian stability test.

This is also the basic idea behind Deep Equilibrium Models. Instead of stacking a finite number of identical layers, a DEQ defines the hidden representation as the fixed point z* = fθ(z*, x) and solves for it directly. The network is deep in the sense of repeated dynamics, but stores only the equilibrium state. Implicit differentiation then computes gradients through that fixed point without unrolling every iteration.

Reproduce the figure and fixed points 
import numpy as np

def iterate(weight, initial, steps=12):
    states = [initial]
    for _ in range(steps):
        states.append(np.tanh(weight * states[-1]))
    return states

for weight in (0.8, 1.4):
    for initial in (-0.4, 0.4):
        print(weight, initial, iterate(weight, initial))

fixed_point = 0.4
for _ in range(100):
    fixed_point = np.tanh(1.4 * fixed_point)
print(fixed_point)

What I would argue against / where this breaks

A stable fixed point is not automatically a good representation. It can erase information that the task needs, and a network with several attractors can be sensitive to tiny perturbations near a basin boundary. The one-neuron example is also much simpler than a modern recurrent network: real Jacobians can be non-normal, high-dimensional, input-dependent, and difficult to solve.

There is also a difference between finding an equilibrium and having a convergent iteration. A fixed point may exist while the particular update rule oscillates or diverges. Thus the lecture’s stability analysis is not just decoration for neural networks: it tells us when an equilibrium layer can actually be reached by the solver used to compute it.
