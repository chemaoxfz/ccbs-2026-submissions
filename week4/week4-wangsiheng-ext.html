Fast binding does not make free substrate slow

wangsiheng · Lecture 6 extension · CCBS 2026 · 9.28

One sentence: Fast complex adjustment can coexist with a poor standard Michaelis–Menten progress curve, because binding may rapidly move a substantial amount of substrate into the complex; tracking free plus bound substrate preserves that missing pool.

The point I am adding

The supplied Lecture 6 slides show that standard QSSA becomes less accurate as enzyme abundance increases. I turn that warning into a numerical test: can binding be much faster than catalysis while the usual reduced model still predicts product formation poorly? The key distinction is between free substrate and substrate that has not yet become product.1

Keep the same closed, well-mixed reaction, E + S ⇌ C → E + P. Let ET be total enzyme and S0 the initial substrate, with C(0) = P(0) = 0. Define the remaining substrate total q = S + C. Adding the exact substrate and complex balances cancels binding:

dq/dt = −k2C,   P = S0 − q, dC/dt = k1(ET − C)(q − C) − (k−1 + k2)C.

Binding can change S quickly without changing q. Setting the complex’s formation and loss approximately in balance, with KM = (k−1 + k2)/k1, gives a quadratic. Its smaller, physical root is

A(q) = ET + q + KM, C̄(q) = ½[A(q) − √(A(q)2 − 4ETq)].

The total QSSA uses dq/dt ≈ −k2C̄(q) with q(0) = S0, then reconstructs S ≈ q − C̄(q). This established change of variable keeps substrate sequestration in the bookkeeping.2 It does not, by itself, guarantee that the fast-state approximation is accurate.

Work it

Choose illustrative values ET = S0 = 1 µM, k1 = 10 µM−1s−1, k−1 = 9.9 s−1, and k2 = 0.1 s−1, so KM = 1 µM. Unbinding takes about 0.10 s, whereas catalysis takes 10 s. Yet the small-enzyme ratio ET/(KM + S0) is 0.5, not small.

Near the initial total, the closure gives C̄(1) = (3 − √5)/2 ≈ 0.382 µM. Thus about 38% of the substrate can be bound after fast adjustment. Replacing total substrate by free substrate discards a substantial pool.

I integrate the full equations and total QSSA independently. For comparison, the standard reduction is ds/dt = −k2ETs/(KM + s), s(0) = S0, with product estimate Pstd = S0 − s. That last estimate neglects bound substrate. All three curves below show the same observable: product formed.

Code that produced Figure 1 and the table (Python 3, standard library) 
from math import sqrt

# Concentrations: micromolar; time: seconds.
ET = S0 = KM = 1.0
k1, km1, k2 = 10.0, 9.9, 0.1

def bound(q):
    a = ET + q + KM
    return 2*ET*q / (a + sqrt(a*a - 4*ET*q))

def rhs(y):
    q, c, qt, s = y
    return (-k2*c,
            k1*(ET-c)*(q-c) - (km1+k2)*c,
            -k2*bound(qt),
            -k2*ET*s/(KM+s))

def rk4(y, h):
    a = rhs(y)
    b = rhs([v+h*z/2 for v,z in zip(y,a)])
    c = rhs([v+h*z/2 for v,z in zip(y,b)])
    d = rhs([v+h*z for v,z in zip(y,c)])
    return [v+h*(a0+2*b0+2*c0+d0)/6
            for v,a0,b0,c0,d0 in zip(y,a,b,c,d)]

def run(h=0.001, T=60.0):
    y = [S0, 0.0, S0, S0]  # full total, full complex, tQSSA total, sQSSA free
    last = [0.0]*3
    t50 = [None]*3
    maxerr = [0.0]*2
    points = [(0.0, 0.0, 0.0, 0.0)]
    for i in range(1, round(T/h)+1):
        y = rk4(y, h)
        t = i*h
        p = [S0-y[0], S0-y[2], S0-y[3]]
        assert -1e-10 <= y[1] <= min(ET,y[0])+1e-10
        assert all(-1e-10 <= z <= S0+1e-10 for z in p)
        for j in range(3):
            if t50[j] is None and p[j] >= S0/2:
                t50[j] = t-h+h*(S0/2-last[j])/(p[j]-last[j])
        for j in range(2):
            maxerr[j] = max(maxerr[j], abs(p[j+1]-p[0])/S0)
        if i % round(0.25/h) == 0:
            points.append((t, *p))
        last = p
    return t50, maxerr, points

times, errors, points = run()
print("t50: full, total QSSA, standard QSSA", times)
print("max |P_reduced-P_full| / S0: total, standard", errors)
for j, name in enumerate(("full", "total", "standard"), start=1):
    path = " ".join(("M" if i == 0 else "L") +
                    f"{60+10*t:.2f},{274-200*row[j]/S0:.2f}"
                    for i, row in enumerate(points) for t in [row[0]])
    print(name, path)  # SVG path data used in Figure 1

Where this breaks

Total QSSA still omits the initial buildup: it assigns C̄(S0) > 0 immediately, while the full model starts from C(0) = 0. It should not be used to infer that early complex trajectory. If complex relaxation is no longer fast compared with total-substrate change, the closure also needs rechecking.3 Open systems, reversible catalysis or changing enzyme totals require modified balances.

Here KM includes catalytic loss; the equilibrium dissociation constant is instead Kd = k−1/k1. They are close for these chosen rates, but are not interchangeable in general. The numerical success above is evidence for this parameter set and time window, not a universal accuracy claim.
