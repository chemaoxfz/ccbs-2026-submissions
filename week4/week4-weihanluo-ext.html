WEEK 4 — Extension: When equilibrium looks like attention

Author: Weihan Luo · Week 4 (2026-09-28) · CCBS 2026

One sentence: Equilibrium binding and softmax attention use the same normalized competition rule, but biological state weights have physical meaning while neural attention scores are learned compatibilities.

The point I am adding

Lecture 7 turns a list of molecular states into probabilities. If state i has weight wi, its equilibrium probability is

pi = wi / Σjwj

When the weights come from free energies, wi = exp(−βGi). A lower-free-energy state receives more probability, but all possible states compete through the same denominator. Lecture 8 uses this allocation as the fast binding layer: binding redistributes molecules among states, while slower catalysis changes the totals and produces activity.

Transformer attention has the same algebra. Given a query and several keys, the attention score for item i is si = q·ki/√d, and the attention weight is

αi = exp(si) / Σjexp(sj)

Set si = −βGi and the two expressions become identical. The query is then acting like a context that changes the effective energy of each candidate, and the softmax is a normalized state allocation. This is a strong mathematical connection, not a claim that a Transformer is literally a warm biological molecule.

Work it

For two competing states, define the effective advantage of state 1 as a = −βΔG in the binding model, or as the attention score gap a = s1 − s0 in the neural model. In both cases, the favored state's share is

share1 = exp(a)/(1 + exp(a))

The plot shows that the curves overlap exactly after putting the two systems on the same effective-score axis. A positive advantage gives state 1 most of the probability; an advantage of zero gives each state one half.

Reproduce the figure 
import numpy as np
import matplotlib.pyplot as plt

advantage = np.linspace(-4, 4, 200)
binding_share = np.exp(advantage) / (1 + np.exp(advantage))
attention_share = 1 / (1 + np.exp(-advantage))

plt.plot(advantage, binding_share, label="equilibrium binding")
plt.plot(advantage, attention_share, "--", label="softmax attention")
plt.xlabel("effective advantage a")
plt.ylabel("share of state 1")
plt.ylim(0, 1)
plt.grid(alpha=0.25)
plt.legend()
plt.show()

Ramsauer and colleagues make the connection stronger than a visual resemblance: they show that a modern Hopfield-network update is mathematically equivalent to Transformer attention, while interpreting the network in terms of energy minima and fixed points. This gives a route from Lecture 7's weighted states to an ML model with an explicit energy-based interpretation.

What I would argue against / where this breaks

Softmax normalization alone does not prove that attention is at thermodynamic equilibrium. In a biological model, weights must agree with physical affinities, conservation constraints and, for equilibrium cycles, detailed balance. In a Transformer, the scores are learned dot products and change with the query. There is usually no temperature, conserved molecular pool or physical energy budget.

The connection is therefore about a shared calculation: many candidates compete, exponentials turn score differences into positive weights, and normalization produces a distribution. The biological interpretation adds mechanisms that the neural equation does not automatically have. Saying “attention is equilibrium binding” would be too strong; saying “attention reuses the mathematics of normalized state competition” is defensible.
