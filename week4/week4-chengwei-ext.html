Week 4: Estimating reaction rates when the states are hidden

Author: Chengwei Jin · Week 4 (2026-09-22) · CCBS 2026

One sentence: In a controlled binding simulation, explicitly modelling observation noise recovers switching rates that simple signal thresholding badly overestimates.

The point I am adding

Lecture 7 describes molecular states and their transition rates.1 Where would those rates come from experimentally? A fluorescence detector reports brightness, not a molecular-state label. If noise repeatedly crosses an intensity threshold, counting each crossing as a reaction invents extra transitions. A hidden Markov model (HMM) separates two ingredients: an unseen state that switches, and a noisy signal emitted by that state.2

Consider a receptor switching between free and bound states at fixed ligand concentration. I set the binding and unbinding rates to 1.20 and 0.80 s−1, then simulated 1,000 s of exact continuous-time jumps. Instantaneous measurements arrive every 0.05 s. Their mean brightness is 0.2 when free and 0.8 when bound, with independent Gaussian noise of standard deviation 0.25. These are illustrative parameters, not experimental measurements.

Work it

I gave a two-state Gaussian HMM only the brightness record and sampling interval. The fit learned the brightness distributions and transition probabilities from three predetermined starting points. It never received the true states or rates. Crucially, a per-frame transition probability is not a per-second rate: I converted the fitted matrix using P = exp(QΔt), with the exact two-state formula below. The displayed state path is a separate Viterbi decoding; rates come from the likelihood fit, not from counting its switches.

The HMM estimated 1.22 and 0.81 s−1. For comparison, assigning each sample to a state using the midpoint of the same fitted brightness means gave 7.45 and 5.43 s−1, after the same rate conversion. The threshold mistakes observation noise for rapid binding and release. Across 30 additional independently simulated records, the HMM estimates averaged 1.19 and 0.80 s−1. The result therefore survives changing the random trajectory.

How probabilities become rates

Use rows for source states. Let p = Pfree,bound and q = Pbound,free. For a homogeneous two-state continuous-time process, with r = kbind + kunbind,

p = (kbind/r)(1 − e−rΔt),
q = (kunbind/r)(1 − e−rΔt).

Adding them gives r = −ln(1 − p − q)/Δt. Therefore

kbind = r p/(p + q),
kunbind = r q/(p + q).

This requires 0 < p + q < 1. The fitted values are p = 0.058001 and q = 0.038485. Dividing off-diagonal probabilities by Δt alone is only a small-interval approximation. For the binding interpretation, kbind = kon[ligand]; the concentration must be known to obtain a bimolecular kon.

All fits converged. The three starts for the displayed trace reached log likelihoods within 0.001. Exhaustive enumeration of a small example verifies the forward-backward likelihood, posterior state probabilities, expected transition counts and Viterbi decoding. Continuous-to-discrete-to-continuous rate conversion is also checked. The known simulation truth is loaded only after inference, for validation.

Where this breaks

This is a matched-model validation: the number of states is supplied, and the simulated noise matches the fitted Gaussian model. Correlated noise, bleaching, exposure-time averaging or indistinguishable brightness states could change the result. HMM inference provides parameter estimates under a model, not proof that its states are the molecule's unique physical mechanism.2 A two-state fit also cannot establish a sustained cyclic current. The extension here is the missing step between a reaction diagram and its estimated rates.

Reproduce the calculation: complete code

Save the four files below together in an analysis folder. Python and Node.js require no third-party packages. Run these commands from its parent folder:

python analysis/generate.py
node analysis/fit.cjs
node analysis/test.cjs

generate.py writes the observation-only input, withheld truth and independent validation records. hmm.cjs implements the fitter; fit.cjs produces analysis/results.json. Rates are estimated by scaled forward-backward EM with Gaussian emission means and variances. The threshold baseline uses the midpoint of the fitted means, with no hysteresis or smoothing.

generate.py
"""Exact continuous-time binding model, sampled instantaneous Gaussian signals.

All numbers are illustrative; no experimental parameter values are claimed.
Run: python analysis/generate.py. Only the standard library is needed.
The inference input is stored separately from hidden-state validation truth.
"""
from pathlib import Path
import json
import math
import random

ROOT = Path(__file__).resolve().parents[1]
DT, DURATION = .05, 1000.0
K_BIND, K_UNBIND = 1.2, .8
MEANS, SIGMA = [.2,.8],.25
MAIN_SEED, REPLICATES = 20260922, 30

def simulate(seed):
    events_rng = random.Random(seed)
    noise_rng = random.Random(seed+1_000_000)
    state = int(events_rng.random() < K_BIND/(K_BIND+K_UNBIND))
    next_time = events_rng.expovariate(K_UNBIND if state else K_BIND)
    y,z = [],[]
    transitions = [0,0]
    n = round(DURATION/DT)+1
    for i in range(n):
        t=i*DT
        while next_time<=t:
            transitions[state]+=1
            state=1-state
            next_time += events_rng.expovariate(K_UNBIND if state else K_BIND)
        z.append(state)
        y.append(MEANS[state]+noise_rng.gauss(0,SIGMA))
    return y,z,transitions

def main():
    y,z,transitions = simulate(MAIN_SEED)
    # No hidden states, true rates, emission means or noise scales in fit input.
    (ROOT/'analysis'/'observations.json').write_text(json.dumps(dict(dt=DT,y=y)),encoding='utf-8')
    (ROOT/'analysis'/'truth.json').write_text(json.dumps(dict(seed=MAIN_SEED,dt=DT,duration=DURATION,rates=[K_BIND,K_UNBIND],means=MEANS,sigma=SIGMA,z=z,jump_counts=transitions)),encoding='utf-8')
    replicates = [dict(seed=MAIN_SEED+100+j,y=simulate(MAIN_SEED+100+j)[0]) for j in range(REPLICATES)]
    (ROOT/'analysis'/'replicates.json').write_text(json.dumps(dict(dt=DT,replicates=replicates)),encoding='utf-8')
    # Exact sampled transition probabilities used only for implementation QA.
    factor = -math.expm1(-(K_BIND+K_UNBIND)*DT)
    print(json.dumps(dict(samples=len(y),dt=DT,actual_jumps=transitions,
        exact_P01=K_BIND/(K_BIND+K_UNBIND)*factor,
        exact_P10=K_UNBIND/(K_BIND+K_UNBIND)*factor,
        independent_replicates=REPLICATES)))

if __name__=='__main__':
    main()
hmm.cjs
/* Two-state Gaussian HMM. No truth or simulation constants are used here.
   Rows of P are source states; rates[0] is low -> high.
   Scaled forward-backward EM; Viterbi decoding is separate from rate fitting. */
'use strict';
const assert = require('node:assert/strict');

function expectation(y,m,keep=false){
  const n=y.length, f=new Float64Array(2*n), e=new Float64Array(2*n), c=new Float64Array(n);
  let ll=0;
  for(let t=0;t<n;t++){
    for(let j=0;j<2;j++){
      const d=y[t]-m.mu[j], v=m.variance[j];
      e[2*t+j]=Math.max(1e-300,Math.exp(-d*d/(2*v))/Math.sqrt(2*Math.PI*v));
      const prior=t===0?m.pi[j]:f[2*(t-1)]*m.P[0][j]+f[2*(t-1)+1]*m.P[1][j];
      f[2*t+j]=prior*e[2*t+j];
    }
    c[t]=f[2*t]+f[2*t+1];ll+=Math.log(c[t]);
    f[2*t]/=c[t];f[2*t+1]/=c[t];
  }
  const count=[[0,0],[0,0]],w=[0,0],sum=[0,0],sumsq=[0,0];
  let back=[1,1],first;
  const posterior=keep?new Float64Array(2*n):null;
  for(let t=n-1;t>=0;t--){
    const g=[f[2*t]*back[0],f[2*t+1]*back[1]],total=g[0]+g[1];
    for(let j=0;j<2;j++){
      g[j]/=total;w[j]+=g[j];sum[j]+=g[j]*y[t];sumsq[j]+=g[j]*y[t]*y[t];
      if(keep)posterior[2*t+j]=g[j];
    }
    if(t===0){first=g;break;}
    const prev=[0,0];
    for(let i=0;i<2;i++)for(let j=0;j<2;j++){
      const term=m.P[i][j]*e[2*t+j]*back[j]/c[t];
      count[i][j]+=f[2*(t-1)+i]*term;prev[i]+=term;
    }
    back=prev;
  }
  return {ll,count,w,sum,sumsq,first,posterior};
}

function init(y,switching){
  const s=[...y].sort((a,b)=>a-b),n=s.length;
  const mu=[s[Math.floor(.2*(n-1))],s[Math.floor(.8*(n-1))]];
  const mid=(mu[0]+mu[1])/2;
  const w=[0,0],sum=[0,0],sumsq=[0,0];
  for(const x of y){const j=Number(x>mid);w[j]++;sum[j]+=x;sumsq[j]+=x*x;}
  const variance=w.map((v,j)=>Math.max(.0001,sumsq[j]/v-(sum[j]/v)**2));
  return {mu:sum.map((v,j)=>v/w[j]),variance,pi:[.5,.5],P:[[1-switching,switching],[switching,1-switching]]};
}

function fitOne(y,start){
  let m=init(y,start),prev=-Infinity,history=[];
  for(let iter=0;iter<300;iter++){
    const e=expectation(y,m);history.push(e.ll);
    if(e.ll < prev-1e-7*Math.max(1,Math.abs(prev)))throw Error('EM likelihood decreased');
    if(iter>1 && e.ll-prev < 1e-8*y.length) return {...m,ll:e.ll,iterations:iter+1,converged:true,history};
    prev=e.ll;
    m={mu:e.sum.map((v,j)=>v/e.w[j]),
       variance:e.sumsq.map((v,j)=>Math.max(1e-8,v/e.w[j]-(e.sum[j]/e.w[j])**2)),
       pi:e.first,P:e.count.map(row=>{const total=row[0]+row[1];return row.map(x=>x/total)})};
  }
  return {...m,ll:expectation(y,m).ll,iterations:300,converged:false,history};
}

function ordered(m){
  if(m.mu[0]<=m.mu[1])return m;
  return {...m,mu:[m.mu[1],m.mu[0]],variance:[m.variance[1],m.variance[0]],
    pi:[m.pi[1],m.pi[0]],P:[[m.P[1][1],m.P[1][0]],[m.P[0][1],m.P[0][0]]]};
}

function fit(y){
  const candidates=[.01,.10,.35].map(s=>ordered(fitOne(y,s)));
  candidates.sort((a,b)=>b.ll-a.ll);
  const best=candidates[0];
  return {...best,starts:candidates.map(({ll,iterations,converged})=>({ll,iterations,converged}))};
}

function rates(P,dt){
  const p=P[0][1],q=P[1][0],r=p+q;
  if(!(r>0 && r<1))throw Error('This fitted transition matrix has no positive two-state continuous-time embedding');
  const total=-Math.log1p(-r)/dt;
  return [total*p/r,total*q/r];
}

function threshold(y,m,dt){
  const cut=(m.mu[0]+m.mu[1])/2,z=y.map(v=>Number(v>cut));
  const count=[[0,0],[0,0]];
  for(let t=1;t<z.length;t++)count[z[t-1]][z[t]]++;
  const P=count.map(row=>row.map(x=>x/(row[0]+row[1])));
  return {cut,P,rates:rates(P,dt),count};
}

function viterbi(y,m){
  const n=y.length,back=new Uint8Array(2*n),z=new Uint8Array(n);
  const loge=(x,j)=>-.5*(Math.log(2*Math.PI*m.variance[j])+(x-m.mu[j])**2/m.variance[j]);
  let prev=[Math.log(m.pi[0])+loge(y[0],0),Math.log(m.pi[1])+loge(y[0],1)];
  for(let t=1;t<n;t++){
    const next=[0,0];
    for(let j=0;j<2;j++){
      const x=prev[0]+Math.log(m.P[0][j]),q=prev[1]+Math.log(m.P[1][j]);
      back[2*t+j]=Number(q>x);next[j]=Math.max(x,q)+loge(y[t],j);
    }
    prev=next;
  }
  z[n-1]=Number(prev[1]>prev[0]);
  for(let t=n-2;t>=0;t--)z[t]=back[2*(t+1)+z[t+1]];
  return Array.from(z);
}
module.exports={expectation,fit,fitOne,rates,threshold,viterbi};
fit.cjs
'use strict';
const fs=require('node:fs'),path=require('node:path');
const {fit,rates,threshold,viterbi}=require('./hmm.cjs');
const root=__dirname;
const read=name=>JSON.parse(fs.readFileSync(path.join(root,name),'utf8'));
const input=read('observations.json');
const model=fit(input.y);
const main={model,rates:rates(model.P,input.dt),threshold:threshold(input.y,model,input.dt),decoded:viterbi(input.y,model)};
// Only after fitting: truth enters validation, never inference.
const truth=read('truth.json');
main.decodingAccuracy=main.decoded.reduce((s,x,i)=>s+(x===truth.z[i]),0)/truth.z.length;
const validation=read('replicates.json'),replicates=[];
for(const item of validation.replicates){
  const model=fit(item.y);
  replicates.push({seed:item.seed,rates:rates(model.P,validation.dt),threshold:threshold(item.y,model,validation.dt).rates,
    converged:model.converged,iterations:model.iterations});
}
const summary={};
for(const method of ['rates','threshold']){
  summary[method]=[0,1].map(j=>{
    const values=replicates.map(r=>r[method][j]);
    const mean=values.reduce((s,x)=>s+x,0)/values.length;
    const sd=Math.sqrt(values.reduce((s,x)=>s+(x-mean)**2,0)/(values.length-1));
    const rmse=Math.sqrt(values.reduce((s,x)=>s+(x-truth.rates[j])**2,0)/values.length);
    return {mean,sd,rmse};
  });
}
fs.writeFileSync(path.join(root,'results.json'),JSON.stringify({main,replicates,summary},null,2));
console.log(JSON.stringify({main_rates:main.rates,means:model.mu,noise_sd:model.variance.map(Math.sqrt),
  threshold_rates:main.threshold.rates,decodingAccuracy:main.decodingAccuracy,
  starts:model.starts,summary},null,2));
test.cjs
'use strict';
const assert=require('node:assert/strict'),fs=require('node:fs'),path=require('node:path');
const {expectation,fit,rates,viterbi}=require('./hmm.cjs');
const m={mu:[-.4,1.1],variance:[.3,.2],pi:[.4,.6],P:[[.8,.2],[.3,.7]]};
const y=[.2,.8,-.1,.3,.9];
// Exhaustive enumeration independently checks the likelihood, smoothing,
// expected transition counts and most probable state path on a tiny example.
let likelihood=0,best=-1,bestPath;
const posterior=new Float64Array(2*y.length),count=[[0,0],[0,0]];
for(let bits=0;bits<2**y.length;bits++){
  const z=y.map((_,i)=>(bits>>i)&1);
  let p=m.pi[z[0]];
  for(let t=0;t<y.length;t++){
    if(t)p*=m.P[z[t-1]][z[t]];
    p*=Math.exp(-((y[t]-m.mu[z[t]])**2)/(2*m.variance[z[t]]))/Math.sqrt(2*Math.PI*m.variance[z[t]]);
  }
  likelihood+=p;
  for(let t=0;t<y.length;t++){
    posterior[2*t+z[t]]+=p;
    if(t)count[z[t-1]][z[t]]+=p;
  }
  if(p>best){best=p;bestPath=z;}
}
const e=expectation(y,m,true);
assert(Math.abs(Math.log(likelihood)-e.ll)<1e-12);
for(let i=0;i<posterior.length;i++)assert(Math.abs(posterior[i]/likelihood-e.posterior[i])<1e-12);
for(let i=0;i<2;i++)for(let j=0;j<2;j++)assert(Math.abs(count[i][j]/likelihood-e.count[i][j])<1e-12);
assert.deepEqual(viterbi(y,m),bestPath);
// Exact continuous-to-discrete-to-continuous round trip, including unequal rates.
for(const [a,b,dt] of [[1.2,.8,.05],[.03,2,.2],[3,7,.01]]){
  const f=-Math.expm1(-(a+b)*dt),p=a/(a+b)*f,q=b/(a+b)*f;
  const r=rates([[1-p,p],[q,1-q]],dt);
  assert(Math.abs(r[0]-a)<1e-12 && Math.abs(r[1]-b)<1e-12);
}
assert.throws(()=>rates([[.1,.9],[.9,.1]],.1));
const read=name=>JSON.parse(fs.readFileSync(path.join(__dirname,name),'utf8'));
const result=read('results.json'),truth=read('truth.json');
assert(result.main.model.converged);
assert(result.main.model.starts.every(x=>x.converged));
assert(Math.max(...result.main.model.starts.map(x=>x.ll))-Math.min(...result.main.model.starts.map(x=>x.ll))<.001);
for(const row of result.replicates)assert(row.converged);
for(let j=0;j<2;j++){
  const s=result.summary.rates[j];
  assert(Math.abs(s.mean-truth.rates[j])<4*s.sd/Math.sqrt(result.replicates.length));
  assert(s.rmse<result.summary.threshold[j].rmse);
}
console.log('PASS: exhaustive likelihood/posterior/counts/Viterbi, rate embedding, all fit convergence, independent replicated recovery.');
