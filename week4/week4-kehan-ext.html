Week 4 — Extension: A binding curve has a bandwidth

Author: Kehan Lang · Week 4 (2026-09-28) · CCBS 2026

One sentence: A two-state receptor can have the same equilibrium binding curve at every kinetic speed, yet a periodically changing ligand is transmitted with a frequency-dependent loss of amplitude and a phase lag set by the receptor's relaxation rate.

The point I am adding

Lecture 7 distinguishes stationary occupancy from relaxation speed: for a two-state receptor, the bound fraction is fixed by a ratio of hazards, whereas the relaxation clock is fixed by their sum. [1] Lecture 8 then treats an undriven binding layer as equilibrated while slower catalytic totals change. [2] That reduction is valuable, but it has a clock hidden inside it: a binding state can follow an input only when its relaxation is fast compared with the input's variation. The equilibrium curve therefore does not by itself say how rapidly a receptor can report a changing ligand.

I make this distinction quantitative for the smallest possible binding model. A ligand concentration is prescribed externally and oscillates around a mean. The model asks for the ensemble bound probability, equivalently the mean bound fraction of many independent receptors, while keeping the free ligand prescribed and receptors independent. Even when the static binding law is correct, replacing the kinetic state by its instantaneous equilibrium value is a controlled approximation with a measurable frequency cutoff. This focus on a receptor's kinetic timescale is consistent with receptor-sensing work that relates occupancy dynamics to sensing performance [3], and with analyses that use frequency-dependent transmission for time-varying biochemical inputs [4]; the present calculation does not add diffusion, measurement noise, or information theory.

Work it

Let U and B denote unbound and bound receptor states. At a prescribed free-ligand concentration c(t), binding has hazard k+c(t) and unbinding has hazard k−. If p(t) is the probability of B, arrivals minus departures give

U ⇌ B,    Kd = k−/k+,
dp/dt = k+c(t)(1 − p) − k−p.

For a constant reference concentration c0, write a = k+c0, b = k−, and λ = a + b. The usual equilibrium result is p0 = a/λ = c0/(Kd + c0), while λ−1 is the relaxation time. Multiplying both hazards by a common factor preserves Kd and the whole stationary binding curve, but increases λ by that factor.

What a static curve leaves unidentified

This separation has an experimental consequence. A stationary dose-response curve identifies the ratio Kd = k−/k+, but not the common kinetic scale. At fixed c0, a small step experiment provides the missing datum. After the concentration is held constant, the exact two-state solution is

p(t) = p0 + [p(0) − p0]e−λt.

Thus a transient fit supplies λ, while the plateau supplies p0. Within this specified model they reconstruct the two hazards at that concentration:

a = p0λ,    b = (1 − p0)λ,    k+ = p0λ/c0,    k− = (1 − p0)λ.

This inference is conditional on the two-state, prescribed-ligand model. Its purpose here is not parameter fitting, but to show why one equilibrium curve cannot determine whether a receptor can track a particular signal. Occupancy gives a ratio; a transient supplies the clock.

Now give the ligand a small sinusoidal perturbation, c(t) = c0[1 + ε cos(ωt)], and write p = p0 + δp. Retaining terms first order in ε produces one forced linear equation:

d(δp)/dt + λδp = (abε/λ) cos(ωt).
δpss(t) = [abε/(λ√(λ² + ω²))] cos(ωt − φ),   φ = tan−1(ω/λ).

The instantaneous-equilibrium calculation predicts the same expression with ω set to zero. Thus the dynamic amplitude, divided by the static amplitude, is

H(ω) = λ/√(λ² + ω²) = 1/√[1 + (ω/λ)²].

“Fast” needs an error tolerance

This is a model result, not a universal law for all receptors. Within this two-state model, however, it turns “fast” into a quantitative error budget. If the acceptable amplitude discrepancy from instantaneous equilibrium is 10%, then H ≥ 0.90 and therefore ω/λ ≤ √(0.90−2 − 1) ≈ 0.484. If the allowable phase delay is instead 10°, then ω/λ ≤ tan(10°) ≈ 0.176. The phase requirement is stricter: a receptor can have an amplitude that looks nearly equilibrated while its timing is already appreciably wrong.

Calling the binding layer “fast” therefore requires a dimensionless comparison, ω/λ ≪ 1, together with a tolerance appropriate to the downstream task, rather than merely saying that binding is fast in isolation.

An exact finite-amplitude check

The sinusoidal transfer function is a small-ε result, but the condition behind it has an exact form even when the input excursion is not small. At each instantaneous concentration, define the equilibrium value and the kinetic discrepancy by

peq(t) = c(t)/[Kd + c(t)],    e(t) = p(t) − peq(t).

Substitution into the full nonlinear kinetic equation gives, without linearizing the ligand amplitude,

de/dt = −[k+c(t) + k−]e − dpeq/dt.

The last term is the source of the approximation error: even if e is momentarily zero, a changing equilibrium target immediately creates a discrepancy. When the target moves slowly relative to the instantaneous relaxation rate, the leading correction is e ≈ −[dpeq/dt]/[k+c(t) + k−]. For the sinusoidal input, |dc/dt| grows with ω, which recovers the intuition of the transfer function. The correction is also largest where the equilibrium curve is steep, because dpeq/dc = Kd/(Kd + c)2. The slow and fast receptors are indistinguishable in a static occupancy experiment, because their Kd values agree. They make sharply different predictions for a changing environment. This distinction also matters for model reduction: a downstream equation may correctly use an equilibrium binding relation for the fast receptor, while using the same relation for the slow receptor erases a real delay and attenuation before catalysis has even been considered.

What I would argue against / where this breaks

I would argue against treating “equilibrium binding” as a label that automatically transfers a static curve to a time-varying experiment. It is a reduction justified only after comparing the input timescale with the binding relaxation time. Conversely, a visible lag does not by itself prove nonequilibrium driving: the model here is a passive two-state binding process whose ligand reservoir is externally varied. The lag arises because a finite transition rate cannot instantaneously reallocate probability.

The explicit transfer function also has limits. Its derivation assumes ε is small; Figure 1 deliberately integrates the full nonlinear equation rather than presenting the linear solution as exact at ε = 0.35. It assumes a well-mixed prescribed free-ligand concentration, one reversible binding site, constant microscopic rate constants, and independent receptors. Ligand diffusion, receptor clustering, multiple conformations, finite-pool depletion, cooperative binding, downstream catalytic delays, or stochastic single-trajectory readout add states or clocks. In those settings, λ may be replaced by several relaxation modes and the simple one-pole response need not survive.

Finally, the conclusion concerns the bound fraction, not every biological output. If a slow catalytic layer integrates binding, it can filter high-frequency input further; if feedback changes the ligand reservoir, the input is no longer prescribed. The useful lesson is therefore conditional: equilibrium weights remain appropriate for the fast layer only in the frequency regime where its own kinetics have time to relax, which is the separation-of-clocks assumption made explicit.

Show the core calculation and plotting logic 
const KD = 1, C0 = 1, EPS = 0.35;
function rhs(t, p, omega, r) {
  const c = C0 * (1 + EPS * Math.cos(omega * t));
  const kp = r / KD, km = r;
  return kp * c * (1 - p) - km * p;
}
function rk4(t, p, dt, omega, r) {
  const k1 = rhs(t, p, omega, r);
  const k2 = rhs(t + dt/2, p + dt*k1/2, omega, r);
  const k3 = rhs(t + dt/2, p + dt*k2/2, omega, r);
  const k4 = rhs(t + dt, p + dt*k3, omega, r);
  return p + dt * (k1 + 2*k2 + 2*k3 + k4) / 6;
}
