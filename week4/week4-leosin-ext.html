Fast binding can slow a signal

Leo Sin (施延庆) · Week 4, lectures 7–8 · CCBS 2026 · 28 September 2026

One sentence: Even if a transcription factor binds and unbinds almost instantly, adding downstream binding sites can make its free concentration respond more slowly to a change in production, because the sites must be filled as the signal rises.

The point I am adding

Lecture 8's binding–catalysis model reconstructs free species from conserved totals; its optional sponge example then asks how binding changes a steady-state response. Here is a different question: if the upstream circuit makes more regulator, how quickly does its free concentration change? This is the "retroactivity" of a downstream load described by Del Vecchio, Ninfa and Sontag.2 It can be derived from the same equilibrium bookkeeping used in lectures 7–8.1

Let x be free transcription-factor concentration, D the fixed total concentration of identical, nonproductive DNA binding sites, and K their dissociation constant. Binding is fast, reversible and undriven. At equilibrium, the bound amount is Dx/(K+x), so the slowly changing regulator total is

q(x) = x + Dx/(K+x).

Suppose synthesis adds regulator at rate α and only free regulator is removed at rate γx. Binding moves it between pools without changing q. The chain rule now exposes the load:

[1 + DK/(K+x)²] dx/dt = dq/dt = α − γx.

The bracket is a dimensionless buffer capacity: a small increase in free x requires a larger increase in total q. At the steady state x* = α/γ, a small perturbation relaxes with time constant τ = [1 + DK/(K+x*)²]/γ. The free steady state is unchanged by D in this particular model, but the speed is not.

Work it

Use illustrative units: K = 1 µM, γ = 1 min−1, and step synthesis from 1 to 1.1 µM min−1. Both systems start at x = 1 µM and approach 1.1 µM. With no binding sites, τ near the starting state is 1 min. With D = 9 µM, it is 1 + 9/(1 + 1)² = 3.25 min. Numerical integration of the equation above gives 90% response times of 2.303 and 7.184 min, respectively. The plotted rates and concentrations are chosen to isolate the mechanism; they are not measurements of a particular organism.

Code that produced Figure 1 and the two numbers (Python 3, standard library) 
def run(D, h=0.001, T=12):
    x = 1.0
    points = [(0.0, x)]
    t90 = None
    def rate(z):
        return (1.1 - z) / (1 + D / (1 + z)**2)
    for i in range(1, int(T/h) + 1):
        a = rate(x)
        b = rate(x + h*a/2)
        c = rate(x + h*b/2)
        d = rate(x + h*c)
        x += h*(a + 2*b + 2*c + d)/6
        t = i*h
        if t90 is None and x >= 1.09:
            t90 = t
        if i % 200 == 0:
            points.append((t, x))
    path = " ".join(("M" if j == 0 else "L") +
                    f"{50+50*t:.1f},{190-120*(z-1)/0.1:.1f}"
                    for j, (t, z) in enumerate(points))
    return t90, path

for D in (0, 9):
    t90, path = run(D)
    print(D, t90, path)  # paste path into the matching SVG path above

Where this breaks

The slowdown follows from a specific removal rule, not from equilibrium alone. If bound regulator is degraded or diluted too, the total-balance equation changes, and both its steady free level and response time can change. If binding is not much faster than synthesis and removal, the equilibrium formula for the bound pool cannot be imposed at every instant; one must integrate binding and unbinding explicitly. For a large input jump the buffer capacity also changes along the path, so a single τ is only a local approximation. These are model checks, rather than exceptions to the conservation argument.
