WEEK 4 — Extension: Same affinity, different responses to a short pulse

Author: zhuxiaomeng · Week 4 (2026-09-28) · CCBS 2026

One sentence: Equal equilibrium affinity does not guarantee equal output during a finite stimulus, and cumulative output requires a longer pulse than endpoint occupancy to approach its equilibrium prediction.

The point I am adding

Lecture 7 distinguishes equilibrium occupancies from kinetic timescales [1], while Lecture 8 calculates output from state activities under a fast-binding approximation [2]. I ask how accurate that approximation is during a finite ligand pulse. The extension is a readout-specific error criterion: reaching near-equilibrium occupancy at the end does not imply that the output accumulated earlier is close to the equilibrium prediction.

Work it

Consider R + L ⇌ C, with association constant kon, dissociation rate koff, and fixed receptor total. Initially all receptors are unbound. During 0 ≤ t ≤ T, free ligand is held at L0. The bound fraction f obeys df/dt = konL0(1 − f) − kofff. Hence feq = L0/(Kd + L0), Kd = koff/kon, and τ = 1/(konL0 + koff). Assume an ideal output proportional to bound occupancy, without feedback on binding. Its cumulative value during the pulse is proportional to A(T) = ∫0Tf(t)dt. Direct integration gives:

f(t) = feq(1 − e−t/τ)
A(T) = feq[T − τ(1 − e−T/τ)]
A(T)/Aeq(T) = 1 − (1 − e−x)/x
x = T/τ,   Aeq(T) = feqT.

In illustrative units, let L0 = 1 and T = 1. Compare (kon, koff) = (0.1, 0.1) with (10, 10): both have Kd = 1 and feq = 0.5, yet their cumulative outputs reach only 9.37% and 95.00% of the equilibrium prediction. More generally, 95% accuracy requires T/τ ≈ 3.00 for endpoint occupancy but 20.00 for cumulative output (Figure C). Here “95%” means the actual value reaches 95% of its equilibrium prediction; it is a chosen tolerance, not a biological threshold. Numerical quadrature agrees with the analytic integral.

What I would argue against / where this breaks

I would argue against using either an identical Kd or a near-equilibrium endpoint to infer an identical accumulated response. The earlier lag remains in the integral. This result assumes constant free ligand during the pulse, initially unbound receptors, and a linear, nonperturbing readout. Ligand depletion, pre-existing occupancy, receptor trafficking, or nonlinear downstream dynamics require a different model. Only output during the pulse is counted; post-pulse activity is excluded. The calculation tests the accuracy of a timescale approximation, not whether real drugs with faster binding are more effective.

Derivation and numerical checks

Writing λ = konL0 + koff reduces the ODE to f′ + λf = konL0. With f(0) = 0, its solution is f = feq(1 − e−λt). Integrating from 0 to T yields the displayed formula.

The endpoint error relative to its equilibrium prediction is e−x, so a 5% tolerance gives x ≥ −ln(0.05) = 2.995732. The cumulative error is (1 − e−x)/x; solving it equal to 0.05 gives x = 19.99999996. At small x, A/Aeq ≈ x/2; at large x, A/Aeq ≈ 1 − 1/x. Thus the accumulated fractional deficit decays much more slowly than the endpoint deficit.

Reproducible Python calculation

Requires Python, NumPy, and SciPy. This code computes the responses, checks the analytic integral against numerical quadrature, and finds both 95% thresholds. The figure is drawn by the JavaScript embedded in this HTML, using the same analytic formulas. 

import numpy as np
from scipy.integrate import quad
from scipy.optimize import brentq

# Concentration unit c0; time unit t0.
# kon: 1/(c0*t0); koff: 1/t0.
# All parameters are illustrative, not experimental measurements.

L0 = 1.0
T = 1.0

systems = {
    "Slow": (0.1, 0.1),
    "Fast": (10.0, 10.0),
}

def endpoint_ratio(x):
    return -np.expm1(-x)

def cumulative_ratio(x):
    return 1.0 + np.expm1(-x) / x

endpoint_threshold = -np.log(0.05)
cumulative_threshold = brentq(
    lambda x: cumulative_ratio(x) - 0.95,
    1.0,
    30.0,
)

print("95% endpoint threshold:", endpoint_threshold)
print("95% cumulative threshold:", cumulative_threshold)

for name, (kon, koff) in systems.items():
    kd = koff / kon
    tau = 1.0 / (kon * L0 + koff)
    feq = L0 / (kd + L0)

    def f(t):
        return feq * (-np.expm1(-t / tau))

    area_numeric = quad(f, 0.0, T)[0]

    area_exact = feq * (
        T - tau * (-np.expm1(-T / tau))
    )

    area_equilibrium = feq * T

    assert np.isclose(
        area_numeric,
        area_exact,
        rtol=1e-10,
    )

    print(
        name,
        "Kd =", kd,
        "tau =", tau,
        "f(T) =", f(T),
        "A(T) =", area_exact,
        "A/Aeq =", area_exact / area_equilibrium,
    )

# Expected results:

# 95% endpoint threshold: 2.995732273553991
# 95% cumulative threshold: 19.999999958776918

# Slow:
# tau = 5.0

# A/Aeq = 0.09365376538990922
#
# Fast:
# tau = 0.05
