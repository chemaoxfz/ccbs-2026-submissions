The hidden cost of reading a biochemical switch

A local reaction-order calculation reveals why connecting more reporter sites changes the very threshold they are supposed to measure.

Author: Li Changkai  ·  Week 6 (15 and 20 October 2026)  ·  Original deadline: 26 October 2026
One sentence. An ultrasensitive molecular comparator is not a plug-and-play logic gate: each downstream binding site consumes free repressor, shifts the decision boundary, and changes the apparent logarithmic gain.

1The question beyond the lecture

Lecture 12 builds a three-gene molecular comparator: proteins R and S form an inactive 1:1 complex; unpaired S represses an output promoter. Lecture 12's exposition already derives the shift of the 50% response point when the reporter is no longer negligible.[1] I want to ask the next design question: how does that load change the sharpness of the decision, and how many readers can the switch afford?

Lecture 11 defines reaction order as a local derivative on logarithmic axes.[2] That is exactly the missing tool: a dose–response curve may look like a nearly digital step, but the slope tells us how rapidly its output changes around the threshold. A binding site that simply observes a chemical signal is also a sink for it. Experiments on protein sequestration and transcription-factor titration establish the biological relevance of these two mechanisms, though the numbers below are my illustrative calculation, not a fit to those experiments.[3][4]

2Close the mass balance before reading the bit

Let RT, ST and GT be fixed total concentrations of protector R, repressor S and reporter binding sites G. Let Kpair and Kout be their respective dissociation constants. Binding is reversible, fast relative to protein production/removal, and each reporter site binds one S independently:

R + S ⇌ RS   and   G + S ⇌ GS.

The two complexes contribute to the conserved total of S. Eliminating both bound concentrations gives the strictly increasing function of free repressor S:

ST = S + RTSKpair + S + GTSKout + S .

Its derivative is positive for all nonnegative concentrations, so every total ST determines a unique free S. The active fraction of the reporter is p = G/GT = Kout/(Kout+S). At 50% activity, free S = Kout, giving the already known half-response point:

ST50 = Kout + RTKoutKpair + Kout + GT2 .

The last term is the back-action of measuring the switch: each extra unit of reporter-site concentration moves the midpoint by exactly one-half unit.

3Derive the slope that the original threshold hides

A local apparent Hill exponent measures the slope of log odds against log total repressor at the midpoint; it is not molecular cooperativity or a global Hill-curve fit. Since (1−p)/p = S/Kout, the chain rule gives a logarithmic derivative (equal to −2 d ln p / d ln ST at the midpoint):

nlocal = d ln[(1−p)/p]d ln ST│p=1/2 = STS (dST/dS)│S=Kout .

Differentiating the conservation law, rather than guessing a Hill coefficient, supplies the new result:

D50 = 1 + RTKpair(Kpair + Kout)² + GT4Kout .
nlocal = ST50Kout D50 .

The key distinction is what is held fixed. The output promoter's microscopic occupancy is noncooperative in free S, yet its response to total ST can be extremely steep because the R pool first absorbs most added S. Reporter sites introduce a second sink, so adding readers reshapes the transformation from total to free repressor.

4Compute a switching curve and a reader budget

Use the same normalized binding constants as the Lecture 12 worked calculation, to make comparison straightforward: RT = 1, Kpair = 0.001, Kout = 0.03. All concentrations are divided by one common reference scale c0; these values are illustrative, not experimentally estimated.[1]

The first consequence is a fan-out budget. If an engineer allows at most a 5% displacement of the original midpoint, the exact half-response equation requires GT ≤ 2(0.05)(0.99774) = 0.09977 c0. Suppose, solely as a design illustration, each downstream reader contributes g = 0.01 c0 independent binding sites. Then the same comparator can support at most nine such readers without exceeding this threshold-shift tolerance. This is a model-specific capacity, not a universal limit on cellular fan-out.

For comparison, requiring nlocal ≥ 10 yields GT ≤ 0.19278 c0 in this example. The 5% midpoint requirement is therefore the tighter of these two specifications. Counting genes alone would miss this stoichiometric constraint.

Reproduce the plot and numbers — calculation code (embedded, runs locally)
// Same functions are used by the inline, dependency-free plot.
const RT = 1, KPAIR = 0.001, KOUT = 0.03;
function totalFromFree(s, load) {
  return s + RT*s/(KPAIR+s) + load*s/(KOUT+s);
}
function freeFromTotal(st, load) {
  let lo = 0, hi = st;
  for (let i = 0; i < 70; i++) {
    const mid = (lo + hi)/2;
    if (totalFromFree(mid, load) > st) hi = mid;
    else lo = mid;
  }
  return (lo + hi)/2;
}
function active(st, load) {
  return KOUT/(KOUT + freeFromTotal(st, load));
}
function midpoint(load) {
  return KOUT + RT*KOUT/(KPAIR+KOUT) + load/2;
}
function localSlope(load) {
  const d = 1 + RT*KPAIR/(KPAIR+KOUT)**2
            + load/(4*KOUT);
  return midpoint(load)/(KOUT*d);
}

5What the result does—and does not—prove

There is an important counterexample to the slogan “loading always blunts a switch.” The formula above implies nlocal → 2 as GT → ∞ at fixed microscopic affinities and RT. A weak, nearly noncooperative comparator starting below 2 can actually become steeper in this particular local metric when more sites are added. What is unavoidable here is the midpoint displacement; the sign of the slope change depends on the parameters.

The model assumes fast binding equilibrium, fixed protein totals, independent 1:1 reporter sites, and no hidden competitors. It does not establish response time, stochastic classification error, or long-term memory. Added DNA sites may also perturb expression, and site counts vary between cells. Brewster and colleagues observed that binding-site competition modifies regulatory dose response and that cell-to-cell plasmid variation can flatten sharp population transitions.[4] Buchler and Cross showed ultrasensitive sequestration experimentally, but did not measure this particular fan-out budget.[3]

Falsifiable test: hold repressor/protector expression as constant as possible, systematically add known operator sites, and measure the half-active point and near-midpoint slope of a separate, low-copy sensing promoter. The simple model predicts an additional 0.5 unit of required repressor total per unit of added identical binding-site concentration. Failure could reveal expression changes, heterogeneous affinities, nonequilibrium binding, or extra molecular sinks. The lesson is that a biochemical logic gate must be specified together with its load—not only its isolated truth table.
