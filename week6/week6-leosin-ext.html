A correct XOR can pulse the wrong answer

Leo Sin (施延庆) · Week 6, lectures 11–12 · CCBS 2026 · 26 October 2026

One sentence: Connecting four chemically relaxing NAND gates gives the right XOR truth table at rest, yet a 00 → 11 input step produces a large transient output-1 pulse even though XOR is 0 at both ends.

The point I am adding

Lecture 12 builds XOR from four NAND gates and derives the relaxation of one molecular NAND, ż = a(1−z)−bz, where z is the output-1 fraction [1]. That settles the truth table and the settling time of an isolated gate. I want to ask the next question: what does the connected circuit do while its internal gates are still changing?

Use the lecture's wiring: n1 = NAND(x,y), n2 = NAND(x,n1), n3 = NAND(y,n1), and z = NAND(n2,n3) [1]. At rest this gives XOR. Now switch 00 → 11. The steady output is 0 before and after, so a static truth-table check predicts no response. The composed dynamics instead predict a pulse. This is not merely a mathematical nuisance: the Cello genetic-circuit study reported a temporary wrong output in one composed circuit and identified propagation delay as a necessary design consideration [2]. My calculation below isolates that issue in the lecture's minimal model.

Work it

The same rate law also covers intermediate values. Let two upstream signals have output-1 fractions u and v, with the unselected forms making up 1−u and 1−v. The lecture's mass-action rates become a = κc02(1−uv) and b = κc02uv [1]. Measuring time in gate lifetimes, τ = κc02t, every gate therefore obeys the simple equation

dz/dτ = 1 − z − uv.

Start at the settled 00 state, (n1,n2,n3,z) = (1,1,1,0), then apply x = y = 1. The first three equations have exact solutions n1 = e−τ and n2 = n3 = 1−τe−τ. Only the output needs numerical integration:

dz/dτ = 1 − z − (1 − τe−τ)²,   z(0)=0.

My RK4 integration (step 10−4 gate lifetimes) gives a peak output-1 fraction of 0.4543 at τ = 2.069, after which z returns to 0. The two second-layer signals initially dip because both see the new high inputs while n1 is still high; they recover only after n1 falls. The output NAND temporarily reads that dip as two low inputs. All rates are identical illustrative teaching values, not fitted biological parameters.

Code that produced Figure 2 and the peak (Python 3, standard library) 
import math

def n2(t):
    return 1 - t*math.exp(-t)

def rate(t, z):
    return 1 - z - n2(t)**2

h, z = 0.0001, 0.0
peak = (z, 0.0)
rows = [(0.0, z, n2(0.0))]
for i in range(1, 80001):
    t = (i-1)*h
    k1 = rate(t, z)
    k2 = rate(t+h/2, z+h*k1/2)
    k3 = rate(t+h/2, z+h*k2/2)
    k4 = rate(t+h, z+h*k3)
    z += h*(k1 + 2*k2 + 2*k3 + k4)/6
    if z > peak[0]:
        peak = (z, i*h)
    if i % 1000 == 0:
        rows.append((i*h, z, n2(i*h)))

print("peak z and time:", peak)       # (0.454316..., 2.0693)
print("minimum n2:", 1-2/math.e**2)  # 0.729329..., at t = 2
for column in (1, 2):
    print(" ".join(("M" if j == 0 else "L") +
          f"{60+75*row[0]:.1f},{220-180*row[column]:.1f}"
          for j, row in enumerate(rows)))

What I would argue against / where this breaks

The number 0.4543 is not a universal property of XOR. It belongs to this idealized model: equal catalytic constants and signal pools, instantaneous input switching, no leakage, and no output trapped in unresolved complexes—the same closure used for the lecture's one-gate calculation [1]. Unequal gate speeds or finite input ramps can change the pulse, so each implementation needs its own composed simulation.

Also, an analog pulse is not automatically a binary mistake. A reader that calls output 1 only above 0.5 would still classify this particular trace correctly, although only 0.0457 of margin remains. My claim is therefore precise: a correct steady truth table does not certify the transient or its readout margin. A safe sampling time must be chosen from the worst path and initial state, not from one gate's settling time alone.
