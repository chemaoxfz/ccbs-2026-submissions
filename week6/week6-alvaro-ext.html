Week 6 — Extension: where the integer test sits — the exact Hopf of the repressilator

Author: Álvaro Bátrez · Week 6 (lecture 11, Thu Oct 15) · 2026-10-22 · CCBS 2026

One sentence: lecture 11 settled the integers — virtual targets, eigenvalues −1−g and −1+g/2 ± i √3 g/2, instability at g > 2, so the repressilator oscillates at Hill n = 3 but (g < 2 at every finite α) never at n = 2 — and I add what it left undrawn: the exact continuum Hopf boundary αcrit(n) = n/(n−2)·(2/(n−2))1/n, which shows the integer verdict is exactly right at integer resolution yet blind in between: at α = 20 the true boundary is n = 2.27, so n = 2.4 oscillates while the integer test still says "no".

The point I am adding

Lecture 11 read the repressilator through reaction-order structure. In its normalized variables (q̄i = qi/K, t̄ = t/t0) the model is

dq̄i/dt̄ = α/(1 + q̄i−1n) − q̄i, cyclic over the three genes.

Monomial balances per dominance regime, candidates falling outside their own regime become virtual targets — and the lecture did not stop at the structural story: it computed the local eigenvalues at the symmetric equilibrium,

−1−g,   −1 + g/2 ± i √3 g/2,

with instability exactly at g > 2 — oscillation at n = 3 (its case α = 100, equilibrium ≈ 3.14) and g < 2 at every finite α for n = 2. Those are statements about two integers. The question my lecture-4 exposition would ask next: in the continuum between them, where exactly does the oscillation die?

The lecture's loop gain g is, written in (α, n) alone, β = n(1 − x*/α) with x*(1 + x*n) = α. I verified its eigenvalue formula against the numeric Jacobian (max error 6×10⁻¹⁰ over 30 random (α, n)) and then took the step the lecture's two integer points never needed: set β = 2 and eliminate x*, which gives the Hopf boundary of the (n, α) plane in closed form, αcrit(n) = n/(n−2) · (2/(n−2))1/n for n > 2 — no rate constants, just structure, the way the lecture likes it. The lecture's own case sits far above the minimum: n = 3 needs only α > 3·21/3 = 3.78.

The code (core)

import numpy as np
from scipy.optimize import brentq

def xstar(a, n):  return brentq(lambda x: x*(1+x**n) - a, 1e-9, 10*a)
def beta(a, n):   return n*(1 - xstar(a, n)/a)     # loop gain at the equilibrium
def alpha_crit(n):                                # Hopf boundary, closed form
    return (n/(n-2)) * (2/(n-2))**(1/n)

# eigenvalues (exact):  lam1 = -1-beta ;  lam± = -1 + beta/2 ± i*beta*sqrt(3)/2
# Hopf at beta = 2.  Boundary verified: beta(alpha_crit(n), n) = 2.000000.
# n = 2: beta < 2 for every finite alpha (-> 2 only as alpha -> inf).

from scipy.integrate import solve_ivp
def runs(a, n, T=300, x0=(4,1,2)):
    f = lambda t, x: [-x[0] + a/(1+x[1]**n), -x[1] + a/(1+x[2]**n),
                      -x[2] + a/(1+x[0]**n)]
    return solve_ivp(f, [0,T], x0, method="LSODA", rtol=1e-9, atol=1e-11)
# alpha=20: n=2.0 decays | n=2.2 decays | n=2.4 oscillates (amp 4.0) | n=3 oscillates

Where this breaks

  • Symmetry is load-bearing. The closed form uses the symmetric equilibrium and the cyclic eigenvalues 1, e±2πi/3; an asymmetric repressilator has no such formula and its integer test may fail in either direction.
  • The Hopf is local; the limit cycle is checked only by simulation. I did not prove supercriticality — every simulated case beyond the boundary converged to a cycle, but that is evidence, not a theorem.
  • The lecture's verdict is not purely structural. Part 3 already computes the local eigenvalues and the g > 2 instability threshold — what it does not do is place the boundary in the continuum, comparing only the two integer points. That continuum boundary is this essay's contribution; the fair summary is: the lecture says whether (at integers), the closed form says where (for every n).
  • Continuous n is a modeling fiction — real Hill coefficients come from cooperativity and land where they land; the continuum sweep is a diagnostic of the test, not a design recipe.
