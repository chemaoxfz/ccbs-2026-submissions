A stable circuit can still
amplify a disturbance

Author: Wang Siheng (wangsiheng) · 24 October 2026 · Extending Lecture 11

One sentence: Even a circuit that is stable for every fixed positive turnover time can transiently amplify a small disturbance; a stability certificate guarantees eventual return, not a small excursion in the quantities we measure.

The point I am adding

Lecture 11 writes local dynamics in relative concentrations and uses a diagonal Lyapunov certificate to prove stability across turnover times [1]. I want to ask a different design question: how far can a disturbance grow before it disappears? The distinction is familiar from nonnormal linear systems, where stable eigenvalues can coexist with transient amplification [2]. Here is a two-pool example that makes the gap explicit, including why it does not contradict the lecture’s certificate.

Work it: a decaying signal can still drive another pool

Let x = δqX/qX* and y = δqY/qY* be small fractional deviations from a positive equilibrium. Choose equal turnover times and measure time in that common lifetime. The illustrative balance-order matrix is H = [−1, κ; 0, −1], with feedforward coupling κ ≥ 0. Both eigenvalues are −1 for every κ. Even with unequal fixed clocks, the matrix remains triangular, with eigenvalues −1/τX and −1/τY: it is D-stable. Nevertheless, a pulse in Y feeds X while both deviations relax.

Exact solution of the stated linear model. κ is a dimensionless local coupling; ε is a small initial fractional deviation. All parameters are illustrative.

The solution follows by substituting y(t) into the X equation and multiplying by et. The downstream response peaks at t = 1, with xmax/ε = κ/e. At κ = 8, a 1% upstream deviation therefore produces a 2.94% downstream peak in this linear model. The combined fractional disturbance has gain g(t) = √(x² + y²)/ε = e−t√(1 + κ²t²); its peak is 2.966 at t = 0.984. These are calculations from the displayed equations, not experimental data. Increasing κ changes the excursion without moving either eigenvalue.

The code behind the figure · JavaScript

// Exact solution, normalized by the initial y pulse.
function sample(t, k) {
  const y = Math.exp(-t);
  const x = k * t * y;
  const p = 1 + k * k / 4;
  return {
    ordinary: Math.hypot(x, y),
    weighted: Math.sqrt((x*x + p*y*y) / p)
  };
}

// Global peak for this initial condition, t >= 0.
function peak(k) {
  if (k <= 2) return {t: 0, gain: 1};
  const t = (1 + Math.sqrt(1 - 4/(k*k))) / 2;
  const gain = sample(t, k).ordinary;
  return gain > 1 ? {t, gain} : {t: 0, gain: 1};
}

// Plot 301 exact samples on 0 <= t <= 6.
function curves(k) {
  return Array.from({length: 301}, (_, i) => {
    const t = i * 6 / 300;
    return {t, ...sample(t, k)};
  });
}

Try κ = 0, then κ = 8. The weighted size keeps decreasing even when the ordinary size exceeds one. The solid curve is for the specified Y-only pulse, not the worst case over all initial directions.

The certificate still works. Choose P = diag(1, 1 + κ²/4), so V = x² + (1 + κ²/4)y². Direct differentiation gives the expression below, which is strictly negative away from equilibrium. At κ = 8, V gives Y a weight of 17: transfer from Y into X can increase ordinary distance while this weighted distance shrinks. Thus the certificate proves decay in a particular metric; it does not promise that every concentration excursion is small. The orange curve displays the extra quantity a circuit designer should check.

dV/dt = −2x² + 2κxy − 2(1 + κ²/4)y²
        = −2(x − κy/2)² − 2y² < 0   for (x, y) ≠ (0, 0).

What I would argue against / where this breaks

I would argue against using “stable” as shorthand for “small response.” This example is a local, deterministic model, not evidence that a particular biological circuit has κ = 8. Large excursions can invalidate the linearization, and biochemical mechanisms may constrain attainable coupling. The plotted gains assume equal clocks; unequal clocks change the transient even though stability remains. Finally, amplification depends on the chosen coordinates and metric: fractional concentrations make the comparison explicit, but another readout or weighting asks another question. The correct conclusion is to specify and calculate a transient gain alongside stability.
