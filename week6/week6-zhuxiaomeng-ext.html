One sentence: In a synNotch–CAR T-cell circuit, receptor persistence makes antigen history part of the decision, so a static AND truth table alone is incomplete.

The point I am adding

Lecture 12 connects molecular logic to decisions that depend on a cell's history.1 I want to make that connection concrete in immunotherapy. A static AND gate reads two current inputs. In Roybal and colleagues' circuit, antigen A activates a synthetic Notch receptor (synNotch), which induces a chimeric antigen receptor (CAR) recognizing antigen B.2 This introduces an internal state: the amount of CAR already expressed. What happens if A disappears before B is encountered?

Work it

Consider only the period after priming stops. Let C denote CAR expression above a negligible baseline and δ its effective removal rate. Assume no further production and first-order loss. Then:

dCdt=−δC,c(t)≡C(t)C(0)=e−δt=2−t/t1/2.

Here t1/2 is the expression half-life and time is in hours. The paper reports an approximately 8-hour half-life after removing a plate-bound surrogate priming stimulus in Jurkat cells (Figure 2F).2 I use that timescale in an illustrative decay model, without fitting the experimental curve. Normalizing both scenarios to the same initial level gives 70.7% remaining at 4 hours and 12.5% at 24 hours. If B is encountered at either time, the current inputs can be identical (A absent, B present), while receptor availability differs.

What I would argue against / where this breaks

I would argue against interpreting this circuit as an instantaneous coincidence detector. I would also argue against treating residual CAR as proof of off-target killing. The model omits antigen density, expression delays, signaling thresholds and cell movement. The 8-hour estimate is not a universal value for primary therapeutic T cells. Importantly, the authors found no evidence of killing a separate single-antigen tumor after priming in their tested mouse model.2 They also discussed temporal coupling, so this is a worked extension of an existing idea, not a new discovery. My narrower conclusion is that an AND label should be accompanied by the timing conditions under which it describes the biological response.

Reproduce the calculation and figure (Python 3)

Save this code as analysis.py and run python analysis.py. It writes decay.svg and decay.csv. No additional packages or network access are required.

"""Python 3, standard library only. Run: python analysis.py
Writes decay.svg and decay.csv in the current directory.
8 h: approximate Jurkat CAR-expression half-life reported in Roybal et al.
4 h and 16 h: illustrative sensitivity assumptions, not measurements.
The first-order decay law is a model assumption, not a fit to raw data.
"""
import csv
import math
from pathlib import Path

def remaining(hours, half_life=8):
    return 2 ** (-hours / half_life)

def make_svg():
    left, top, width, height = 72, 64, 530, 190
    x = lambda t: left + width * t / 32
    y = lambda c: top + height * (1 - c)
    parts = ['<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 318" role="img" aria-labelledby="plot-title plot-desc">',
             '<title id="plot-title">Receptor availability depends on the time since priming ended</title>',
             '<desc id="plot-desc">First-order decay model. An eight-hour half-life gives 70.7 percent remaining after four hours and 12.5 percent after twenty-four hours. Four- and sixteen-hour half-lives are sensitivity assumptions. No killing outcome is predicted.</desc>',
             '<rect width="640" height="318" fill="#fff"/>',
             '<g font-family="Arial, sans-serif" fill="#20201e" font-size="12">',
             '<text x="72" y="22" font-size="15" font-weight="bold">Same current inputs; different receptor histories</text>',
             '<text x="72" y="42" fill="#566">Model illustration. Priming stops at hour 0; initial receptor level = 1.</text>']
    for v in [0, .25, .5, .75, 1]:
        parts += [f'<line x1="{left}" y1="{y(v):.2f}" x2="{left+width}" y2="{y(v):.2f}" stroke="#e5e7eb"/>',
                  f'<text x="60" y="{y(v)+4:.2f}" text-anchor="end">{v:g}</text>']
    for t in [0, 4, 8, 16, 24, 32]:
        parts += [f'<text x="{x(t):.2f}" y="275" text-anchor="middle">{t}</text>']
    parts += [f'<path d="M{left},{top} V{top+height} H{left+width}" fill="none" stroke="#20201e"/>',
              '<text x="337" y="305" text-anchor="middle">Time after priming stimulus removal (hours)</text>',
              '<text x="18" y="159" transform="rotate(-90 18 159)" text-anchor="middle">Relative CAR expression</text>']
    for half, color, dash in [(4,'#877f77','5 4'),(16,'#1f9a8e','7 4'),(8,'#5a73ce','')]:
        points = ' '.join(f'{x(i/10):.2f},{y(remaining(i/10, half)):.2f}' for i in range(321))
        parts += [f'<polyline points="{points}" fill="none" stroke="{color}" stroke-width="2.5" stroke-dasharray="{dash}"/>']
    for t in [4,24]:
        c=remaining(t)
        parts += [f'<line x1="{x(t):.2f}" y1="{y(c):.2f}" x2="{x(t):.2f}" y2="254" stroke="#b8aea5" stroke-dasharray="3 3"/>',
                  f'<circle cx="{x(t):.2f}" cy="{y(c):.2f}" r="5" fill="#5a73ce" stroke="white"/>',
                  f'<text x="{x(t)+9:.2f}" y="{y(c)-10:.2f}" fill="#344c9c">{100*c:.1f}%</text>']
    for yy,label,col,dash in [(85,'8 h: reported scale','#5a73ce',''),(105,'4 h: assumed','#877f77','5 4'),(125,'16 h: assumed','#1f9a8e','7 4')]:
        parts += [f'<line x1="397" y1="{yy-4}" x2="426" y2="{yy-4}" stroke="{col}" stroke-width="2.5" stroke-dasharray="{dash}"/>',f'<text x="434" y="{yy}">{label}</text>']
    return '\n'.join(parts + ['</g></svg>'])

if __name__ == '__main__':
    Path('decay.svg').write_text(make_svg(), encoding='utf-8')
    with open('decay.csv', 'w', newline='') as f:
        writer=csv.writer(f)
        writer.writerow(['hours_after_removal','half_life_hours','relative_expression'])
        for half in [4,8,16]:
            for t in range(33):
                writer.writerow([t, half, remaining(t,half)])
    for t in [4,8,16,24]:
        print(f'{t} h: {100*remaining(t):.3f}% remaining')
