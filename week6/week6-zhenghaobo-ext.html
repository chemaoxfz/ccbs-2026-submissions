Week 6 — Extension: Perfect adaptation has a clock

Author: Zheng Haobo · Week 6 (2026-10-26) · CCBS 2026
One sentence: Zero steady gain fixes this circuit's constant-input endpoint, not its small-step relative peak (set by r) or increasing-exponential asymptotic offset (set by τ2).

The point I am adding

Core Figure 7 already says “Different clocks change the transient, not the return.” Figure 9 already plots this model's matched response: at r = 1, w:1→2, the fold-level output goes 1.00→1.3075→1.00 (peak independently reproduced below). Neither gives peak-height/time formulas, their r-dependence, or ramps: my additions. The model, with positive parameters, is q̇1 = k1w − δq1q2,   q̇2 = k2w − γq2,   y = q1;   q1* = k1γ/(δk2),   q2* = k2w*/γ. q1 is the output pool; q2 controls removal. At input w*, define zi = (qi−qi*)/qi*, zw = Δw/w*, and turnover time τi = qi*/fi*, where fi* is balanced production/removal flux. Thus τ1 = γ/(δk2w*), τ2 = 1/γ, and r = τ2/τ1 (unit rate constants give r = w*).

Work it

Dimensionless blocks (state, input, readout, direct input): HA = −1−10−1,   Hb = (1, 1)T,   Hc = (1, 0),   Hd = 0.
Core's boxed equation: ż = diag(τ)−1(HAz + Hbzw),   zy = Hcz + Hdzw = z1. The eigenvalues are −1/τ1, −1/τ2; the steady gain Hd−Hc(HA)−1Hb is zero. For a small positive step from z(0)=0, solve τ2ż2 = zw−z2, then τ1ż1 = zw−z1−z2: z1(t) = zw [r/(r−1)] (e−t/τ2 − e−t/τ1),   r ≠ 1.
ż1 = 0 ⇒ tp = τ1 r ln(r)/(r−1),   p = max z1 = zw r−1/(r−1). As r→1, ln(r)/(r−1)→1: z1 = zw(t/τ1)e−t/τ1, p/zw→1/e, and tp→τ1. As r→∞, ln(r)/(r−1)→0, so p/zw→1. At r=2 it is 0.5. “Relative peak” means max(δq1/q1*); the fold-level peak is 1+p.

Now let w = w0eβt, β>0, in the original nonlinear equations. Exactly, q2 = k2w/(γ+β) + Ce−γt. Against its moving equilibrium q2,eq = k2w/γ (unlike the step reference), z̃2→−β/(γ+β). The quasi-static balance q1q2≈k1w/δ becomes asymptotically valid: write q̇1=a(t)[b(t)−q1], where a=δq2>0, ∫a dt diverges, and b=k1w/(δq2)→k1(γ+β)/(δk2). Variation of constants therefore gives q1/q1* − 1 → −z̃2/(1+z̃2) → β/γ = βτ2. This offset is asymptotic, not instantaneous. Original-ODE integration (β=0.1, γ=1, w0=1, t=80) gives absolute relative-offset error 2.5e-15, with tolerance refinement checked.

What I would argue against / where this breaks

Zero gain alone bounds neither quantity; these dependencies require this model/input family. The peak formula is local. With unit rate constants, w0=1 and input multipliers ×1.1/×2/×3/×10, nonlinear relative peaks differ from linear predictions by −2.3%/−16.4%/−25.8%/−50.8%; w0=4 shows the same pattern (folded results). Discount means 100(pnonlinear/plinear−1). Figure 9's reproduced fold peak 1.3075 means p=0.3075: precisely the ×2 case's −16.4%. The ramp limit requires increasing exponential input and indefinite validity of the bilinear law; saturation or substantial binding requires recalculating the orders and conclusions (core §6).

"""Bilinear feedforward adaptation; dimensionless concentration and time units."""
import json
import platform
import numpy as np
import scipy
from scipy.integrate import solve_ivp

RTOL, ATOL = 2e-13, 2e-14

def peak(r):
    return float(np.exp(-np.log(r)/(r-1))) if r != 1 else float(1/np.e)

def peak_time(r):
    return float(np.log(r)/(r-1)) if r != 1 else 1.0  # tau2 = 1; tau1 = 1/r

def exact(t, r):
    t = np.asarray(t)
    return t*np.exp(-t) if r == 1 else r/(r-1)*np.exp(-t)*(-np.expm1(-t*(r-1)))

def integrate(fun, initial, end, method="DOP853", rtol=RTOL, atol=ATOL, events=True):
    def turning(t, q): return fun(t, q)[0]
    turning.direction = -1
    sol = solve_ivp(fun, (0, end), initial, method=method, rtol=rtol, atol=atol,
                    dense_output=True, events=turning if events else None)
    assert sol.success, sol.message
    return sol

def calculate():
    results = {"versions": {"python": platform.python_version(), "numpy": np.__version__, "scipy": scipy.__version__},
               "solver": {"rtol": RTOL, "atol": ATOL}, "linear": [], "nonlinear": [], "exponential": []}
    grid = np.unique(np.r_[0, np.geomspace(1e-5, 12, 700)])
    curves = {}
    for r in (1.5, 2, 4, 10, 100):
        fun = lambda t, z: [r*(1-z[0]-z[1]), 1-z[1]]
        sol = integrate(fun, [0, 0], 12, "Radau")
        tm = float(sol.t_events[0][0]); pm = float(sol.sol(tm)[0])
        error = float(np.max(np.abs(sol.sol(grid)[0]-exact(grid, r))))
        assert error < 1e-10 and abs(tm-peak_time(r)) < 1e-9 and abs(pm-peak(r)) < 1e-10
        results["linear"].append(dict(r=r, peak=peak(r), time=peak_time(r), numeric_peak=pm, numeric_time=tm, max_error=error))
        if r in (2, 10): curves[str(r)] = dict(t=grid.tolist(), z=sol.sol(grid)[0].tolist(), peak=[tm, pm])
    results["limits"] = {"r_to_1": peak(1), "r_to_infinity": 1.0,
                         "r_near_1": peak(1+1e-7), "r_large": peak(1e9), "time_r_to_1_in_tau1": 1.0}
    # Linearized ramp z_w = a*t; its late relative offset is a*tau2.
    a, r = 0.01, 4
    lin = integrate(lambda t, z: [r*(a*t-z[0]-z[1]), a*t-z[1]], [0, 0], 40)
    results["linear_ramp"] = dict(a=a, r=r, time=40, expected=a, observed=float(lin.y[0,-1]), error=abs(float(lin.y[0,-1])-a))
    assert results["linear_ramp"]["error"] < 1e-10
    # Original nonlinear rates: k1=k2=delta=1; q1*=gamma, q2*=w0/gamma.
    for gamma, w0 in ((1, 1), (1, 4), (2, 1)):
        beta, end = 0.1*gamma, 80/gamma
        fun = lambda t, q: [w0*np.exp(beta*t)-q[0]*q[1], w0*np.exp(beta*t)-gamma*q[1]]
        sol = integrate(fun, [gamma, w0/gamma], end, "Radau", events=False)
        fine = integrate(fun, [gamma, w0/gamma], end, "Radau", 5e-14, 5e-15, events=False)
        observed = float(sol.y[0,-1]/gamma-1); expected = beta/gamma
        z2 = float(sol.y[1,-1]/(w0*np.exp(beta*end)/gamma)-1)
        error = abs(observed-expected); refinement = abs(float(fine.y[0,-1]-sol.y[0,-1])/gamma)
        assert error < 1e-10 and refinement < 1e-10
        results["exponential"].append(dict(gamma=gamma, w0=w0, beta=beta, time=end, expected=expected, observed=observed,
                                           error=error, refinement=refinement, moving_z2=z2, expected_z2=-beta/(gamma+beta)))
    for w0 in (1, 4):
        for fold in (1.1, 2, 3, 10):
            w = w0*fold
            sol = integrate(lambda t, q: [w-q[0]*q[1], w-q[1]], [1, w0], 24)
            tm = float(sol.t_events[0][0]); pm = float(sol.sol(tm)[0]-1)
            prediction = (fold-1)*peak(w0); discount = 100*(pm/prediction-1)
            results["nonlinear"].append(dict(w0=w0, fold=fold, relative_peak=pm, fold_peak=1+pm,
                                              linear_peak=prediction, discount_percent=discount, time=tm))
    results["peak_ratio"] = peak(10)/peak(2)
    results["checks_passed"] = True
    return results, {"peak_curve": {"r": np.geomspace(0.02, 100, 500).tolist(),
                     "p": [peak(r) for r in np.geomspace(0.02, 100, 500)]}, "trajectories": curves}

if __name__ == "__main__":
    results, data = calculate()
    print(json.dumps(results, indent=2))
    print("Figure data: 500 closed-form points; 701 time points per integrated trajectory; tau2=1, z_w=1.")
