How long does a molecular winner take to win?

Author: Chengwei Jin · Week 6 (2026-10-22) · CCBS 2026

One sentence: In this deterministic majority circuit, the time to a fixed winning threshold grows without bound as the initial advantage approaches zero, although the eventual winner remains determined.

The point I am adding

Lecture 12 proves that, in its deterministic winner-take-all network, the initially more abundant species eventually occupies the conserved pool.[1] I ask how long this takes. If a downstream action has a deadline, eventual correctness alone is insufficient. I keep the lecture’s reactions and vary only the initial advantage, separating the identity of the winner from the time needed to read it.

Work it

Let X,Y,Z denote concentrations. All three reactions share the positive rate constant k, with units of inverse concentration per time:

X+Y→k2Z,Z+X→k2X,Z+Y→k2Y.

The total Q=X+Y+Z is conserved. Use fractions x=X/Q, y=Y/Q, z=Z/Q and time τ=kQt. Start with no intermediate and relative advantage ϵ=x(0)−y(0), where 0<ϵ<1:

z(0)=0,x(0)=1+ϵ2,y(0)=1−ϵ2.

Define τ90 as the first time x=0.9. This finite threshold avoids waiting for exact extinction of an initially present minority. To expose the delay, set δ=x−y. Mass action and conservation give

dδdτ=zδ,dzdτ=1−4z+3z2−δ22.

The tied equilibrium is (x,y,z)=(1/3,1/3,1/3). Nearby, the small difference grows approximately as dδ/dτ≈δ/3. An almost tied trajectory first approaches this state, then leaves as its advantage grows. During that slow departure, exponential amplification gives

δout≈δineΔτ/3⟹Δτ≈3ln(δoutδin).

Choose a small fixed exit difference δout. The entry difference δin is proportional to the initial advantage, because the preceding approach gives a finite amplification. The time outside this neighborhood remains bounded as ϵ decreases. Consequently,

τ90≈3ln(1ϵ)+C90,ϵ→0+.

The constant C90 collects the remaining entry and exit time. The coefficient three comes from the growth rate near the tied state, rather than a curve fit. Reducing the initial advantage tenfold should add approximately 3ln10 dimensionless time units.

Numerical integration gives 14.16, 21.07 and 27.98 for initial X:Y percentages of 51:49, 50.1:49.9 and 50.01:49.99. The successive delays both approach 6.91. A separate fixed-step integration agrees within 4×10−7 time units. Repeating the calculation at a 95% threshold changes the times but preserves the near-tie increment. Physical time is T90=τ90/(kQ).

Reproduce the calculation and figure

Save the code below as reproduce.py and run python reproduce.py. Requires NumPy, SciPy and Matplotlib. It writes the numerical results, CSV data and SVG/PDF/PNG figure to a generated folder. It also checks a direct three-concentration integration, conservation, an exact tie, a second threshold and an independent RK4 calculation.

"""Reproduce the Week 6 winner-take-all timing calculation and both figure panels.

Run: python reproduce.py
Requires numpy, scipy and matplotlib. No data downloads or random sampling.
All concentrations are fractions of Q; tau=k*Q*t is dimensionless time.
The course model uses the same bimolecular rate constant k in all three reactions.
"""
from pathlib import Path
import csv
import json
import math
import sys

import numpy as np
from scipy.integrate import solve_ivp
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

BASE = Path(__file__).resolve().parent
OUT = BASE / "generated"
OUT.mkdir(exist_ok=True)


def rhs(tau, state):
    """state=(delta,z); delta=x-y, z=Z/Q, and x+y+z=1."""
    delta, z = state
    return np.array([z * delta, (1 - 4*z + 3*z*z - delta*delta)/2])


def integrate(epsilon, threshold=0.9, max_step=0.1):
    def crossing(tau, state):
        delta, z = state
        return (1 - z + delta)/2 - threshold
    crossing.terminal = True
    crossing.direction = 1
    solution = solve_ivp(
        rhs, (0, 150), [epsilon, 0.0], method="DOP853",
        rtol=2e-12, atol=[1e-16, 1e-14], max_step=max_step,
        events=crossing, dense_output=True,
    )
    assert solution.success
    assert solution.t_events[0].size == 1, "The winning threshold was not reached."
    return float(solution.t_events[0][0]), solution


def rk4_event(epsilon, step=0.0025, threshold=0.9):
    """Independent fixed-step integration with linear crossing interpolation."""
    state = np.array([epsilon, 0.0])
    tau = 0.0
    for _ in range(100000):
        x = (1 - state[1] + state[0])/2
        a = rhs(tau, state)
        b = rhs(tau + step/2, state + step*a/2)
        c = rhs(tau + step/2, state + step*b/2)
        d = rhs(tau + step, state + step*c)
        new = state + step*(a + 2*b + 2*c + d)/6
        xn = (1 - new[1] + new[0])/2
        if xn >= threshold:
            return tau + step*(threshold-x)/(xn-x)
        state, tau = new, tau+step
    raise RuntimeError("No threshold crossing in RK4 check.")


def direct_rhs(tau, state):
    x, y, z = state
    return [x*(z-y), y*(z-x), 2*x*y-z*(x+y)]


EPSILONS = [0.02, 0.002, 0.0002]
rows = []
trajectories = []
max_rk4_error = 0.0
max_direct_error = 0.0
max_conservation_error = 0.0
minimum_fraction = 0.0
for epsilon in EPSILONS:
    tau90, solution = integrate(epsilon)
    rk4 = rk4_event(epsilon)
    half_step, _ = integrate(epsilon, max_step=0.05)
    max_rk4_error = max(max_rk4_error, abs(tau90-rk4))
    sample = np.linspace(0, tau90, 501)
    delta, z = solution.sol(sample)
    x, y = (1-z+delta)/2, (1-z-delta)/2
    direct = solve_ivp(
        direct_rhs, (0, tau90), [(1+epsilon)/2, (1-epsilon)/2, 0],
        method="DOP853", rtol=2e-12, atol=1e-14,
        max_step=0.05, dense_output=True,
    )
    xyz = direct.sol(sample)
    max_direct_error = max(max_direct_error, float(np.max(np.abs(xyz-np.array([x,y,z])))))
    max_conservation_error = max(max_conservation_error, float(np.max(np.abs(xyz.sum(axis=0)-1))))
    minimum_fraction = min(minimum_fraction, float(xyz.min()))
    assert abs(tau90-half_step) < 1e-7
    rows.append({"epsilon":epsilon, "initial_x_fraction":(1+epsilon)/2,
                 "initial_y_fraction":(1-epsilon)/2, "tau90":tau90,
                 "T90_in_physical_time":"tau90/(k*Q)"})
    trajectories.append((epsilon, sample, x, y, z))

assert max_rk4_error < 2e-6
assert max_direct_error < 1e-8
assert max_conservation_error < 1e-10
assert minimum_fraction > -1e-12

# Exact tie must remain invariant. It tends to (x,y,z)=(1/3,1/3,1/3).
tie = solve_ivp(rhs, (0, 80), [0, 0], method="DOP853", rtol=2e-12, atol=1e-14, max_step=0.1)
assert np.max(np.abs(tie.y[0])) == 0
assert abs(tie.y[1,-1]-1/3) < 1e-12

# Test the near-tie coefficient using two distinct completion thresholds.
predicted_increment = 3*math.log(10)
threshold_checks = []
for threshold in [0.9, 0.95]:
    times = [integrate(epsilon, threshold)[0] for epsilon in [0.002, 0.0002, 0.00002]]
    increment = times[-1]-times[-2]
    assert abs(increment-predicted_increment) < 1e-5
    threshold_checks.append({"threshold":threshold,"times":times,
                             "last_decade_increment":increment})

grid = np.geomspace(0.2, 0.00001, 51)
times = np.array([integrate(float(epsilon))[0] for epsilon in grid])
assert np.all(np.diff(times)>0)
# The slope is derived, not fitted. An additive offset is anchored at epsilon=1e-5.
offset = float(times[-1]-3*np.log(1/grid[-1]))
guide = 3*np.log(1/grid)+offset

result = {
    "model":"X+Y->2Z; Z+X->2X; Z+Y->2Y, equal rate k",
    "initial_intermediate":0, "winning_fraction":0.9,
    "time_unit":"tau=k*Q*t", "table":rows,
    "predicted_increment_per_decade":predicted_increment,
    "observed_increments":np.diff([row['tau90'] for row in rows]).tolist(),
    "guide_offset_anchor_epsilon":float(grid[-1]),"guide_offset":offset,
    "checks":{"max_RK4_time_error":max_rk4_error,
              "max_direct_coordinate_error":max_direct_error,
              "max_conservation_error":max_conservation_error,
              "minimum_direct_fraction":minimum_fraction,
              "exact_tie_delta":float(tie.y[0,-1]),
              "exact_tie_z":float(tie.y[1,-1]),
              "threshold_checks":threshold_checks},
    "environment":{"python":sys.version.split()[0],"numpy":np.__version__,
                   "matplotlib":matplotlib.__version__},
}
(OUT/'results.json').write_text(json.dumps(result,indent=2),encoding='utf-8')
with (OUT/'timing-scan.csv').open('w',newline='',encoding='utf-8') as f:
    writer=csv.writer(f);writer.writerow(['initial_relative_advantage','tau90','slope3_guide'])
    writer.writerows(zip(grid,times,guide))
with (OUT/'trajectories.csv').open('w',newline='',encoding='utf-8') as f:
    writer=csv.writer(f);writer.writerow(['epsilon','tau','x','y','z'])
    for epsilon,sample,x,y,z in trajectories:
        writer.writerows(zip(np.full_like(sample,epsilon),sample,x,y,z))

# Matplotlib ships Computer Modern fonts; use those without requiring TeX.
cmr = Path(matplotlib.get_data_path())/'fonts/ttf/cmr10.ttf'
font_manager.fontManager.addfont(str(cmr))
plt.rcParams.update({
    'font.family':'cmr10','mathtext.fontset':'cm','font.size':13,
    'axes.formatter.use_mathtext':True,'svg.fonttype':'path',
    'axes.spines.top':False,'axes.spines.right':False,
    'axes.labelsize':14,'xtick.labelsize':12,'ytick.labelsize':12,
    'axes.edgecolor':'#877F77','axes.labelcolor':'#20201E',
    'text.color':'#20201E','xtick.color':'#20201E','ytick.color':'#20201E',
    'savefig.facecolor':'white','figure.facecolor':'white',
})
colors=['#D75567','#1F9A8E','#5A73CE']
fig,axs=plt.subplots(2,1,figsize=(6.9,7.3))
fig.subplots_adjust(left=.13,right=.97,bottom=.09,top=.95,hspace=.56)
ax=axs[0]
for color,row,(_,sample,x,y,z) in zip(colors,rows,trajectories):
    label=rf"$\epsilon={row['epsilon']:g}$"
    ax.plot(sample,x,color=color,lw=2.3,label=label)
    ax.scatter([row['tau90']],[.9],s=38,c=[color],edgecolors='white',linewidths=.8,zorder=5)
    ax.annotate(f"{row['tau90']:.2f}",(row['tau90'],.9),xytext=(0,10),textcoords='offset points',ha='center',color=color,fontsize=12)
ax.axhline(.9,color='#877F77',lw=1,ls='--',zorder=0)
ax.set(xlim=(0,30),ylim=(.27,1.03),xlabel=r'Dimensionless time $\tau=kQt$',ylabel=r'Winner fraction $X/Q$')
ax.set_yticks([1/3,.5,.7,.9]);ax.set_yticklabels([r'$1/3$',r'$0.5$',r'$0.7$',r'$0.9$'])
ax.legend(loc='lower right',frameon=False,fontsize=12)
ax.set_title('A  Smaller initial leads take longer to reach 90%',loc='left',fontsize=15,pad=13)
ax.grid(axis='y',color='#EDE7E0',lw=.7,zorder=0)

ax=axs[1]
ax.plot(1/grid,times,color='#D75567',lw=2.3,label='ODE threshold time')
ax.plot(1/grid,guide,color='#20201E',lw=1.3,ls='--',label=r'$3\ln(1/\epsilon)+C$ guide')
for color,row in zip(colors,rows):
    ax.scatter([1/row['epsilon']],[row['tau90']],s=38,c=[color],edgecolors='white',linewidths=.8,zorder=5)
ax.set_xscale('log');ax.set(xlim=(5,1e5),ylim=(0,40),xlabel=r'Inverse initial advantage $1/\epsilon$',ylabel=r'Decision time $\tau_{90}$')
ax.set_xticks([10,100,1000,10000,100000]);ax.set_yticks([0,10,20,30,40])
ax.legend(loc='upper left',frameon=False,fontsize=12)
ax.set_title('B  Near a tie, each tenfold reduction adds 6.91',loc='left',fontsize=15,pad=13)
ax.grid(axis='y',color='#EDE7E0',lw=.7,zorder=0)
for extension in ['svg','pdf','png']:
    fig.savefig(OUT/f'winner-timing.{extension}',dpi=180)
plt.close(fig)
print(json.dumps(result,indent=2))

What I would argue against / where this breaks

This is a near-tie result for continuous deterministic concentrations, equal rates and the stated initial condition. It is not a probability of choosing the correct winner. Discrete stochastic majority models require separate probability and completion-time calculations.[2] An exact tie stays symmetric here and never reaches the winning threshold. Unequal rates, an initial intermediate pool or molecular noise require new checks. Thus a deadline turns the initial advantage into a performance requirement: knowing which state wins does not specify when its answer is usable.
