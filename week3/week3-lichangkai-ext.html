When a steady state hides a slow response: a timescale extension of biochemical dynamics

Question

Lecture 3 introduced reaction networks as dynamical systems: dx/dt = Γv(x). A common intuition is that if two systems have the same steady state, they should recover similarly after perturbations. Here I test a related question: can two systems with the same final level have very different recovery times?

Model

Consider a simple production–degradation model:

dx/dt = k - γx

The steady state is x*=k/γ, but the relaxation time is τ=1/γ. Therefore changing the degradation rate changes the speed of recovery without changing the idea of a production/degradation balance.

A numerical experiment

I fixed the steady state at 100 molecules by choosing different pairs of (k, γ). Three systems all satisfy k/γ=100, but their recovery speeds differ. The simulation below was generated with the following Python code. 

import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 10, 500)

for gamma in [0.2, 1, 5]:
    k = 100 * gamma
    x0 = 0
    x = k/gamma + (x0-k/gamma)*np.exp(-gamma*t)
    plt.plot(t, x, label=f"gamma={gamma}")

plt.xlabel("time")
plt.ylabel("molecule number")
plt.legend()
plt.savefig("recovery.png", dpi=200)

Result

The computed half-times are:

  • γ = 0.2: τ1/2 = ln(2)/0.2 = 3.47 time units
  • γ = 1: τ1/2 = ln(2)/1 = 0.69 time units
  • γ = 5: τ1/2 = ln(2)/5 = 0.14 time units

Interpretation

The steady state only describes a balance between addition and removal. It does not tell us the transient behavior. In biological systems this means measuring only the final protein abundance can miss important mechanistic differences: two cells may contain the same amount of a protein while having very different turnover rates and responses to environmental changes.

Reproducibility

All calculations use the analytical solution x(t)=x*+(x(0)-x*)exp(-γt). The only external mathematical fact used is the half-life relationship t1/2=ln(2)/γ.
