Week 3 — Extension: A stable fixed point is only metastable — extinction at the zero boundary

Author: Leo Sin · Week 3 (2026-09-21) · CCBS 2026

One sentence: For any self-replicating species whose production rate vanishes at zero copies, the zero boundary that Lecture 5 put on the master equation is an absorbing trap that is reached with probability one — so a deterministically stable fixed point only buys a lifetime that grows exponentially with copy number, not immortality.

The point I am adding

Lecture 5 built the master equation for integer molecule counts, put a zero boundary on the probability flow (counts cannot go negative), and then showed that as copy numbers grow the deterministic rate equation takes over. The deterministic picture is then handed to Lecture 4's machinery: find fixed points, check stability. I want to point at a case where the two pictures give opposite long-time answers, and quantify exactly how long you have to wait to see it.

Take the simplest self-replicating population with competition: molecules are born at per-capita rate b, and die at per-capita rate d plus a crowding term c·i per molecule. The deterministic equation is the logistic

dx/dt = (b − d)·x − c·x²,   with stable carrying capacity K = (b − d)/c,

stable for every K. But stochastically, birth requires an existing molecule: from X = 0 nothing is ever born again. The zero boundary is absorbing, and a birth–death chain with an absorbing state reachable from everywhere hits it with probability one. The "stable fixed point" is metastable: the population sits near K in a so-called quasi-stationary distribution, looking perfectly equilibrated, until one unlucky run of death fluctuations walks it down to zero — permanently. The only question left, and the one I answer below, is: how long does that take?

Work it

I set b = 2, d = 1 (time unit = one mean molecule lifetime, 1/d) and choose the crowding c = (b − d)/K so that the deterministic carrying capacity is exactly K molecules. Figure 1 shows the tension directly: the deterministic solution climbs to K and stays, while a Gillespie run of the same process hovers around K for thousands of molecule-lifetimes — long enough to look stationary in any experiment — and then collapses to zero without warning.

The mean waiting time can be computed exactly, with no Monte Carlo error. Conditioning on the first step (the backward equation from Lecture 5's probability-flow picture) gives, for the mean extinction time Ti starting from i molecules,

−1 = λi(Ti+1 − Ti) + μi(Ti−1 − Ti),   T₀ = 0,

a tridiagonal linear system that the code below solves directly. Figure 2 compares this exact answer with Gillespie averages: they agree within statistical error, and the message is in the shape — the mean extinction time grows exponentially in K, by a factor of ten for every ~8 extra copies of carrying capacity.

Read off the scale: at K = 10 the population lives ≈ 26 molecule-lifetimes (if these are bacterial mRNAs with ~5-minute lifetimes, about two hours); at K = 30, ≈ 5.4×10³; at K = 100, ≈ 5.6×10¹² lifetimes — of order 10⁷ years, effectively never. The exponential-in-K law is the classic result for the stochastic logistic model (Nåsell 2001; Doering, Sargsyan & Sander 2005, who also show that the diffusion approximation gets even the exponent wrong — this is a genuinely discrete effect). This is why deterministic stability theory works at all: it describes the K → ∞ limit, where the lifetime diverges. But for anything that self-replicates at tens of copies — plasmids, mitochondrial genomes, a small founding population — the expiration date is real and short, and no stability analysis of the rate equation will mention it.

Code that produces Figures 1 and 2 and every quoted number (Python, numpy + matplotlib) 
"""
Week 3 extension: deterministic stability vs stochastic extinction.

Model: logistic birth-death process.
    birth: X -> X+1 at rate b*i
    death: X -> X-1 at rate d*i + c*i^2,  c = (b-d)/K
Deterministic limit: dx/dt = (b-d)x - c x^2, stable carrying capacity x* = K.
Stochastic: state 0 is absorbing, so extinction is certain; we measure and
compute exactly the mean time to extinction starting from X(0) = K.

Outputs: fig1.svg, fig2.svg, and printed numbers quoted in the essay.
"""
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
B, D = 2.0, 1.0  # per-capita birth / death


def exact_mean_extinction_time(K, b=B, d=D):
    """Mean first-passage time from X(0)=K to 0, exactly, via the backward
    equation  -1 = lam_i (T_{i+1}-T_i) + mu_i (T_{i-1}-T_i),  T_0 = 0,
    solved as a tridiagonal system truncated far above K (reflecting top,
    which is harmless because deaths dominate there)."""
    c = (b - d) / K
    N = int(12 * K) + 50
    i = np.arange(1, N + 1, dtype=float)
    lam = b * i
    mu = d * i + c * i * i
    # tridiagonal coefficients for T_i: lower* T_{i-1} + diag * T_i + upper * T_{i+1} = -1
    lower = mu.copy()
    diag = -(lam + mu)
    upper = lam.copy()
    upper[-1] = 0.0  # reflecting truncation at N
    diag[-1] = -mu[-1]  # -1 = mu_N (T_{N-1} - T_N)
    rhs = -np.ones(N)
    # Thomas algorithm for the tridiagonal system
    for k in range(1, N):
        w = lower[k] / diag[k - 1]
        diag[k] -= w * upper[k - 1]
        rhs[k] -= w * rhs[k - 1]
    T = np.empty(N)
    T[-1] = rhs[-1] / diag[-1]
    for k in range(N - 2, -1, -1):
        T[k] = (rhs[k] - upper[k] * T[k + 1]) / diag[k]
    return T[int(round(K)) - 1]  # start from X(0)=K


def gillespie_extinction_times(K, n_runs, b=B, d=D, t_max=1e9):
    """Direct Gillespie (Doob) simulation; returns extinction times from X(0)=K."""
    c = (b - d) / K
    times = np.empty(n_runs)
    for r in range(n_runs):
        x, t = K, 0.0
        while x > 0 and t < t_max:
            lam = b * x
            mu = d * x + c * x * x
            rate = lam + mu
            t += rng.exponential(1.0 / rate)
            if rng.random() < lam / rate:
                x += 1
            else:
                x -= 1
        times[r] = t
    return times


def gillespie_trajectory(K, b=B, d=D, t_max=1e9, max_steps=2_000_000):
    """One trajectory (thinned for plotting), from X(0)=K to extinction."""
    c = (b - d) / K
    x, t = K, 0.0
    ts, xs = [0.0], [x]
    steps = 0
    while x > 0 and t < t_max and steps < max_steps:
        lam = b * x
        mu = d * x + c * x * x
        rate = lam + mu
        t += rng.exponential(1.0 / rate)
        x += 1 if rng.random() < lam / rate else -1
        steps += 1
        if steps % 300 == 0 or x == 0:
            ts.append(t)
            xs.append(x)
    return np.array(ts), np.array(xs)


# ---- 1) exact numbers, to size the simulation budget ----
Ks_exact = np.array([5, 10, 15, 20, 25, 30, 35, 40, 50, 60, 80, 100])
exact = np.array([exact_mean_extinction_time(K) for K in Ks_exact])
print("K, exact mean extinction time (start at K):")
for K, T in zip(Ks_exact, exact):
    print(f"  K={K:4d}   T={T:.3e}")

# ---- 2) Gillespie means where affordable ----
sim_Ks, sim_means, sim_sems, sim_n = [], [], [], []
for K in [5, 10, 15, 20, 25, 30]:
    T_exact = exact_mean_extinction_time(K)
    n_runs = 400 if T_exact < 3e3 else 120
    ts = gillespie_extinction_times(K, n_runs)
    sim_Ks.append(K)
    sim_means.append(ts.mean())
    sim_sems.append(ts.std() / np.sqrt(n_runs))
    sim_n.append(n_runs)
    print(f"sim K={K:3d} n={n_runs} mean={ts.mean():.3e} sem={sim_sems[-1]:.1e} "
          f"(exact {T_exact:.3e}, ratio {ts.mean()/T_exact:.3f})")

# ---- 3) trajectories for fig 1 (K=30, three independent runs) ----
K_traj = 30
trajs = [gillespie_trajectory(K_traj) for _ in range(3)]
for j, (ts, xs) in enumerate(trajs):
    print(f"traj {j}: extinct at t={ts[-1]:.1f}")

# deterministic ODE solution: x(t) = K x0 / (x0 + (K - x0) e^{-(b-d) t})
def ode(t, x0, K, b=B, d=D):
    r = b - d
    return K * x0 / (x0 + (K - x0) * np.exp(-r * t))

# ---- figures ----
plt.rcParams.update({"font.size": 9, "axes.linewidth": 0.8,
                     "svg.fonttype": "none", "path.simplify": True,
                     "path.simplify_threshold": 0.5})

ts0, xs0 = trajs[2]  # the run extinct at t ~ 7400
fig, ax = plt.subplots(figsize=(6.4, 2.9))
t_grid = np.linspace(0, ts0[-1] * 1.04, 400)
ax.plot(t_grid, ode(t_grid, K_traj, K_traj), color="#1f4e79", lw=2.2,
        label="deterministic limit, $x(t)$", zorder=3)
ax.plot(ts0, xs0, color="#c0392b", lw=0.9, alpha=0.95,
        label="one Gillespie run, $X(t)$", zorder=2)
ax.annotate("extinction:\nno warning, no return", xy=(ts0[-1], 1),
            xytext=(ts0[-1]*0.55, 6), fontsize=8, color="#c0392b",
            arrowprops=dict(arrowstyle="->", color="#c0392b", lw=0.9))
ax.set_xlabel("time (units of one mean molecule lifetime, $1/d$)")
ax.set_ylabel("molecules $X$")
ax.set_xlim(0, t_grid[-1])
ax.set_ylim(bottom=-1)
ax.legend(frameon=False, loc="upper left", fontsize=8)
fig.tight_layout()
fig.savefig("/tmp/week3ext/fig1.svg")
plt.close(fig)

fig, ax = plt.subplots(figsize=(6.4, 3.0))
K_line = np.linspace(4, 100, 300)
T_line = np.array([exact_mean_extinction_time(k) for k in K_line])
ax.plot(K_line, T_line, color="#1f4e79", lw=1.6,
        label="exact mean extinction time (backward equation)")
ax.errorbar(sim_Ks, sim_means, yerr=sim_sems, fmt="o", ms=4.5, color="#c0392b",
            ecolor="#c0392b", elinewidth=1, capsize=3,
            label="Gillespie simulation (mean ± s.e.m.)")
ax.set_yscale("log")
ax.set_xlabel("carrying capacity $K$ (molecules)")
ax.set_ylabel("mean time to extinction")
ax.legend(frameon=False, loc="upper left", fontsize=8)
fig.tight_layout()
fig.savefig("/tmp/week3ext/fig2.svg")
plt.close(fig)
print("figures written")

What I would argue against / where this breaks

Not every zero is absorbing. The whole argument needs production to vanish at zero copies. A chromosomal gene keeps transcribing mRNA no matter how few transcripts exist, and an ecosystem with immigration never truly dies out; the zero boundary then re-opens and the quasi-stationary state becomes a genuine stationary one. The claim applies only to autocatalytic entities — things born only from themselves.

The exponential cuts both ways. At genomic copy numbers (10³–10⁴ molecules) the extinction time is so astronomically long that the deterministic picture is not just convenient but correct for all practical purposes; my Figure 2 stops being measurable, not just computable. The phenomenon lives at K ~ 1–100, which is precisely where real self-replicating cellular machinery (plasmid copy numbers, organelle genome copies) actually sits.

Quasi-stationarity hides the trap. Before extinction, every moment of the distribution looks stationary, so no finite experiment distinguishes "stable" from "metastable with a 10⁷-year lifetime". One could object that the distinction is then metaphysics; the answer is that the distribution of extinction times (roughly exponential, so extinction arrives without warning, as in Figure 1) is observable in principle and matters for designs like kill switches and containment, where you want the absorbing state reached quickly rather than never.
