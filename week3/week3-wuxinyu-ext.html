Same affinity, different protein crosslinking

Xinyu Wu (吴新宇) · Week 3 · CCBS 2026 · 15 September 2026
L5: Markov states → L6: when fast-state averaging fails

One sentence: Equal equilibrium binding affinity does not imply equal finite-time covalent crosslinking: averaging over binding is reliable only when binding exchange is sufficiently fast relative to capture.

The question from my research

I work on covalent protein crosslinking. If two binders have the same dissociation constant, should they crosslink equally well? Proximity-enabled covalent protein engineering makes this question concrete: Li et al. engineered PD-1 to covalently capture PD-L1 [1]. However, proximity is an opportunity, not a completed bond. I use a minimal model to ask when equilibrium occupancy loses the timing information needed to predict capture.

Three states, one quantitative null model

Consider protein A already bearing a reactive group, with partner B in excess. Let U, C and X denote the fractions unbound, reversibly complexed and covalently crosslinked. This isolates the second capture step, not the entire chemistry of adding a bifunctional linker.

U ⇄ C → X
U → C: a = kon[B];   C → U: b = koff;   C → X: c
dU/dt = −aU + bC
dC/dt = aU − (b + c)C;   dX/dt = cC

All three rates have units s−1. Assume constant rates, irreversible capture and an initially unbound population: U(0)=1. These are also the state probabilities of a continuous-time Markov chain. Without capture, the bound fraction is peq=a/(a+b).

Null assumption: binding equilibrates instantly within the unreacted pool, so C≈peq(1−X). Consequently,

XRE(t) = 1 − exp(−c peq t).

This rapid-equilibrium reduction is justified in the fast-exchange limit c/(a+b)≪1, after the initial binding transient. It is not an identity for arbitrary rates.

A counterexample I calculated

Set [B]=1 μM and c=0.1 s−1. Compare slow exchange, a=b=0.01 s−1, with fast exchange, a=b=1 s−1. Both have Kd=b/kon=1 μM and peq=1/2. Every parameter is illustrative, not measured or fitted.

Solving the full three-state model gives 36.6% versus 94.5% crosslinking at 60 s; the equilibrium null predicts 95.0% for both. The corresponding exchange times 1/(a+b) are 50 s and 0.5 s, whereas the chemical clock 1/c is 10 s. Slow exchange cannot maintain the assumed equilibrium mixture while capture removes complexes.

Thus, matching Kd preserves a ratio of rates, not their absolute clock. A useful experimental comparison would measure binding kinetics and a crosslinking time course, rather than interpreting one endpoint band as equilibrium affinity.

Where this argument breaks

This is a counterexample, not a fit to my experiments or to [1]. Real linkers introduce orientation-dependent reactivity, hydrolysis, competing monolinks and changing concentrations; the fuller model in Kammer et al. explicitly treats several of these pathways [2]. Here c compresses chemistry and geometry into one constant. Pre-equilibrating the proteins changes the early-time result. With no losses, both model systems eventually reach X=1: the claim concerns finite-time capture, not different ultimate yields. Nor does it establish a universal rule that faster exchange always improves crosslinking.

Calculation and reproducibility

For s=a+b+c and r±=(s±√(s²−4ac))/2, the exact solution used in Figure 1 is

X(t)=1−[r+e−r−t−r−e−r+t]/(r+−r−).

The roots are distinct for the chosen positive rates. The script evaluates the smaller root in a numerically stable form. Independent fourth-order Runge–Kutta integration at steps 0.02 s and 0.01 s agrees at 60 s within 10−8; probability conservation, positivity and monotonicity also pass. The exact curve has X′(0)=0, whereas the instantaneous-equilibrium approximation has X′RE(0)=c/2: its missing initial transient is visible mathematically.

Additional check: the mean first-capture time starting unbound is (a+b+c)/(ac), giving 120 s and 21 s, versus 20 s under the null. These are mean waiting times, not single-exponential fits.

"""Original three-state crosslinking calculation; Python standard library only.
Run: python crosslink_calculations.py
All parameters are illustrative, NOT measurements or literature estimates.
Generates crosslink-model.svg and crosslink-model.csv alongside this script.
"""
import csv
import math
from pathlib import Path


def crosslinked(t, a, b, c):
    """Exact absorbing-state probability, starting entirely unbound."""
    s = a + b + c
    root = math.sqrt(s*s - 4*a*c)
    rs = 2*a*c/(s + root)
    rf = (s + root)/2
    return 1 - (rf*math.exp(-rs*t) - rs*math.exp(-rf*t))/(rf-rs)


def rk4(tmax, dt, a, b, c):
    def rhs(y):
        u, bound, x = y
        return (-a*u+b*bound, a*u-(b+c)*bound, c*bound)
    y = (1., 0., 0.)
    n = round(tmax/dt)
    h = tmax/n
    for _ in range(n):
        k1 = rhs(y)
        k2 = rhs(tuple(v+h*k/2 for v,k in zip(y,k1)))
        k3 = rhs(tuple(v+h*k/2 for v,k in zip(y,k2)))
        k4 = rhs(tuple(v+h*k for v,k in zip(y,k3)))
        y = tuple(v+h*(p+2*q+2*r+s)/6 for v,p,q,r,s in zip(y,k1,k2,k3,k4))
        assert abs(sum(y)-1) < 1e-10 and min(y) > -1e-12
    return y[2]


def make_svg():
    width, height = 720, 390
    left, right, top, bottom = 70, 695, 88, 330
    px = lambda t: left + (right-left)*t/120
    py = lambda p: bottom - (bottom-top)*p
    parts = [f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 {width} {height}" role="img" aria-labelledby="plot-title plot-desc">',
             '<title id="plot-title">Same affinity, different finite-time crosslinking</title>',
             '<desc id="plot-desc">At sixty seconds the slow-exchange model gives about 37 percent crosslinking, the fast-exchange model 95 percent, despite identical equilibrium binding affinity. The rapid-equilibrium approximation predicts 95 percent for both.</desc>',
             '<rect width="720" height="390" rx="8" fill="white"/>',
             '<g font-family="Arial, sans-serif" font-size="14" fill="#263747">',
             '<text x="24" y="28" font-size="18" font-weight="bold">Same Kd = 1 μM; same chemical rate c = 0.1 s⁻¹</text>']
    series = [('Rapid-equilibrium null', '#697581', '7 5', lambda t: 1-math.exp(-.05*t)),
              ('Fast exchange', '#087e8b', '', lambda t: crosslinked(t,1,1,.1)),
              ('Slow exchange', '#c14a23', '', lambda t: crosslinked(t,.01,.01,.1))]
    for i,(label,color,dash,fn) in enumerate(series):
        lx = [25,310,510][i]
        parts += [f'<line x1="{lx}" y1="54" x2="{lx+27}" y2="54" stroke="{color}" stroke-width="3" stroke-dasharray="{dash}"/>',f'<text x="{lx+33}" y="59">{label}</text>']
    for j in range(5):
        v=j/4
        parts += [f'<line x1="{left}" y1="{py(v)}" x2="{right}" y2="{py(v)}" stroke="#e2e8ed"/>',f'<text x="{left-12}" y="{py(v)+5}" text-anchor="end">{v:g}</text>']
    for t in range(0,121,30):
        parts.append(f'<text x="{px(t)}" y="354" text-anchor="middle">{t}</text>')
    parts += [f'<path d="M{left},{top} V{bottom} H{right}" fill="none" stroke="#415463"/>',
              '<text x="380" y="380" text-anchor="middle">Time after mixing (s)</text>',
              '<text transform="translate(20,210) rotate(-90)" text-anchor="middle">Crosslinked fraction X(t)</text>',
              f'<line x1="{px(60)}" y1="{top}" x2="{px(60)}" y2="{bottom}" stroke="#aab4bc" stroke-dasharray="3 5"/>']
    for label,color,dash,fn in series:
        coords=' '.join(('M' if t==0 else 'L')+f'{px(t):.2f},{py(fn(t)):.2f}' for t in range(121))
        parts.append(f'<path d="{coords}" fill="none" stroke="{color}" stroke-width="2.6" stroke-dasharray="{dash}"/>')
    for a,col,dy in [(1,'#087e8b',25),(.01,'#c14a23', -30)]:
        v=crosslinked(60,a,a,.1)
        parts += [f'<circle cx="{px(60)}" cy="{py(v)}" r="4" fill="{col}"/>',f'<text x="{px(60)+10}" y="{py(v)+dy}" fill="{col}" font-weight="bold">{100*v:.1f}% at 60 s</text>']
    return '\n'.join(parts+['</g></svg>'])


if __name__ == '__main__':
    base=Path(__file__).resolve().parent
    for label,a,b in [('slow',.01,.01),('fast',1.,1.)]:
        exact=crosslinked(60,a,b,.1)
        for dt in [.02,.01]:
            assert abs(rk4(60,dt,a,b,.1)-exact)<1e-8
        assert abs(crosslinked(0,a,b,.1))<1e-12
        vals=[crosslinked(t,a,b,.1) for t in range(121)]
        assert all(-1e-12<=v<=1 for v in vals)
        assert all(x<=y+1e-12 for x,y in zip(vals,vals[1:]))
        print(f'{label}: X(60)={exact:.9f}; mean first capture={(a+b+.1)/(a*.1):.3f} s')
    print(f'Rapid-equilibrium null: X(60)={1-math.exp(-3):.9f}; mean first capture=20 s')
    (base/'crosslink-model.svg').write_text(make_svg(),encoding='utf-8')
    with (base/'crosslink-model.csv').open('w',newline='',encoding='utf-8') as f:
        writer=csv.writer(f)
        writer.writerow(['time_s','slow_X','fast_X','rapid_equilibrium_X'])
        for t in range(121):
            writer.writerow([t,crosslinked(t,.01,.01,.1),crosslinked(t,1,1,.1),1-math.exp(-.05*t)])
    print('PASS: analytic solution vs RK4, two step sizes, conservation, positivity, monotonicity.')
