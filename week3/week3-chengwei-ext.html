Week 3 Extension: Can the Slower Molecular Signal Win?

Chengwei Jin · Week 3 · 2026-09-17 · CCBS 2026

One sentence: In a race between two independent molecular sources, raising a shared count threshold makes the faster source more likely to win, but delays the decision.

The point I am adding

Two signals start together. Signal B produces molecules faster than signal A. A smooth model puts B ahead at every positive time, but does that guarantee B reaches a trigger first? Lecture 5 distinguishes a mean trajectory from an individual history.1 I extend that distinction to a race: how reliably can a count threshold select the faster source?

Consider two independent production channels, ∅ → A and ∅ → B, with constant propensities a and b. Both counts start at zero. The first species to reach K molecules wins, and we stop the simulation. There is no degradation, feedback or competition for resources. This is an illustrative short-window model of accumulating signals, not a fitted biological circuit.

Work it

I set a = 1 and b = 1.5 events per minute. These are chosen parameters, not rates inferred from an observed mean. Gillespie sampling draws an exponential waiting time with total rate a+b, then adds A with probability a/(a+b) or B otherwise.2 Repeating until either count reaches K gives a winner and a decision time. I ran 50,000 independent races at each of five thresholds.

At K = 1, slower A wins 40.0% of races in theory. At K = 20, it still wins 10.2%. The mean decision time rises from 0.40 to 13.09 minutes. Simulations give 39.9% and 10.1%, with mean times of 0.40 and 13.08 minutes. A higher threshold averages over more event identities, reducing accidental victories by the slower source. Waiting for more events also takes longer. The deterministic prediction that B always wins misses the finite-threshold probability.

Exact check, full numerical results and derivation

Let p = a/(a+b), q = 1−p, and T be the time until the first threshold crossing. Each event independently belongs to A with probability p. If A wins with j B molecules present, the final event is A, and the preceding K+j−1 events contain K−1 A events and j B events. Thus:

P(A wins) = ∑j=0K−1 C(K+j−1, j) pKqj.

Here C(n,j) = n!/[j!(n−j)!] counts the possible event orders. Swap p and q to obtain the probability that B wins with j A molecules. Write their sum as wj. The race then lasts K+j events, each with mean wait 1/(a+b), independently of the event labels. Consequently:

E[T] = ∑j=0K−1 (K+j) wj / (a+b).

These finite sums are derived here to verify the simulation. Probability depends only on the rate ratio. Multiplying both rates by the same factor leaves the winner probabilities unchanged and divides mean time by that factor. At equal rates, symmetry gives a 50% winning probability for every K. A larger threshold improves selection only when one rate really is higher. On a shared event sequence, increasing K cannot make the stopping time earlier.

Reproduce the figure's numbers: complete Python source

Save as analysis/run.py in a folder with an analysis subfolder and run with Python 3. It uses only the standard library and writes results.json. The figure plots those results. The browser implementation is shown separately below.

"""Exact first-passage race and seeded Gillespie verification. Python standard library only."""
import json, math, random, statistics
from pathlib import Path
ROOT = Path(__file__).resolve().parents[1]

def exact(k, a=1.0, b=1.5):
    p, q = a/(a+b), b/(a+b)
    awin = mean_n = second = total = 0.0
    for j in range(k):
        wa = math.comb(k+j-1, j)*p**k*q**j
        wb = math.comb(k+j-1, j)*q**k*p**j
        mass, n = wa+wb, k+j
        awin += wa
        total += mass
        mean_n += n*mass
        second += n*(n+1)*mass/(a+b)**2
    mean = mean_n/(a+b)
    assert abs(total-1)<1e-12
    return awin, mean, second-mean*mean

def simulate(k, a, b, m, seed):
    rng = random.Random(seed)
    wins, times = 0, []
    for _ in range(m):
        na = nb = 0
        t = 0.0
        while na < k and nb < k:
            t += -math.log(1-rng.random())/(a+b)
            if rng.random() < a/(a+b): na += 1
            else: nb += 1
        wins += na == k
        times.append(t)
    return wins/m, statistics.mean(times), statistics.stdev(times)/math.sqrt(m)

def main():
    rows=[]
    for k in [1,3,5,10,20]:
        p,t,v=exact(k)
        ph,th,se=simulate(k,1,1.5,50000,20260917+k)
        pse=math.sqrt(p*(1-p)/50000)
        assert abs(ph-p)<5*pse and abs(th-t)<5*se
        rows.append(dict(k=k,p=p,time=t,sim_p=ph,sim_time=th,p_se=pse,time_se=se))
    # Independent checks: symmetry, K=1, and a survival-probability sum.
    for k in [1,2,10,30]:
        assert abs(exact(k,1,1)[0]-.5)<1e-12
        p,t,_=exact(k)
        survival=sum(math.comb(i+j,i)*.4**i*.6**j/2.5 for i in range(k) for j in range(k))
        assert abs(t-survival)<1e-11
        assert abs(exact(k,2,3)[1]-t/2)<1e-12
    assert abs(exact(1)[0]-.4)<1e-12
    assert abs(exact(1)[1]-.4)<1e-12
    data=dict(rates=[1,1.5],trials_per_threshold=50000,seed_rule='20260917 + K',rows=rows,
              curve=[dict(k=k,p=exact(k)[0],time=exact(k)[1]) for k in range(1,21)])
    (ROOT/'analysis/results.json').write_text(json.dumps(data,indent=2),encoding='utf-8')
    print(json.dumps(rows,indent=2))

if __name__=='__main__': main()

What I would argue against / where this breaks

“Faster on average” does not mean “first every time.” But this race does not establish a universal cellular speed–accuracy law. Calling an A victory an error presumes the goal is to select the faster input. The threshold is a defined readout, not a modeled molecular switch. Degradation, bursts, unequal starting counts or coupled production change the result. Applying the model to cells would require measured rates and a justified threshold mechanism. Here, the extension is a quantitative first-passage comparison, not evidence about a particular cell fate.

// Shared by the standalone page and the Node verification script.
function seeded(seed) {
  return function () {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function race(K, a, b, rng) {
  let A = 0, B = 0, time = 0;
  const path = [[0, 0, 0]];
  while (A < K && B < K) {
    time += -Math.log(1 - rng()) / (a + b);
    if (rng() < a / (a + b)) A++; else B++;
    path.push([time, A, B]);
  }
  return {winner: A === K ? 'A' : 'B', time, path};
}
function theory(K, a, b) {
  const p = a / (a + b), q = 1 - p;
  let wa = p ** K, wb = q ** K, probability = 0, mean = 0;
  for (let j = 0; j < K; j++) {
    probability += wa;
    mean += (K + j) * (wa + wb) / (a + b);
    wa *= (K + j) / (j + 1) * q;
    wb *= (K + j) / (j + 1) * p;
  }
  return {probability, mean};
}
