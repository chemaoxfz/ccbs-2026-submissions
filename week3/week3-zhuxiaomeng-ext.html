WEEK 3 — Extension: When measurement hides noise

Author: zhuxiaomeng · Week 3 (2026-09-21) · CCBS 2026

One sentence: A longer measurement window can suppress observed gene-expression variance without changing the underlying dynamics, so a smoother signal alone does not establish weaker intrinsic fluctuations.

The point I am adding

Lecture 6 averages a rapidly switching promoter to simplify its dynamics [1]. I instead keep the reaction rates fixed and average only the observation: can an unchanged system appear quieter when measurements integrate over longer windows? This extends the stochastic-dynamics topic of Lecture 5 and the promoter model of Lecture 6 by adding an explicit observation process.

Work it

The promoter switches OFF→ON at rate α and ON→OFF at rate β; protein is produced at rate ρ while ON and removed at rate γ per molecule. Set α = β = 0.5γ and ρ = 20γ. The stationary moment formulas in Lecture 6 give mean μ = 10 and variance σ² = 60 [1]. These are illustrative model parameters. Define the trailing measurement YT(t) = (1/T)∫t−TtP(s) ds. For a stationary process, averaging preserves the mean, while the variance follows from integrating the covariance between every pair of times in the window:

E[YT] = μ
Var(YT) = (2/T²) ∫0T(T − τ) C(τ) dτ.

Here C(τ) = Cov[P(t), P(t + τ)]. With time measured in units of 1/γ, this model gives C(τ) = (60 + 50τ)e−τ. I compared its covariance integral with 24 independent Gillespie trajectories, computing window averages directly from the event histories. The derivation, parameters and executed code are included below.

Increasing T from 0.2 to 5 relaxation times reduces the theoretical observed variance from 59.211 to 31.421 (46.9%); the corresponding simulated values are 59.564 and 31.590. The theoretical mean remains 10, consistent with the simulated means of approximately 9.953. At T = 20, the theoretical observed variance is 10.200, only 17.0% of the instantaneous variance. The reactions have not changed; temporal integration has hidden much of their fluctuation.

What I would argue against / where this breaks

I would argue against inferring weak intrinsic noise or fast promoter switching from low measured variance alone. The averaging window must be considered relative to the signal’s correlation time. This is not the same as recording instantaneous values less often: under stationarity, sparse sampling preserves their marginal variance but loses temporal information. My result assumes stationary expression and ideal time integration; during a changing mean, averaging can also delay or distort the response. Detector noise, reporter maturation and cell-to-cell variability are excluded, so the calculation does not establish how any particular instrument behaves.

Calculation, exact covariance and numerical results

Let G ∈ {0,1}, p = α/(α+β), k = α+β, and q = Cov(G,P). Stationary moment equations give μ = ρp/γ, q = ρp(1−p)/(γ+k), and σ² = μ + (ρ/γ)q. With γ = 1, k = 1 and p = 1/2, these give q = 2.5 and σ² = 60.

For lag u ≥ 0, define H(u) = Cov[G(t+u),P(t)]. Since the switching process is autonomous, H′ = −kH with H(0) = q. Protein dynamics then give C′ = ρH − γC, C(0) = σ². For k = γ = 1 this yields C(u) = (σ² + ρqu)e−u = (60 + 50u)e−u. Thus ∫C(u)du = 110 and τint = 110/60 = 11/6. The window-variance identity follows from Var(YT) = T−2∫0T∫0TC(u−v)du dv, using the evenness of the scalar stationary covariance.

Numerical design: 24 independent Gillespie trajectories, seed 20260921; initial G = P = 0; 100 time units discarded, followed by 20 additional units of history for the largest window. Each replicate has a 5,000-unit observation period. Window integrals are computed exactly from the piecewise-constant event trajectory. Endpoints are 0.5 units apart. Overlapping windows are correlated: uncertainty is calculated across the 24 independent trajectories, not across windows. Variance is estimated as the average of (YT−10)² using the known stationary mean, avoiding the finite-path bias of estimating the mean separately on each trajectory. Error bars are ±1.96 between-replicate standard errors, a normal approximation.

Reproducible Python code — simulation, numerical checks and original figure

Save this code as simulation.py and run python simulation.py with NumPy, SciPy and Matplotlib. It produces figure.svg, figure.png and results.json. Versions used: NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8. All figure data and numerical results in this essay come from this executed code. The HTML itself requires no Python or network connection.

import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from scipy.integrate import quad
import json

# Dimensionless time u = gamma*t; alpha/gamma=beta/gamma=0.5.
# Direct Gillespie simulation; no time discretization of reactions.
SEED, REPS, BURN, LENGTH = 20260921, 24, 100., 5000.
WINDOWS = np.array([.1,.2,.5,1.,2.,5.,10.,20.])
MU, VAR = 10., 60.

def trajectory(rng, stop):
    t, g, n = 0., 0, 0
    times, counts = [t], [n]
    while True:
        hazards = np.array([.5*(1-g), .5*g, 20.*g, float(n)])
        total = hazards.sum()
        t += rng.exponential(1./total)
        if t >= stop:
            break
        reaction = np.searchsorted(np.cumsum(hazards), rng.random()*total)
        if reaction == 0: g = 1
        elif reaction == 1: g = 0
        elif reaction == 2: n += 1
        else: n -= 1
        times.append(t); counts.append(n)
    times.append(stop); counts.append(n)
    times, counts = np.array(times), np.array(counts)
    area = np.r_[0., np.cumsum(np.diff(times)*counts[:-1])]
    def integral(q):
        q = np.asarray(q)
        k = np.minimum(np.searchsorted(times,q,side='right')-1,len(times)-2)
        return area[k] + counts[k]*(q-times[k])
    return times, counts, integral

def covariance(u):
    # Equal switching and degradation relaxation rates: k=gamma=1.
    return (60.+50.*u)*np.exp(-u)

def theory(T):
    return 2.*quad(lambda u:(T-u)*covariance(u),0.,T,epsabs=1e-10)[0]/T**2

means, variances = [], []
for rep, child in enumerate(np.random.SeedSequence(SEED).spawn(REPS)):
    times, counts, integral = trajectory(np.random.default_rng(child),BURN+LENGTH+20.)
    endpoints = np.arange(BURN+20., BURN+LENGTH+20., .5)
    ys = np.array([(integral(endpoints)-integral(endpoints-T))/T for T in WINDOWS])
    means.append(ys.mean(axis=1))
    # Known stationary mean avoids downward bias from fitting each path's mean.
    variances.append(((ys-MU)**2).mean(axis=1))
    if rep == 0:
        grid=np.linspace(BURN+20.,BURN+80.,6001)
        raw=counts[np.searchsorted(times,grid,side='right')-1]
        paths=[(integral(grid)-integral(grid-T))/T for T in [.2,5.]]
means, variances = np.array(means),np.array(variances)
mean_se=means.std(axis=0,ddof=1)/np.sqrt(REPS)
var_se=variances.std(axis=0,ddof=1)/np.sqrt(REPS)
th=np.array([theory(T) for T in WINDOWS])
# Numerical verification against independent exact moments and quadrature.
assert abs(covariance(0)-VAR)<1e-12
assert np.all(np.diff(th)<0)
assert np.all(np.abs(means.mean(axis=0)-MU)<5*mean_se)
assert np.all(np.abs(variances.mean(axis=0)-th)<5*var_se)
plt.rcParams.update({'font.family':'DejaVu Sans','font.size':10,'axes.spines.top':False,'axes.spines.right':False,'svg.fonttype':'none'})
fig=plt.figure(figsize=(10.5,6.0),layout='constrained')
gs=fig.add_gridspec(2,2,height_ratios=[1.1,1])
a=fig.add_subplot(gs[0,:]); b=fig.add_subplot(gs[1,0]); c=fig.add_subplot(gs[1,1])
a.step(grid-grid[0],raw,where='post',color='#a5aeb7',lw=.8,label='Instantaneous count')
for y,col,label in zip(paths,['#187f91','#d66b32'],['Window 0.2','Window 5']):
    a.plot(grid-grid[0],y,color=col,lw=1.6,label=label)
a.set(xlabel='Time elapsed (1/γ)',ylabel='Protein count / average',title='A   Same dynamics, different observation windows',xlim=(0,60)); a.legend(loc='upper right',frameon=False,ncol=3,fontsize=9)
b.axhline(MU,color='#444',ls='--',label='Theory: 10')
b.errorbar(WINDOWS,means.mean(axis=0),yerr=1.96*mean_se,fmt='o',color='#187f91',capsize=3,label='Simulation ± 1.96 SE')
b.set(xscale='log',xlabel='Window length T (1/γ)',ylabel='Observed mean',title='B   Mean is preserved',ylim=(9.5,10.5)); b.legend(frameon=False,fontsize=9)
fine=np.geomspace(.1,20,200)
c.plot(fine,[theory(t)/VAR for t in fine],color='#d66b32',label='Exact covariance integral')
c.errorbar(WINDOWS,variances.mean(axis=0)/VAR,yerr=1.96*var_se/VAR,fmt='o',color='#187f91',capsize=3,label='Simulation ± 1.96 SE')
c.set(xscale='log',xlabel='Window length T (1/γ)',ylabel='Observed variance / 60',title='C   Variance is suppressed',ylim=(0,1.08)); c.legend(frameon=False,fontsize=9)
fig.savefig('figure.svg'); fig.savefig('figure.png',dpi=170)
result={'windows':WINDOWS.tolist(),'means':means.mean(axis=0).tolist(),'mean_se':mean_se.tolist(),'variances':variances.mean(axis=0).tolist(),'variance_se':var_se.tolist(),'theory':th.tolist(),'numpy':np.__version__,'scipy':__import__('scipy').__version__,'matplotlib':matplotlib.__version__}
with open('results.json','w') as f: json.dump(result,f,indent=2)
print(json.dumps(result,indent=2))
