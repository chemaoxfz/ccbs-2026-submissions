Week 3 — Extension: The same noise histogram can hide three molecular clocks

Author: Siheng Wang · Week 3, Lectures 5–6 · due 2026-09-21, 23:59 · CCBS 2026

One sentence: In the birth–death system from Lecture 5, multiplying both reaction rates by the same factor leaves the entire steady-state distribution unchanged, yet it changes how long a fluctuation is remembered—so a snapshot can identify a balance, but not a timescale.

The point I am adding

Lecture 5 moves from the mean to a distribution and then to single Gillespie trajectories [1]. That raises a useful inverse question: if I measure the full steady-state histogram—not just its mean—have I learned the underlying rates? For the lecture's two-channel model, the answer is no.

Setting the probability flow in the chemical master equation to zero gives the recurrence pn=(b/d)/n · pn−1. After normalization,

Nss ~ Poisson(μ),   μ=b/d,   pn=e−μμn/n!.

Therefore the steady histogram contains only the ratio b/d. I fixed μ=20 molecules and compared three clocks:

b=4, d=0.2 min⁻¹slow · b/d=20
b=20, d=1 min⁻¹medium · b/d=20
b=100, d=5 min⁻¹fast · b/d=20

Work it

Suppose the count is n now. Its conditional mean after a lag τ is μ+(n−μ)e−dτ. At stationarity, multiplying by the present fluctuation and averaging gives Cov[N(t),N(t+τ)]=μe−dτ; dividing by Var(N)=μ leaves the normalized autocorrelation ρ(τ)=e−dτ. The correlation half-time is therefore ln(2)/d: 3.47, 0.693 and 0.139 min for the three systems.

Reproducible calculation embedded in this file 
# Python 3; no packages
from math import exp, log
from random import Random

mu = 20
systems = [(4, 0.2), (20, 1.0), (100, 5.0)]

# Exact stationary distribution, shared by all three systems
p = [exp(-mu)]
for n in range(1, 46):
    p.append(p[-1] * mu / n)

for b, d in systems:
    print("b/d =", b/d,
          "variance =", mu,
          "correlation half-time =", log(2)/d)

# Exact autocorrelation values used in the upper-right panel
for tau in (0, 0.25, 0.5, 1, 2, 5, 10):
    print(tau, [exp(-d*tau) for b, d in systems])

# Gillespie's direct method for the sample paths
def trajectory(b, d, t_end=10, seed=1):
    rng = Random(seed)
    n, t = mu, 0.0
    path = [(t, n)]
    while t < t_end:
        a0 = b + d*n
        t += -log(rng.random()) / a0
        if t > t_end:
            break
        n += 1 if rng.random()*a0 < b else -1
        path.append((t, n))
    path.append((t_end, n))
    return path

for i, (b, d) in enumerate(systems):
    path = trajectory(b, d, seed=120+i)
    print(b, d, "events =", len(path)-2,
          "range =", (min(n for t,n in path),
                     max(n for t,n in path)))
The extension: the steady-state CME solves a structural question—what distribution is maintained—but it erases the absolute speed of the reaction channels. A time-lapse experiment restores that information: estimate d from the correlation decay, then recover b=μd. “Same distribution” does not mean “same dynamics.”

What I would argue against / where this breaks

This conclusion is deliberately narrow. It assumes a well-mixed, stationary, linear birth–death process observed without measurement noise. Cell growth, extrinsic fluctuations, hidden promoter states or sparse sampling can add extra correlation times. In those cases a single exponential fit would be a model test, not an automatic rate estimate.
